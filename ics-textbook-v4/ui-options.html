4.1.1 / 过程调用约定

4.1.1 过程调用与栈帧

一次调用，怎样保存现场并返回。

教材 122–124 页PDF 647–649 页PPT 已涉及 · 需掌握

函数计算完，还需要回到调用者继续执行。因此，处理器必须保存返回位置，也要为参数和局部变量安排空间。我们从一个具体状态开始：ESP = 1000，EBP = 1200。

本节重点

把地址和内容分别跟踪。ESP 保存栈顶的地址；沿着这个地址读取，才会得到栈中保存的值。

01从一次压栈开始

在这里采用的 32 位约定中，压入一个四字节值，先让 ESP 减去 4，再把值写到新地址。压入 5 后，ESP = 996，地址 996 起的四字节保存 5。

IA-32 · AT&T准备参数并调用
pushl $5
pushl $3
call  add

两次压入参数后，ESP = 992。执行 call 时，再压入四字节返回地址，ESP 变成 988，随后才转到 add 的入口。

02为局部变量建立稳定的参照

进入函数后，栈顶还可能继续移动。我们先保存调用者的 EBP，再用当前栈顶建立稳定的参照，最后给局部变量留出空间。

IA-32 · AT&T建立栈帧
pushl %ebp
movl  %esp, %ebp
subl  $4, %esp

保存旧值后，ESP = 984；复制栈顶后，EBP = 984；预留局部空间后，ESP = 980。此时参照位置保持不变，参数和局部变量都可以相对它定位。

地址保存的内容相对位置
980局部变量预留空间EBP - 4
984调用者的旧基址EBP + 0
988返回地址EBP + 4
992第一个参数 3EBP + 8

第一个参数在地址 992，而参照是 984，两者相差 8。所以 8(%ebp) 的偏移来自已经走过的实际存放过程。
