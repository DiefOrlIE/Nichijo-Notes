# 读到这里你就可以去做教材第四章第11题了！

> 教材原题 · PDF 第962–963页

11. 已知C语言函数`test()`的入口参数有`a`、`b`、`c`和`p`，过程体代码如下：

```c-template
*p = a;
return b*c;
```

函数`test()`过程体对应的IA-32汇编代码如下：

```asm
movl 20(%ebp), %edx
movsbw 8(%ebp), %ax
movw %ax, (%edx)
movzwl 12(%ebp), %eax
movzwl 16(%ebp), %ecx
mull %ecx
```

完成下列任务。

（1）写出函数`test()`的原型，以给出返回参数的类型以及入口参数`a`、`b`、`c`和`p`的类型和顺序。

（2）写出对应的x86-64汇编代码。

## 提示1：先确定分析对象

把读宽度、扩展方式、写宽度分别标出来：`movsbw`把1字节按符号扩展到2字节，`movzwl`把2字节补零到4字节。第一个`movl`读出的是指针值，随后`movw`写入的对象只有2字节。

## 提示2：把关键步骤展开

按`EBP+8,+12,+16,+20`先确定`a,b,c,p`顺序。再考虑窄整数的C整数提升：32位`int`可以表示`unsigned short`的全部值，故`b*c`先按`int`运算。乘法指令的名字不能单独还原整个函数的返回声明。

## 完整解答与核对

按题目给出的访问方式，最直接的一组参数解释是：`a`为`signed char`，`b,c`为`unsigned short`，`p`为`short *`，顺序为`a,b,c,p`。在本课程Linux默认有符号`char`模型中，`char a`也能表达同一行为；显式写`signed char`可消除默认符号性差异。

|行|含义|
|---|---|
|1|从`EBP+20`取`p`到`EDX`|
|2|读`a`的低8位，符号扩展为16位放入`AX`|
|3|沿`p`写2字节，完成`*p=a`|
|4|读`b`的16位，零扩展为32位放入`EAX`|
|5|读`c`的16位，零扩展为32位放入`ECX`|
|6|对两个已零扩展的数做32位无符号乘法，完整积在`EDX:EAX`|

返回类型存在信息不足，不能只凭最后的`mull`宣称唯一答案。一个相容原型可以写成`int test(signed char a, unsigned short b, unsigned short c, short *p);`，在`b*c<=INT_MAX`等C有定义的输入上，它返回`EAX`中的乘积。若返回声明改成`unsigned int`，相同有定义输入也可使用同样返回位串；是否需要解释`EDX:EAX`为64位返回值，还要看调用点或补充声明。题给两个16位无符号数的乘积最多`0xFFFE0001`，所以这里`EDX`恒为0，它的出现本身无法证明调用者消费了64位返回值。

尤其要记住整数提升：在32位`int`环境中，两个`unsigned short`先提升为`int`，所以`return b*c;`可能发生有符号溢出；把返回类型改成无符号或64位，不会自动把乘法提前改成该类型。若另写`return (unsigned long long)b*c;`，可保证先宽乘，但那已经修改了原题表达式，不能冒充原题唯一还原。

下面选用上述32位`int`返回原型，给出一份相容的64位平台实现。参数`a,b,c,p`依次使用`DIL,SI,DX,RCX`的相应有效部分；指针保持64位，写入对象仍为2字节。

```asm64
.globl hw_test64
hw_test64:
    movsbw %dil, %ax
    movw %ax, (%rcx)
    movzwl %si, %eax
    movzwl %dx, %r8d
    imull %r8d, %eax
    ret
```

`imull`在这里取32位低半，足以实现选定的32位返回接口；它不说明源参数因此变成有符号短整数。若另外明确采用“64位无符号宽乘后返回”的新接口，可先零扩展`b,c`，再做64位乘法并从`RAX`返回，但必须同时写清改变后的C表达式与接口。

核对`a=-2,b=300,c=200`：`*p`的两字节为`FE FF`，返回60000。`a=-128,b=0,c=65535`得到`*p=-128`、返回0；`a=127,b=65535,c=1`返回65535。若用`65535*65535`测试，只能按给定机器位串得到`0xFFFE0001`，不能把它当作原有符号`int`乘法的可移植C结果。

若教师对返回类型给出唯一约定，按补充约定填写；仅据当前题面，应将上述相容答案与信息不足的理由一并说明。
