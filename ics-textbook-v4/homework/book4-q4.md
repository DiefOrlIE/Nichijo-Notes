# 读到这里你就可以去做教材第四章第4题了！

题意：恢复`operate(int x, int y, int z, int k)`中`v`的表达式；逐条注释以下IA-32函数体，并给出Linux System V AMD64版本及性能比较。建帧、退帧代码在原题中省略。

```asm
movl 12(%ebp), %ecx
sall $8, %ecx
movl 8(%ebp), %eax
movl 20(%ebp), %edx
imull %edx, %eax
movl 16(%ebp), %edx
andl $65520, %edx
addl %ecx, %edx
subl %edx, %eax
```

## 提示1：先确定分析对象

先抄参数槽：`x`在`EBP+8`，`y`在`+12`，`z`在`+16`，`k`在`+20`。AT&T的双操作数顺序为源、目的，最后一条尤其要按目的减源读。

## 提示2：把关键步骤展开

第5条之后`EAX`保存`x*k`的低32位。第8条之后`EDX`保存`(z&65520)+(y<<8)`的低32位。最后的被减数仍在`EAX`，不能把两个表达式颠倒。

## 完整解答与核对

逐条结果如下；机器层面的32位算术保留低32位。

|行|含义与执行后的状态|
|---|---|
|1|读`y`，`ECX=y`|
|2|`ECX`左移8位，形成`y<<8`的位串|
|3|读`x`，`EAX=x`|
|4|读`k`，`EDX=k`|
|5|乘法低32位写回，`EAX=low32(x*k)`|
|6|重新读`z`，旧`EDX=k`不再保留|
|7|保留掩码`65520=0xFFF0`允许的位，`EDX=z&65520`|
|8|`EDX=low32((z&65520)+(y<<8))`|
|9|`EAX=low32(x*k-((z&65520)+(y<<8)))`|

缺失的表达式可填为`x*k - ((z & 65520) + (y << 8))`。按C中32位`int`解释时，应限于左移合法、乘法及加减中间结果均不溢出的输入；汇编位串仍可按模`2^32`追踪，不能据此给原有符号C表达式增加溢出保证。

Linux System V AMD64下，`x,y,z,k`依次在`EDI,ESI,EDX,ECX`。一份完整的叶函数如下，仍以32位`int`做运算。

```asm64
.globl hw_operate64
hw_operate64:
    movl %esi, %eax
    sall $8, %eax
    andl $65520, %edx
    addl %edx, %eax
    imull %ecx, %edi
    subl %eax, %edi
    movl %edi, %eax
    ret
```

这版先在`EAX`得到减数，再在`EDI`得到乘积，按`乘积-减数`计算，最后移入返回寄存器`EAX`。它使用的寄存器均可由本约定下的被调用函数改写，无需额外保存被调用者保存寄存器。

性能比较只能给有证据的结论：原题函数体9条指令，其中4条读参数内存；此版计算部分7条指令，参数已在寄存器，没有显式数据内存读取。`ret`等控制交接另计；调用者准备参数、依赖链、处理器和优化也会影响实际耗时，不能仅据数量给固定倍速。

核对输入`x=3,y=2,z=63,k=5`：乘积15，掩码结果48，左移结果512，最终`15-(48+512)=-545`。若算成正545，请回查最后减法顺序。
