# 自学讲义网页样式规范 V1

定稿日期：2026-11-05；目录与验收范围更新：2026-11-08。适用于今后的课程自学讲义网页。视觉基准为 ICS 教材式自学讲义当前阅读页；本文件固定已确认的风格，新增课程默认沿用。正文教学另遵循《AI自学讲义制作与重写总规范 V4》，先写并验收 Markdown，再生成网页。

## 1. 整体风格

页面应清晰、简洁、有重点，适合持续阅读。采用柔和的米灰纸面、暖棕色强调与克制的层次。正文为连续教材式文章，主要解释、推导和完整例题默认展开；提示与答案可分别折叠。不以卡片墙、密集边框、口号式大标题打断教学。

默认亮色，保留夜间模式。视觉样式、阅读控件与讲义内容分开维护，今后换课程无需重新设计阅读界面。

## 2. 页面布局与对称

正文以整个可用浏览器视口的水平中心为中心，左右留白始终相等。不能把正文只放在“扣除目录后的剩余区域”中央。默认正文纸面宽度 960px，内部左右留白 52px、顶部 42px；移动端内边距约 24px。

左侧目录只显示章节编号与名称，不在目录项中追加页码；页码保留在正文来源行和跟读对照表。目录固定在左侧，独立滚动；正文滚动时，目录自动高亮当前小节、展开其所在分组，并在需要时把当前项滚入可见区域。目录不能随正文消失，也不能因自动跟随拉动正文。空间不足时收为“目录”按钮打开的左侧面板，正文继续保持居中。

桌面可直接在纸面左右边缘拖动宽度。边缘平时无可见把手、竖条或装饰；鼠标悬停显示横向缩放光标。拖动任一边缘，两侧对称展开或收拢。键盘用户仍可操作边缘及数值控件。

纸面宽度可设置 720–1440px，步长 20px；实际宽度不得超过视口减去两侧安全留白。目录宽度约 160–280px，随边侧空间调整；正文宽度加 352px 大于视口时，目录改为可展开面板。

## 3. 字体与正文

正文采用可合法嵌入的宋体风格字体，当前实现为 `StudySerif`，并提供系统宋体回退。中文常规与粗体字形都必须覆盖新讲义内容；不能只验证英文字体加载成功。

默认正文字号 19px，行高约 2.05；段落间距约 1.1em。字号可调整 16–24px，步长 1px。表格和代码随正文字号适当缩放，辅助信息保持较小字号。

目录优先使用华文中宋，回退仿宋，再回退已嵌入的宋体；不能假设每台设备都安装有同名商业字体。目录正文约 15px、小节约 13px。顶部控件采用清楚的系统界面字体。

## 4. 所有代码都使用等宽字体

代码块和正文中的行内代码统一采用真正的等宽字体，当前实现为嵌入式 `ICSMono`，来自可合法分发的 DejaVu Sans Mono。使用字体许可所要求的声明；可回退 Cascadia Code、Consolas、Liberation Mono、monospace。

寄存器名、指令、变量名、类型名、函数调用、表达式、命令、路径、文件名及字节串，只要承担代码含义，就应在 Markdown 中正确标记为行内代码或代码块。不能只改代码块 CSS，让正文中的代码仍以比例字体显示。英文解释性句子无需整段变为代码。

代码及其子元素强制继承等宽字体，禁用会改变字符组合显示的连字；术语弹窗标记与语法高亮不能破坏字体。代码块保留原空格、缩进、换行和复制文本，长行在框内水平滚动。不得给整页制造横向滚动条。

代码框使用稍深的米灰底和细边框。按语言进行真实词法高亮：关键字用柔和紫色、函数或汇编指令用蓝色、寄存器与数值用棕橙色、字符串用绿色、注释用灰绿色。夜间模式使用相应浅色。颜色不能成为唯一的语义依据。

## 5. 配色基准

| 用途 | 亮色基础值 | 夜间基础值 |
|---|---|---|
| 外部背景 | `#e5e0d5` | `#201f1c` |
| 正文纸面 | `#f3efe5` | `#292722` |
| 正文文字 | `#332f29` | `#e7e0d3` |
| 次要文字 | `#756d62` | `#bdb2a0` |
| 分隔线 | `#d2c9ba` | `#514a3e` |
| 强调色 | `#8a6139` | `#e0b486` |
| 浅强调／代码底 | `#e9e2d4` | `#343027` |

亮度控件默认 95%，范围 80–100%，步长 1%。亮色背景、纸面和代码底随亮度向暖灰 `#8b806d` 轻微混合；文字保持清楚，不把整页套上透明层或滤镜。夜间模式使用独立配色。

目录滚动条为细暖棕色，轨道与页面背景一致，圆角、低对比度，悬停略加深；当前亮色滑块约为 `#b5a58b`。不保留突兀的白色轨道与默认灰块。

## 6. 标题、引言与教材对照

标题优先采用教材正式章节名；课程按 PPT 编排时采用 PPT 的明确知识点名。保留清楚的序号和来源章号，例如：

> **4.1.1 IA-32的过程调用约定（教材 4.1.1；PPT 第3章）**
>
> 先让调用者提出需求
>
> 纸书 122–124 页 · PPT 第3章 64–79、88–103 页 · 需掌握

标题下的引导语用小字、次要颜色表示，不再冒充正式章节标题。属于同一教材小节的连续讲解可以共享正式标题，原讲解顺序和旧链接定位仍应保留。避免人为制造重复编号或让课程编号与教材编号混淆。

简短来源行只放纸质教材页码、PPT 章号和页码、掌握要求。默认不堆叠 PDF 页序、ISBN、首次出现说明与重复的覆盖解释；详细来源另放来源文档。明确标注“无需掌握”必须有课件覆盖证据；教材带星号或 PPT 标为自学，不能自动推断无需掌握。

## 7. 术语解释与可选标识

必要术语在正文首次出现时仍需讲清楚，弹窗用于随时复查。术语支持鼠标点击、触屏点击、键盘 Enter 或空格打开解释；键盘焦点应可见。

右上角提供“术语标识”选择框，默认 **B · 淡点线**。三种样式随时切换并保存：

| 方案 | 常态 | 悬停或键盘聚焦 |
|---|---|---|
| A · 悬停 | 与普通文字一致，无下划线 | 暖棕色文字、极淡底色 |
| B · 淡点线 | 低对比度、稀疏的小圆点标识 | 点线稍加深，提示可点击 |
| C · 淡底色 | 极淡米棕色底色，无边框 | 底色稍加深 |

B 的当前实现使用间隔约 5px 的细小圆点，常态强调色混合约 36%；避免粗重、连续、高反差下划线。标识不得改变术语所处代码的等宽字体、行距或字符内容。

## 8. 顶部阅读控件

顶部保留正文宽度、字号、亮度、术语标识、日夜模式与术语入口。前三项采用带上下按钮的数字框，可以直接输入数值，并显示 px 或 %；不用滑动条。

上下按钮采用自定义米灰底和暖棕箭头，悬停略深，与目录滚动条及纸面同一色系。不能依赖难以着色的平台原生白底箭头。达到上下限时相应按钮禁用；点击、键盘输入和原生方向键操作结果一致。输入中间过程不得被过早强行改写，导致用户无法键入完整数值。

控件约高 31px，边框细、圆角小，视觉存在感低于讲义正文。窄屏有序换行，不能遮住目录按钮、遮挡章节锚点或挤出视口。

## 9. 阅读记忆

在同一浏览器中，保存字号、宽度、亮度、主题、术语样式、习题展开状态和阅读位置。不同讲义及不同阅读路线分别保存位置，避免相互覆盖。

恢复到上次小节内部的实际阅读位置。重新打开同一链接或常规入口时自动续读；用户明确打开另一个章节链接时尊重其定位意图。等字体和主要排版就绪后再恢复，防止后续加载把位置顶走。滚动停下、页面隐藏和离开时均应妥善保存。

## 10. 表格、练习与重点

表格使用细暖灰边线、适量单元格留白，表头轻微加深，长表在局部容器滚动。重点通过适量加粗、段落层次、浅色提示和少量边线体现，避免每句话都染色或加框。

完整示范直接展开。练习题目可见，提示与解答分别展开；解答中保留推演和核对方法。术语解释和折叠区都不能承载正文首次教学缺失的内容。

## 11. 发布与验收

先保存并审读独立 Markdown；通过内容核验后，用同一稿源构建网页。默认发布 GitHub Pages，保留旧版入口。构建和脚本资源使用版本标记，避免正文已更新但旧 CSS、JS 仍被缓存。

后续验收范围仅包括电脑端和平板端，不安排手机端检查。

发布前至少核对：正式目录与标题一致、页码真实、代码字体及高亮正确、三种术语样式可切换、上下按钮可用、边缘拖动保持左右对称、阅读位置恢复、夜间模式、电脑端／平板端的局部滚动和键盘操作。代码框复制文本必须与源稿一致。未做真实读者试学或某种设备测试时，不夸大验证范围。

## 12. 给后续课程的简短指令

请严格沿用本规范的米灰纸面教材式阅读界面：正文相对整个视口居中且左右对称，左侧跟随目录只放编号与名称，华文中宋／仿宋目录字体，正文宋体，全部代码等宽并语法高亮。正文边缘无可见把手，可对称拖动；右上角用暖色上下按钮调宽度、字号、亮度，提供 A／B／C 术语标识，默认 B。正式标题采用教材或 PPT 知识点名，引导语放标题下小字，来源只显示纸书页码、PPT 页码和掌握要求。保存阅读偏好与分路线阅读位置。先完成文字教学与审读，再从唯一稿源生成网页，默认发布 GitHub；仅检查电脑端和平板端。
