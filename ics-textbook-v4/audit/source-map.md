# 来源与正文定位

PPT页码按导出幻灯片序号计数，含标题页。对应附带的四份课件，共436页（117+184+96+39）。教材章节号与课程章号不同：课程第三章同时对应教材第三、四章，课程第四章主要对应教材第五章链接部分。正文采用依赖顺序重排，第五章先讲指令再讲进程；课件顺序相反。

表中页段说明知识主题的定位，不表示逐一复印了每张课件或验证了每个历史平台输出。详细原页标题列在source-page-index.md。数值教学例子一般为讲义自设；教材题写明转述、同类或改编，原题数据单独注明。
