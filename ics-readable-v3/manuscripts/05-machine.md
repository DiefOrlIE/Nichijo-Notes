# 05 一条指令怎样改变寄存器与内存

先修：整数编码、字节布局与标志位。本章先追踪一条赋值，再增加地址和分支。默认IA-32 Linux，AT&T汇编写法。IA是Intel Architecture，IA-32为Intel的32位体系结构。x86是指令体系家族称呼，x86-64是其64位扩展。

## 从C到机器字节

源代码`int add(int a,int b){return a+b;}`需要转换为处理器能执行的指令字节。预处理展开头文件和宏；编译把C翻译为汇编；汇编把助记符编码为目标文件；链接合并目标文件、解析外部符号并形成可执行文件。目标文件还有尚待链接确定的位置，因此汇编完成与能够独立运行不同。

ISA是Instruction Set Architecture，指令集体系结构，规定软件可观察的寄存器、指令和行为。同一ISA可由不同内部电路实现。CISC是Complex Instruction Set Computer，复杂指令集计算机；RISC是Reduced Instruction Set Computer，精简指令集计算机。二者描述设计风格，不足以单独判断某台机器速度。

## 变量地址与指针先用C做一次

假设一个int变量x的值为7，位于地址1000，连续占四字节。表达式x取它的值7；表达式&x取它的起始地址1000。声明`int *p=&x;`会建立另一个变量p，用于保存这个地址。表达式*p沿着p保存的地址找到x，再读取那里的int。执行`*p=9;`会把x改为9，p仍保存地址1000；执行`p=&y;`则只让p改指向y，原x不会因此搬家。

汇编里的寄存器可以保存整数，也可以保存地址。同一条加法硬件不认识“这是指针”的C类型含义，因此读汇编时要从数据流判断。`(%eax)`中的括号要求沿地址访问内存；`%eax`仅取寄存器本身的数。若EAX保存1000，`movl %eax,%ecx`得到1000，`movl (%eax),%ecx`则沿地址读出当前x的9。以下每次寻址都先说明哪项是地址、哪项是数据。

## 先在寄存器之间传一个数

寄存器是处理器内部保存少量数据的位置。EAX、EBX、ECX、EDX、ESI、EDI、EBP、ESP是IA-32常用32位通用寄存器。E代表Extended，扩展；AX沿用Accumulator累加器名称，BX为Base基址，CX为Count计数，DX为Data数据；SI/DI为Source/Destination Index源/目的变址，BP/SP为Base/Stack Pointer基址/栈指针。这些历史名称不表示今天每条指令都受其用途限制。

`movl $5,%eax`把常数5写进EAX。AT&T来自American Telephone and Telegraph，美国电话电报公司，是此汇编语法的历史名称。这里`$`标立即数，`%`标寄存器，操作数按源、目的排列。l表示long，即32位数据宽度。执行后EAX=00000005。

再执行`movl %eax,%ecx`，ECX得到5，EAX仍是5。mov复制数据，源没有被清除。EAX低16位叫AX，低8位叫AL，第8至15位叫AH。若原EAX=12345678，`movb $0xAA,%al`只改低字节，EAX变123456AA。b/w/l/q分别表示8/16/32/64位，q在64位模式常用。

## 地址与取值分开算

假设EAX=100、EBX=3，内存地址116起存小端字节78、56、34、12。`movl 4(%eax,%ebx,4),%ecx`先算100+3×4+4=116，再从116读四字节，拼成12345678，写ECX。括号内是基址、索引、比例，前面是位移。比例允许1、2、4、8；没有索引便不需要比例。

改为`leal 4(%eax,%ebx,4),%ecx`只做同样的地址计算，得到ECX=116，不读地址116的内容。lea意为Load Effective Address，装入有效地址。`$116`是常数116，`116`通常表示绝对地址处的内存操作数，`(%eax)`表示EAX所给地址处的数据。这三种写法必须分别理解。

普通mov通常不允许两个显式内存操作数。若要从一处内存复制到另一处，应先加载临时寄存器，再存出。写指令前依次检查数据宽度、可写目的、寄存器名称、寻址格式与内存操作数数量。

## 类型转换为什么常需两条传送

unsigned char值250位串FA，要写到32位unsigned int对象。首先必须将8位FA零扩展成000000FA。若源在AL，目的指针在EDX，可以`movzbl %al,%ecx`，再`movl %ecx,(%edx)`。movzbl表示零扩展、byte到long。扩展指令的目的须为寄存器，所以先产生扩宽结果，再按目标宽度写入内存。

若源为signed char的−6，同样位串FA，改用`movsbl %al,%ecx`得到FFFFFFFA，再存四字节。目标即使为unsigned int，负的源值也应先符号扩展，转换结果为4294967290。决定扩宽方式时先看源类型的值。

`movx`只是含糊的占位叫法，无法唯一表达扩展指令；AX还是16位，无法表达这次8到32位的输入输出要求。C中char是否有符号依平台，本课程按GCC x86默认有符号解释，需明确时写signed char。

64位模式写EAX会将RAX高32位清零；写AX或AL保留其余位。unsigned int转unsigned long可借此零扩展。负int转64位unsigned long则需符号扩展，例如`movslq %eax,%rcx`，再`movq %rcx,(%rdx)`。截窄long到int只写低32位，超范围转有符号值的语言边界仍需注明。

## 运算与标志什么时候改变

`addl %eax,%ecx`令ECX等于旧ECX加旧EAX，并按32位更新CF、OF、SF、ZF。`subl %eax,%ecx`令ECX减EAX。`cmp`执行目的减源的标志计算，丢弃结果，因此原操作数不改；`test`做按位与、只留标志。mov与lea不改这些标志。AND/OR/XOR及TEST把CF、OF清零，SF、ZF由结果决定。

INC/DEC加减1并更新OF、SF、ZF，保持原CF。乘法MUL/IMUL定义CF、OF，SF、ZF未定义，不能从结果最高位擅自补出它们。移位计数零时保持标志，计数非零时CF通常来自最后移出位；OF只在计数1时有相应定义，多位移位不得套用单步规则。

单操作数`mull %ebx`隐含EAX×EBX，完整无符号乘积写EDX:EAX；`imull`对应有符号乘法。两/三操作数IMUL保留目标宽度结果。无符号除法`divl`把EDX:EAX除以显式除数，商写EAX、余数EDX；有符号`idivl`之前常用`cltd`把EAX符号扩展成EDX:EAX。`shl`左移、`shr`逻辑右移、`sar`算术右移。变量计数常放CL。

## 比较后怎样选择路径

设EAX=FFFFFFFF、ECX=1。执行`cmpl %ecx,%eax`，计算FFFFFFFF−1=FFFFFFFE，无符号不借位CF=0，结果非零ZF=0，有符号−1−1=−2不溢出OF=0，SF=1。

随后`jb`按无符号低于判断，检查CF=1，因此不跳；`jl`按有符号小于判断，检查SF与OF不同，因此跳。`je`检查ZF=1；`jne`检查ZF=0；`jbe`检查CF或ZF；`jle`检查ZF或SF≠OF。先明确C操作数类型，再选择有符号或无符号条件。

条件设置指令`setl %al`把条件真假写成低字节0或1，未改EAX其余字节；若需要32位布尔值，要再零扩展。条件传送cmov在条件满足时复制数据，可实现某些无跳转选择。

## 机器码中的下一条地址

指令在内存中是字节。IA-32/x86-64变长指令通过前缀、操作码、必要的ModR/M、SIB、位移和立即数字段描述操作与位置。ModR/M编码模式和寄存器/内存选择，SIB表示Scale、Index、Base，即比例、索引、基址。各指令不必都有这些字段。

地址1000处若为`74 08`，它是两字节短条件跳转，下一条地址1002，位移08为+8，目标1010。计算使用十六进制时若起点0804838C，则下一条0804838E，加08得到08048396。位移F6按八位补码为−10，从下一条地址往回10字节。不能从本条起点直接加位移。

## 浮点与并行寄存器

x87使用八个80位扩展精度栈寄存器，ST(0)代表栈顶，ST为Stack Top的习惯记法。加载5再加载2，栈顶为2、下一项为5；无操作数`faddp`将两者相加并弹出一项，最后栈顶7。这里是浮点寄存器栈，与内存中ESP指向的函数栈不同。

SIMD是Single Instruction Multiple Data，单指令多数据。SSE是Streaming SIMD Extensions，流式SIMD扩展；AVX是Advanced Vector Extensions，高级向量扩展。XMM为寄存器名称，128位；YMM为256位扩展视图，不必硬造其字母全称。MMX为Intel的技术商标名称，缺少统一官方展开，应按名称使用。SSE的`addps`可对四个32位float分别相加；`addss`仅做标量单精度。`addsd`是标量double加法。浮点指令不能直接套用整数OF/CF规则。

## 练习

题一：EAX=1000、ECX=2，算`8(%eax,%ecx,4)`的地址，并解释movl与leal的区别。

解答：1000+2×4+8=1016。movl读1016开始四字节；leal仅得到整数1016。没有给内存内容时，movl结果无法确定。

题二：EAX=12345678，执行`movw $0xABCD,%ax`后是多少？

解答：1234ABCD。AX覆盖低16位，高16位1234保留。若是在64位模式写EAX，则另有高32位清零规则。

题三：你需要将AL中的signed char负值写入EDX所指的int，写可行指令并说明每步。

解答：`movsbl %al,%ecx`先按源符号扩为32位；`movl %ecx,(%edx)`再按目标int宽度存四字节。不能只存AL，也不能将扩展指令目的写成内存。

题四：08048390的两字节跳转为72 F6，求目标。

解答：先算下一条08048392；F6为246−256=−10；目标08048388。独立核对目标加10恰回下一条。
