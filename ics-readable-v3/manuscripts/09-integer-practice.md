# 整数编码、电路与综合判断

先修：第03章整数。这里把课程中的补充编码和运算实现接回已经做过的计算。先完成前面的整数教学，再阅读本节；浮点与机器指令稍后讲解。本章中标为“机器模型”的题明确采用32位补码回绕和算术右移。

## 一个小数点约定可以改变整串位的值

八位`11000000`按补码整数为192−256=−64。若约定该整数编码统一除128，得到−0.5。此时最低位价值为1/128，最高位价值为−1。所有值都是整数编码乘一个固定比例，这就是定点小数。八位原码小数把首位作为符号，后七位给出小数绝对值，范围为−127/128到127/128，并有两种零。

移码把有符号指数整体加偏置后存储。例如指数−3用偏置7编码为4，指数+3编码为10。读回时分别4−7=−3、10−7=3。在相同偏置下，编码大小能保持真值顺序。若偏置为2的某次幂，有些格式可由补码翻最高位转换；IEEE规格化指数偏置取127或1023，必须用其实际偏置计算。

BCD是Binary-Coded Decimal，二进制编码的十进制。十进制59按每个数字四位分别写为0101和1001，得到01011001；普通无符号二进制59则是00111011。BCD每组四位仅使用0至9的十种状态，不能看到位串就未经约定按普通二进制解释。它适合需要逐位十进制表示的场景，但编码利用率低于普通二进制。

## 加减共用一套加法

希望算八位A−B，可以使用A加上B的补码负值。硬件把B每位取反，再加1。例如7−3：07加FC再加1，得到104，保留04。无符号减法7≥3不借位，虽然这个加法产生了最高进位，但x86减法CF应为0。换成3−7：03+F8+1=FC，没有最高进位，表示借位，CF为1。减法时CF与该加法器的最高进位相反。

对有符号溢出，还可比较进入符号位和离开符号位的两个进位。它们不一致时OF为1。变形补码给符号增加一个位置，原符号扩展一位。以原四位范围−8至7为例，7写00111、3写00011，相加01010，双符号为01，说明超过原正上界；−8写11000、−3写11101，低五位和10101，双符号10，说明低于原负下界。00、11表示结果仍落在原范围。判断目标仍是原四位可表示性，不能把增加符号位理解为原目标已经自动变宽。

## 从部分积理解乘法

无符号13×11中，11=8+2+1，因此乘积是(13左移3)+(13左移1)+13=104+26+13=143。逐位看乘数，每个1产生一份相应位移后的被乘数，每个0产生零，最后相加。这些中间项叫部分积。两个n位数需要最多2n位来容纳完整乘积。

连续的1可以进一步压缩。60=32+16+8+4，也等于64−4，因此13×60可计算为(13左移6)−(13左移2)=832−52=780。Booth重编码正是利用相邻位变化，把连续1段的多次加法变成边界上的加减。对二进制乘数位yᵢ，并在最低位右侧补y₋₁=0，定义dᵢ=yᵢ₋₁−yᵢ。系数仅为−1、0、1，可分别解释为减、跳过、加。若乘数按n位补码解释，Σdᵢ2ⁱ会自动赋予最高位负权。

验证四位乘数0011：d₀=−1，d₁=0，d₂=1，d₃=0，因此值为−1+4=3。乘数1101按补码为−3：d₀=−1，d₁=1，d₂=−1，d₃=0，值为−1+2−4=−3。执行部分积时要保留足够位数并按符号扩展，不能截断到原乘数宽度后再比较完整结果。课程若未要求具体乘法器时序，这个重编码与部分积核对即可说明其原理。

除法也可从纸笔操作理解。计算13/3：先取最大不超过13的3的二倍幂倍数12=3×4，记商4，余1；余数1小于3，停止。得到商4余1，核对13=4×3+1。硬件可通过移位、试减和恢复部分余数逐位生成商；每步应维持“已处理部分=当前商贡献+当前余数”的关系。带符号除法在此基础上处理符号并按目标取整规则调整。

## 综合表达式先声明模型

令x、y为32位int，ux、uy分别为转换后的32位unsigned int。下面分析采用课程机器模型。写标准C时，涉及有符号溢出或负数左移的表达式还要单独检查语言合法性。

`x*x>=0`并非恒真。x=46341时，数学平方2147488281超过INT_MAX，保留低32位后按补码为−2147479015。反例同时说明数学平方非负不等于定宽乘积解读非负。

`(x>y)==(-x<-y)`对一般数学整数成立，但最小补码的取负无法表示。令x=INT_MIN、y=0，左边假；机器模型取负x仍为INT_MIN，右边真，故不恒真。

`~x+~y==~(x+y)`也不恒真。在固定宽度中~x对应−x−1，左边是−x−y−2，右边−x−y−1，相差1。取x=y=0即可检查：左边−2、右边−1。

`(int)(ux-uy)==(y-x)`须保留次序。左边低位对应x−y，右边是y−x。取x=1、y=0，两边1与−1，不等。对照教材原式时不能把右侧擅自看成x−y。

`((x>>2)<<2)<=x`在算术右移的机器模型中成立。写x=4q+r，q向下取整，r为0至3；右移再左移得到4q=x−r，不大于x。这个推导依赖取整与固定宽度解释，不自动证明相同C表达式对负x左移合法。

浮点判断也要注明变量来源。若double dx来自32位int x，转换精确，`(int)dx==x`在范围内成立；若float fx来自x，x=16777217便会失去1。double乘法虽然比float精确，也不能精确保存任意两个32位int的乘积，因为完整乘积可能需要超过53位的有效精度。不能把“所有单个int都能精确转double”推广成“任意乘积都精确”。

## 迁移练习与解答

题一：某库存软件用八位无符号数保存250件，又增加10件后显示4件。请解释，并给出检测思路。

提示：先问运算类型与保存宽度，再比较数学结果和可表示上界。

解答：250+10=260，按模256剩4。若先用更宽类型计算，可检查结果是否超过255；若已经按无符号模加，结果4小于原250，也能识别本次加法回绕。后者针对无符号加法，不适用于有符号溢出后补救。

题二：将一份16位字段存成两个字节，接收端按相反字节序读取。原数0x0102变成多少？

解答：发送顺序与接收约定相反，两个字节意义交换，得到0x0201=513，原来0x0102=258。传输前应约定字节顺序，并在边界转换。

题三：用较少移位加减计算55x，先用小正数核对，再说明类型前提。

解答：55=64−8−1，因此可算(x<<6)−(x<<3)−x。x=2时128−16−2=110。定宽无符号模型按模保持等式；若写有符号C，须额外保证移位与运算合法。性能是否更好还取决于编译器及硬件。


## 题 34：原式与完整推理对照

先按题设把算术视为 32 位补码回绕、右移视为算术右移。下表保持教材中 x>y 的方向，以及第 8 项右侧 y−x 的次序。涉及有符号溢出、负数左移的项，在标准 C11/C17 中还须标明语言边界。

| 题项与表达式 | 判断与推理 |
|---|---|
| `1 · (x*x)≥0` | 假；x=46341，数学平方2147488281，低32位解读为−2147479015。 |
| 2 · (x−1<0) \|\| x>0 | 假；x=INT_MIN，x−1回绕为INT_MAX，两个条件均假。 |
| 3 · x<0 \|\| −x≤0 | 真；负x由左项保证，非负x的负数≤0。 |
| 4 · x>0 \|\| −x≥0 | 假；x=INT_MIN，机器取负仍为INT_MIN。 |
| 5 · x&0xF !=15 \|\| (x<<28)<0 | 按原印刷优先级假；!=优先于&，取x=0。若第一项补为(x&0xF)!=15，则机器模型下真：低四位非全1时左项真，全1时左移后最高位为1。 |
| 6 · (x>y)==(−x<−y) | 假；x=INT_MIN、y=0，左假右真。若取负可表示，负号会反转严格不等号。 |
| 7 · ~x+~y == ~(x+y) | 假；~x≡−x−1，两边差1；x=y=0时−2≠−1。 |
| 8 · (int)(ux−uy)==(y−x) | 假；x=1、y=0时1≠−1。左边对应x−y，顺序与右边相反。 |
| 9 · ((x>>2)<<2)≤x | 真；清低两位得4·floor(x/4)，不大于x；负数也向下取整。 |
| `10 · x*4+y*8 == (x<<2)+(y<<3)` | 真；两边是相同的模2³²乘加运算。 |
| 11 · x/4+y/8 == (x>>2)+(y>>3) | 假；x=−1、y=0，除法向零得0，算术右移得−1。 |
| `12 · x*y == ux*uy` | 真；位串乘积低32位相同，比较时左边转换为unsigned。 |
| 13 · x+y == ux+uy | 真；低32位相同，比较时左边转换为unsigned。 |
| `14 · x*~y+ux*uy == −x` | 真；统一到模2³²，~y+y≡−1，提取x得−x。 |


## 交换与别名：先看每条赋值的新状态

教材题13的三步为`*y=*x ^ *y; *x=*x ^ *y; *y=*x ^ *y;`。取不同对象x=5、y=3，第一步y=5 XOR 3=6，第二步x=5 XOR 6=3，第三步y=3 XOR 6=5，完成交换。每行都用刚更新的状态。若两个指针指同一个对象，第一步把它与自身异或，立即清零，之后无法恢复。因此题14对奇数长度数组执行到左右索引相等时，会将中间对象清零；用left<right停止便避开自身交换。


## 移位除法题的印刷前提

教材题21所给`if(y<0) y+3;`只计算表达式，没有把值存回y。若意图实现负数向零除4，应修为`y+=3`。例如−1：原句后仍−1，算术右移两位仍−1；修正后得到2，右移为0，与−1/4一致。题设另一路(x<<4)−x对应15x。答题先注明修正前提，再写M=15、N=4。
