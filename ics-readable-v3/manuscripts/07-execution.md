# 指令执行与处理器的基本组成

先修：指令、有效地址、函数栈与返回地址。课程第五章《程序的执行（简化版）》先追踪指令，再讨论进程。CPU是Central Processing Unit，中央处理器；本章把它视为能根据指令改变寄存器与内存的执行装置。

## 装入之后，为什么能找到第一条指令

链接把多个目标文件中的定义与引用连接，加载为程序建立运行所需的地址空间和映射，并把控制交给入口代码。入口代码完成必要初始化后才调用main，main通常并非处理器直接开始的第一条指令。关于目标文件的符号、重定位和动态链接，属于课程第四章；这里补充的是理解执行所需的接口。

程序计数器PC是Program Counter，保存下一步控制流所需的指令地址；IA-32对应EIP，Extended Instruction Pointer，扩展指令指针。假定当前指令地址为1000，长度3字节，普通顺序执行的后继地址为1003。若当前是跳转、调用或返回，后继地址便由它们决定。

PPT写PC加“1”时，“1”表示一条指令长度。x86指令变长，长度不能统一当一字节。课件中“假定最长四字节、一次读入IR”的叙述属于演示模型；真实x86指令最长可达15字节，现代处理器还有取指缓冲、译码与流水线，不能用该模型推断实际每周期取指数量。

## 把add拆成可观察操作

设当前指令`addl 4(%eax),%edx`，EAX=1000，EDX=7，内存1004起四字节存05、00、00、00。处理器先依据指令指针取得编码字节，译码确定32位加法、源为内存、目的为EDX。

随后计算有效地址1000+4=1004，从那里读四字节并按小端重组为5。运算部件计算7+5=12，把0000000C写入EDX，同时更新相应标志。若无异常且无控制流转移，后继指令地址取当前地址加本条长度。核对最终状态：EAX保持1000，源内存保持5，EDX由7变12；没有额外指令就不应修改其他通用寄存器。

ALU是Arithmetic Logic Unit，算术逻辑单元，执行加减与逻辑等运算。数据通路包含寄存器、运算部件和传送连接；控制器根据译码结果产生选择与写入控制。IR是Instruction Register，指令寄存器，在简单模型中暂存当前编码。RTL是Register Transfer Language，寄存器传送语言，可以用`EDX←EDX+M32[EAX+4]`概括本条功能。M32[a]表示从地址a读取32位，第一次使用时必须交代宽度。

概括式省略了先算地址和取数的时间顺序，只有在具体过程已走过之后才适合用来复查。它也没有宣称指令一定只需一个时钟周期。指令周期表示取出并执行一条指令的过程；实际时钟周期数取决于具体实现、数据依赖与内存等待。

## 异常与中断怎样改变后继

若地址对应的内存尚未就绪或不允许访问，处理器可能发生与当前指令相关的异常。若发生整数除零，也需要转交异常处理。外部设备完成操作或计时器到时，可产生中断请求。异常通常与当前指令同步，中断通常来自外部异步事件。

操作系统处理事件需要保存足够的恢复信息，再转到处理代码。不同事件恢复点不同：某些故障修复后重新执行原指令，某些陷阱从后继继续，严重错误可能终止进程。因此不能把所有事件一律画成“跳过去再回来”。系统调用是程序主动请求操作系统服务，使用体系结构规定的入口机制进入内核。

## 练习

题一：指令地址2000，长度5，没有跳转也没有异常，下一条在哪？若它是相对位移−12的跳转呢？

解答：顺序后继2005；相对跳转以2005为基准，加−12得1993。这里地址均按十进制给出。先确定基准，避免混用不同进制。

题二：上例add执行前，若内存1004改存FE、FF、FF、FF，EDX仍为7，结果是什么？

解答：源位串FFFFFFFE，有符号值−2，无符号值4294967294。32位相加保留5，CF=1，OF=0，SF=0，ZF=0。地址计算与数据运算分开，EAX仍1000。
