# 第二轮页面与脚本核验

构建输出：四个正式课程章2/3/4/5，20个小节，82个知识主题。目录与正文连续编号，不受源文件编号影响；原unit锚点保留。

content-integrity.py核对11份源文件渲染后的正文内容与网页一致（排除仅由构建器生成的编号），检查章和小节顺序、目录目标及唯一ID。DOM模拟已执行reader.js到初始化末尾，教材答案折叠、术语入口、主题保存与ABI查询无错误。新增答案使用内容标识，并带旧序号迁移表，避免插入题目后恢复到别题。

中文常规与粗体字形按新稿、目录和术语数据重新裁剪检查。第四章新增术语已加入全称及中文。

本地真实浏览器仍受运行环境限制；没有把DOM模拟结果当成手机、平板或Safari真机视觉验收。发布后以云端浏览器继续检查线上目录与功能；真实初学者试读与真机测试未开展。
