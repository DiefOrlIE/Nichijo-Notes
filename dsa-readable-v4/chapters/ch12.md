# 第 12 章　静态查找：成功和失败各要比较几次

> 来源：《DSA 6-Search Tree》静态查找部分。  
> 前置：顺序表、数组、时间复杂度和树。

## 12.1 “找得到”与“确定找不到”是两个任务 {#v4-search-mission}

在一份学生记录表中寻找学号 37，如果确实有这条记录，算法返回它的位置或对象；如果没有，程序也需要在有限时间内确定失败。静态查找指一组记录在查询过程中暂时不修改，动态查找则同时需要有效插删。查找算法必须说明“用哪个字段识别记录”，这叫**关键码**（key）。

如果数据没有排序，最直接的顺序查找需要逐项比较；一旦遇到目标便成功，否则走完整张表失败。如果数据已经有序，可以根据与当前项的大小关系跳过不可能的一部分，得到二分查找。

## 12.2 顺序查找：平均比较次数是怎么算出来的 {#v4-linear-search}

在数组 [5,9,14,21,37] 中从左到右查找 21，需要比较 5、9、14、21，共 4 次；查找 100 若不采用有序提前终止，需要比较全部 5 项。

假设查询**保证成功**，并且五个位置被查到的概率均为 1/5，那么平均比较次数为 <code>(1+2+3+4+5)/5=3</code>。一般 n 项且每项等概率，成功平均查找长度（Average Search Length，ASL）为 (n+1)/2。若题目给出不同概率，要按照 <code>ASL=Σ pᵢ·cᵢ</code> 加权，而不是简单平均。

还必须区分计数口径：如果顺序表带哨兵并允许额外比较，或给定不同失败区间，最终统计对象可能变化。考试先写明成功、失败时在哪里停止。

## 12.3 折半查找为何需要随机访问的有序数组 {#v4-binary-search}

给出有序数组 [2,4,7,9,13,18,22]，要找 13。取闭区间 [0,6] 的中点 mid=3，比较 a[3]=9，发现目标更大，因此可以排除 a[0..3]。新范围 [4,6] 的中点 mid=5，a[5]=18 更大，排除右半段 [5,6]；只剩 [4,4]，a[4]=13，第三次成功。

这个算法的正确性来自一个不变量：**如果目标存在于表中，它始终位于当前闭区间 [low,high] 内**。每次丢弃半边，都有有序性作为证据。如果数据未排序或中间位置无法 O(1) 访问，就不能直接套用 O(log n) 时间保证。

~~~cpp
#include <vector>
int binarySearch(const std::vector<int>& a,int target){
    int low=0,high=(int)a.size()-1;
    while(low<=high){
        int mid=low+(high-low)/2;
        if(a[mid]==target)return mid;
        if(a[mid]<target)low=mid+1;
        else high=mid-1;
    }
    return -1;
}
~~~

用 <code>low+(high-low)/2</code> 避免在大整数范围里计算 low+high 时可能溢出。返回 −1 是此处约定的失败标记；输入为空时 high=−1，循环不会执行，直接失败。

## 12.4 用一棵判定树手算 ASL {#v4-search-decision-tree}

对固定的有序数组，二分查找的每次比较可看成判定树的一个内部位置：第一次比较的中间项是根，比它小转左、大转右。要计算成功 ASL，统计每个关键码第一次被比较时所在的深度（如果根比较次数定义为 1）并按概率加权。

例如七项有序表，中点下标 3 首先被比较；左右子表各有三个，第二层下标 1 和 5；第三层为 0、2、4、6。等概率成功时比较次数分布为 1 个 1 次、2 个 2 次、4 个 3 次，因此 ASL=(1+2×2+4×3)/7=17/7。

失败查找发生在相邻关键码之间或两端的间隙，它们对应判定树的外部空位置。若题目说八个失败区间等概率，就分别计算查找落到空位置前比较了多少个关键码；若题目只要求最坏时间，可直接根据二分区间每轮约减半得到 Θ(log n)。

## 12.5 静态查找与动态查找如何选择 {#v4-search-choice}

如果记录集合不更新且已排序，二分查找可以稳定使用；如果插入、删除频繁，维持有序数组可能每次移动大量元素。二叉搜索树能通过比较大小沿链接进入左右子树，把查找和动态插删放进同一个结构；但普通 BST 的形状可能退化，下一章会具体看到这一缺点。

对题目中“时间”与“比较次数”，不要不加区分。比如在单链表中每轮比较的关键码数量可能不多，但找到所谓的中间结点需要沿链接前进，整体并不等于数组上的二分 O(log n)。
