# 第 08 章　树与二叉树：从一张图走到遍历和重建

> 来源：《DSA 5-Tree》（树、二叉树、遍历、重建）。  
> 前置：递归、栈和队列。  
> 目标：根据数组或遍历序列画出二叉树，逐步推导树的计数性质，写递归和非递归遍历。

## 08.1 为什么“分层关系”需要树 {#v4-tree-idea}

假设学校的课程目录从“数据结构”分为“线性表”“树”“查找”等章，每章又分成若干知识点。这个组织方式中，一个章节可能有多个下一级项目，而每个知识点只有一条通往最上级课程的路径。用单链表表达会很别扭，因为一个结点只能自然地表示一个“下一项”；树能表达一个对象拥有多个下属对象的关系。

树由根结点和零棵或多棵互不相交的子树构成。没有结点的叫空树，只有一个结点时该结点既是根也是叶子。有直接孩子的结点是父结点，没有孩子的结点是叶子。结点的**度**为孩子数，树的度为所有结点度数的最大值。路径长度按边数计算，若根深度定义为 0，它的孩子深度为 1。某个结点的高度可按到最深叶子的边数定义，也可按结点层数定义；考试必须和题面保持一致。

## 08.2 为什么二叉树中“左”和“右”不能随意交换 {#v4-binary-shape}

二叉树的每个结点有两个固定的孩子位置：左子树和右子树。一个根 A 只带左孩子 B 与只带右孩子 B，是不同的二叉树；即使结点值完全相同，也不能把它们当成一样的形状。

<pre class="diagram">只有左孩子        只有右孩子
    A                 A
   /                   \
  B                     B</pre>

满二叉树按约定每层全满；完全二叉树从上到下、从左到右填充到最后一层，最后一层结点靠左。后面“堆”需要完全二叉树的形状，因为它保证可以用一维数组紧凑存放而不出现内部空洞。普通二叉树可以通过数组保存，但要保留缺失的位置。

## 08.3 两个计数公式怎样从边数推出 {#v4-tree-count}

非空树有 n 个结点，恰有 n−1 条父子边，因为除根以外每个结点恰有一个父亲。对于二叉树，设 n₀、n₁、n₂ 分别为有 0、1、2 个孩子的结点数，则结点总数 n=n₀+n₁+n₂；从所有结点数出指向孩子的边共有 n₁+2n₂。所以：

<code>n₀+n₁+n₂−1=n₁+2n₂</code>，整理得 <code>n₀=n₂+1</code>。

因此二叉树若有 7 个度为 2 的结点，叶子必有 8 个。一般树最大度可大于 2，设 nₖ 为度为 k 的结点数，同样令边数相等：

<code>Σ(k nₖ)=Σnₖ−1</code>，可得 <code>n₀=1+Σ_{k≥1}(k−1)nₖ</code>。这道证明只用了两次计算同一批边，记住思路就能自行推回公式。

## 08.4 前序、中序、后序到底改变了什么 {#v4-tree-traversal}

设二叉树根 A，左孩子 B、右孩子 C；B 有左右孩子 D、E，C 有右孩子 F。三种深度优先遍历执行的仍是同样的递归：先处理左子树，再处理右子树。唯一不同的是“输出当前根”放在哪一步。

<pre class="diagram">       A
      / \
     B   C
    / \   \
   D   E   F
前序（根左 右）：A B D E C F
中序（左 根右）：D B E A C F
后序（左右 根）：D E B F C A
层序（按层）：    A B C D E F</pre>

~~~cpp
struct Node{char val;Node* left;Node* right;};
void preorder(Node* p){
    if(!p)return;
    std::cout<<p->val<<" ";
    preorder(p->left);
    preorder(p->right);
}
void inorder(Node* p){
    if(!p)return;
    inorder(p->left);
    std::cout<<p->val<<" ";
    inorder(p->right);
}
void postorder(Node* p){
    if(!p)return;
    postorder(p->left);
    postorder(p->right);
    std::cout<<p->val<<" ";
}
~~~

它们都访问 n 个结点一次，时间 Θ(n)；递归调用栈与高度 h 成正比，为 O(h)。若树退化成链，h=Θ(n)；若近似平衡，h=Θ(log n)。层序遍历需要队列保存已发现的结点，队列最大同时存放的结点数可能达到 O(n)。

## 08.5 给出前序和中序，怎样逐步画出唯一的二叉树 {#v4-tree-rebuild}

给前序序列 <code>A B D E C F</code>，中序序列 <code>D B E A C F</code>，假设结点值互异。前序首项是根 A；中序中 A 左边的三个值 D、B、E 一定属于左子树，右边 C、F 属于右子树。所以前序剩余序列的前 3 项 B、D、E 必然属于左子树，余下 C、F 是右子树。

继续左侧：左子树前序 B D E，首项根 B；它的中序 D B E 显示 D 在 B 左边、E 在 B 右边。右侧：前序 C F，根为 C；中序 C F 说明 C 没有左孩子而有右孩子 F。由此恢复上一节的树。

这个方法能成功的关键是**每次都用中序中根的位置确定左右子树大小**。只给前序与后序一般不够，例如根 A、结点 B：前序 AB、后序 BA 既可能是 A 的左孩子 B，也可能是右孩子 B。题目若含重复关键码，则还需要额外信息才能保证唯一性。

## 08.6 用完全二叉树位置存储一般二叉树：@ 不能压缩 {#v4-tree-array}

对于 0-based 完全二叉树编号，某结点下标 i 的左右孩子位置分别为 2i+1、2i+2，非根结点父位置为 (i−1)/2 向下取整。即使数组里用 @ 表示缺失结点，也不能把后面的非空结点往前挪，否则父子关系会改变。

例如数组 <code>[A,B,C,@,D,E,F]</code>：根 A，左右 B、C；B 的左孩子缺失、右孩子 D；C 有左右孩子 E、F。中序先处理 B→D，再 A，再 E→C→F，所以为 <code>B D A E C F</code>。

对于更长的输入 <code>[A,B,C,D,E,F,G,@,@,H,@,I,J,K,L]</code>，画图时要照位置规则将下标 9 的 H 放在下标 4 的 E 左边，把下标 11、12 的 I、J 放在下标 5 的 F 下方。对应中序为 <code>D B H E A I F J C K G L</code>。

## 08.7 为什么可以用显式栈代替递归遍历 {#v4-tree-stack}

递归中序遍历会先沿左孩子一路走到底，再返回访问父结点，然后向右走。显式栈可以模拟这件事：把尚未访问的祖先依次压栈；当左边走到底，弹出栈顶输出它，再转到其右孩子。这个循环保持的不变量是“栈内结点是其左侧已走完但自身尚未输出的祖先”。

~~~cpp
#include <stack>
#include <iostream>
void inorderIter(Node* root) {
    std::stack<Node*> st;
    Node* cur=root;
    while(cur || !st.empty()){
        while(cur){st.push(cur);cur=cur->left;}
        cur=st.top();st.pop();
        std::cout<<cur->val<<" ";
        cur=cur->right;
    }
}
~~~

如果题目要求**非递归镜像二叉树**，做法类似：把根压栈，每次弹出结点 p，交换 p->left 与 p->right，再把其存在的孩子压入栈；最终返回原来的 root，而不是循环最后处理的临时 p。每结点交换一次，时间 Θ(n)。
