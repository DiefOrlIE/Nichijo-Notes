# 第 02 章　线性表：数组存储与链式存储为什么不同

> 来源：《DSA 2-LinearList》（103 页）及《Lesson 3 Practice》链表填空。  
> 先修：第 00 章的指针和结点、第 01 章的计数方法。

## 02.1 从插入一位学生开始 {#v4-list-meaning}

班级名单原来是 [甲,乙,丙,丁]。如果新学生要排在乙之前，我们希望得到 [甲,新,乙,丙,丁]。不管放在数组还是链表中，名单的**逻辑顺序**都是同一个；它是一张线性表。把表记成 L=(a₀,a₁,…,aₙ₋₁)，每项最多一个直接前驱、最多一个直接后继。空表 n=0 是允许的。

最关键的设计问题是：为了这次插入，计算机实际上要移动多少数据？如果学生数据按顺序放在连续的存储单元里，就需要从末项向右搬；如果学生数据被分别放在结点里，只需改动相邻结点的链接。当然，链表找到“乙之前”这一位置也可能需要从头一路搜索。比较两种结构时必须把**定位位置**和**实际插入**拆开。

## 02.2 顺序表：为什么中间插入要从右往左移动 {#v4-seqlist}

设顺序表容量 6，当前四项 [2,4,6,8] 占下标 0–3，要在下标 1 插入 3。如果从左往右搬，先把 4 放到下标 2，会覆盖原来的 6；正确办法从最右边往左搬：

<pre class="diagram">原内容 [2,4,6,8,_,_]
8 向右 [2,4,6,8,8,_]
6 向右 [2,4,6,6,8,_]
4 向右 [2,4,4,6,8,_]
填 3   [2,3,4,6,8,_]</pre>

给定长度 n、0-based 插入位置 pos，只要 0≤pos≤n 且还没满，就将 j=n,n−1,…,pos+1 位置赋为旧的 j−1 位置，最后放入新项，长度加一。移动次数正好 n−pos；删除 pos 位置则让后续项左移 n−pos−1 次。定位下标 O(1)，最坏搬移 O(n)。

~~~cpp
#include <vector>
#include <stdexcept>
void insertAt(std::vector<int>& a,int pos,int x) {
    if(pos<0 || pos>(int)a.size()) throw std::out_of_range("pos");
    a.insert(a.begin()+pos,x);   // vector 底层移动后缀
}
void eraseAt(std::vector<int>& a,int pos) {
    if(pos<0 || pos>=(int)a.size()) throw std::out_of_range("pos");
    a.erase(a.begin()+pos);
}
~~~

这段代码利用了标准库；手写课堂顺序表时还要维护 capacity、length 和底层数组。注意 length 是当前元素个数，capacity 是已分配容量，两者不能混用，未使用的空槽不属于逻辑线性表。

## 02.3 单链表：顺序从地址链接中产生 {#v4-linkedlist}

单链表 2→4→6→8 的四个结点不必连续放在内存里。每个结点只记录数据和下个结点地址。要在 2 后面插入 3，先让新结点 next 指向原来 2 的后继 4，再让 2 指向新结点。只有两条链接改变，其余结点并未移动。

~~~cpp
struct Node{ int value; Node* next; };
void insertAfter(Node* p,int x) {
    if(!p) return;
    Node* q=new Node{x,p->next};
    p->next=q;
}
bool eraseAfter(Node* p) {
    if(!p || !p->next) return false;
    Node* q=p->next;
    p->next=q->next;
    delete q;
    return true;
}
~~~

时间是 O(1)，但前提是**已经有前驱指针 p**。如果只给“在第 i 项后面插入”，仍要从头走到 i，花费 O(i)。这正是“链表插入是 O(1)”这句口诀经常遗漏的条件。

## 02.4 头结点、尾指针与三种链表变化 {#v4-list-variants}

课程常用**带头结点**的单链表：一个不保存有效数据的哨兵结点先于第一个数据结点，空表时头结点 next 为 null。它的好处是删除第一个数据结点也有合法的“前驱”——头结点，因而代码可以少写一次特判。但“不带头结点”的 head 通常直接指首项，删除首项就必须更新 head 自身；判断代码时先确认是哪种约定。

循环链表令尾结点 next 指回头结点或首项，适合需要循环前进的问题。遍历终止条件要改成“再次遇到起点”，不能等 null。双向链表为每项增加 prev 指针，删除 q 时需连接 <code>q->prev->next=q->next</code> 和 <code>q->next->prev=q->prev</code>（边界处另行处理）。它用空间换来了沿反方向访问和已知结点局部删除的便利。

静态链表则用数组下标而不是真实地址作为链接值，表示“下一个结点放在哪个数组槽”。这对不方便使用动态指针的环境有意义，指针方向依然是逻辑方向，不能把下标顺序当成链表顺序。

## 02.5 头插、尾插与逆序：为何输入顺序可能变化 {#v4-list-build}

读到输入序列 1,2,3，每次头插都会把新结点放在原首项之前：第一次 [1]，第二次 [2,1]，第三次 [3,2,1]；尾插则得到 [1,2,3]。因此选择头插/尾插前必须看最终顺序要求。

逆置已有链表时，利用三个指针 prev、cur、next，先保存未处理链，再让当前结点朝已处理部分指回。第 00 章已经手工演示这个流程；本章把它作为可复用工具，并注意带头结点的链表要只逆置数据结点，再将头结点 next 接到新首项。

## 02.6 作业难点：原地合并两个升序链表，结果要降序 {#v4-list-merge}

两条链为 A:1→4→7，B:2→4→5。任务明确要求**复用原结点、不分配新数据结点**，并把所有值排成非递增顺序。普通合并会生成升序表，还要再逆置一次；更精练的办法是“反复取出当前最小值，然后头插到结果表前端”。

先取 1，结果 1；再取 2，结果 2→1；两条链当前都为 4，取 A 的 4 后结果 4→2→1，B 的 4 仍保留；再取 B 的 4，结果 4→4→2→1；之后取 5、7，最终 7→5→4→4→2→1。每次新结点不小于之前取过的值，因此头插到最前端仍是非递增。

~~~cpp
struct Node{int value;Node* next;};
Node* descendingMerge(Node* a,Node* b) {
    Node* result=nullptr;
    while(a || b) {
        Node* q;
        if(!b || (a && a->value<=b->value)) {
            q=a;
            a=a->next;
        } else {
            q=b;
            b=b->next;
        }
        q->next=result;  // 与原输入断开，接在结果最前
        result=q;
    }
    return result;
}
~~~

想检验代码是否会在其中一个输入提前用尽时报错，专门检查 <code>!b || (a && …)</code> 的求值顺序：C++ 的 <code>||</code> 和 <code>&&</code> 均短路；b 为空直接取 a，否则先保证 a 存在再读 a->value。时间 Θ(m+n)，辅助指针 Θ(1)。如果题目给的是带头结点的两条链，需要从 <code>firstA->next</code>、<code>firstB->next</code> 开始，并明确最后释放多余的头结点。

## 02.7 多项式相加：链表为什么适合稀疏项 {#v4-poly}

多项式 P(x)=3x⁵+2x²+4，可以只存非零项 (系数3,指数5)→(2,2)→(4,0)。若另一个 Q(x)=−3x⁵+7x³−2x²，按指数降序扫描两表，指数大的先输出；指数相等时相加系数。最高次 x⁵ 系数 3+(−3)=0，省略；接着输出 7x³；x² 的 2+(−2)=0，又省略；最后输出常数4，所以 P+Q=7x³+4。

这与合并有序链表的指针决策完全同源，只是“相等”分支从保留两个重复结点改为合成一个新系数，且新系数可能为 0。结构操作可迁移，题目语义仍要逐条核对。
