一、复习时究竟要练什么

你可能已经知道什么是链表、栈、二叉树或 AVL，但在一份没有提示算法名称的试卷上，仍然会遇到困难：题目给出一段数据，你应怎样选择结构？一个指针改向后，原来的后继还在吗？AVL 删除后，哪一层的高度变化需要继续向上传播？

解决这些问题，需要练习从题目条件还原操作规则。读到“原地合并两条升序链表，结果应当降序”时，先从“原地”“两个表头有序”“结果方向相反”三个限制推理：当前最小值可以从两表头之间选出；将取出的结点接到结果表头，就能逐步形成降序链。整个过程中需要分别保存两个未处理表头以及结果表头。先做出这套选择，再写代码，才有机会保证 Θ(m+n) 时间和 Θ(1) 额外结点空间。

另一道题可能要求“删除 BST 中拥有两个孩子的结点，必须使用中序后继”。此时应先进入右子树寻找最小项，随后将该项复制到删除位置，再在原后继位置删除它。对于 AVL，删除动作结束后还要检查回溯路径上的结点高度。若只写“找后继”，关键的回接与平衡修复仍然缺失。

因此，每道题都应追问四件事：有哪些对象与限制、下一步可以做什么、操作后状态怎样变化、最终如何检验结果。先理解这四个问题，再去记算法模板。

二、做题前必须确认的约定

举一个常见的误区：同样是 front=rear，采用牺牲一个槽位的循环队列通常表示空；采用 front/count 的实现还要看 count 的数值。答案与讲义相差一个下标时，先核对约定，再判断是否算错。还有一个容易被忽视的差别：新增 C、D 卷明确采用 BF＝左高－右高，而教学版的一些 AVL 例子采用右高－左高。判断 LL、RR、LR、RL 时须先画实际树形和高低关系，避免单凭平衡因子的正负号套另一套代码。

三、专项题与模拟卷怎样配合

先从三组专项题中选择自己的薄弱题型，每题的完整题干始终显示。请先在纸上写出结果、关键步骤和条件，再点击展开“思路与解答”。展开后的第一段提示适合真正卡住时使用；第二段推导和后续复核用于检查自己的过程。

五、如何把一次错题变成真正的进步

每做完一题，可按以下四档记录状态：

  • A：独立完成。 没有提示，结果正确，也能解释关键分支。
  • B：翻讲义后完成。 方法选对了，但某个定义、下标或边界想不起来。
  • C：看提示才能启动。 理解题意，却无法自己找到第一步，或中途卡住。
  • D：看答案后仍无法解释。 需要回到首次教学正文，找到最早出现的理解断点。

记录具体原因。例如“把 KMP 的 lps[j−1] 误写为 lps[j]”，比笼统地写“串匹配错了”有用；“把 AVL 的 RL 当成 RR，忘了先旋孩子”，也能直接指导下一题的复核。

隔一天再选一道数值变化、方法相同的题目独立完成。如果仍需要提示，就重读对应正文的关键推导；如果已经可以无提示完成，再把精力转到其他薄弱点。

指针与链表改接

第 1 题 · 读代码

题目。 在同一个 C++ 函数中依次执行 int a=4,b=6; int* p=&a; int*& r=p; r=&b; *p=9;。所有变量在执行期间均有效。请指出最后 a、b 的值以及 p 指向的对象，并解释 r=&b 修改了什么。

查看思路与解答

提示：r 是指针变量 p 的引用。

解答与推导：r=&b 将 p 改为指向 b，*p=9 修改 b。a=4，b=9。

易错处：把引用指针误解成复制了整数。

进一步理解：把对象与指针分开追踪：`r` 是 `p` 的别名，所以赋值后 `p` 指向 b；只有执行 `*p=9` 时才改变 b。可在纸上画两个整数方框和一根 `p` 箭头验证。

第 2 题 · 程序填空

题目。 在带有 next 指针的单链表中，指针 p 指向一个已存在的结点，x 指向一个尚未接入链表的新结点。请写出把 x 插到 p 与原后继之间的两条赋值语句，并解释赋值顺序为何重要。允许 p->next 原本为空。

查看思路与解答

提示：先存原后继，再改 p 的边。

解答与推导：x->next=p->next; p->next=x;。画图可验证原后继仍通过 x 可达。

易错处：先修改 p->next 导致旧后继地址丢失。

进一步理解：执行 `x->next=p->next` 时旧后继仍可通过 x 找到，第二句才把 p 与 x 接上。若顺序反过来，旧后继地址可能被覆盖。

第 3 题 · 手工模拟

题目。 有两条互不共享结点的升序单链表 A：1→3→8，B：2→3→6。只允许重接已有结点的 next 指针，不创建数据结点；请将两条链合并为非递增顺序，写出取结点的顺序和最终链表，分析时间与额外空间。

查看思路与解答

提示：每次取当前最小结点头插。

解答与推导：取出顺序 1,2,3,3,6,8；结果 8→6→3→3→2→1。时间 Θ(m+n)，额外空间 Θ(1)。

易错处：相等时跳过一条链的 3。

进一步理解：先由两个表头中选较小结点，依次摘取 1、2、3、3、6、8 并头插，因此输出顺序反过来成为 8→6→3→3→2→1。两个值为 3 的结点都要保留。

第 4 题 · 边界分析

题目。 单链表只保存指向后继的 next，现持有待删除尾结点的指针，手中没有头指针和前驱指针。解释为什么通常无法仅凭这个指针在 O(1) 时间内把尾结点安全地从链表中摘除；补充需要什么信息。

查看思路与解答

提示：尾结点没有后继可复制，也没有指回前驱的链接。

解答与推导：需要从头找到其前驱，更新前驱 next，再 delete 尾项；通常 Θ(n)，除非同时保存前驱或使用双向链表。

易错处：把非尾结点的复制后继技巧错误推广到尾结点。

进一步理解：由于尾结点没有可复制的后继，它无法沿 `next` 找到自己的前驱。没有头指针、双向前驱或外部索引时，缺失用于修改前驱链接的信息。

第 5 题 · 写算法

题目。 结点类型为 struct Node {int value; Node* next;};。写出 Node* reverse(Node* head) 的循环核心，要求原地逆置单链表（允许空链表），最后返回新的表头。说明 prev、cur、next 初值与每次操作顺序。

查看思路与解答

提示：保存未处理后半段。

解答与推导：next=cur->next; cur->next=prev; prev=cur; cur=next;，初始 prev=nullptr,cur=head，最后返回 prev；时间 Θ(n)，额外空间 Θ(1)。

易错处：交换了指向但没有保存 next。

进一步理解：关键不变量：`prev` 指向已逆置部分，`cur` 指向尚未处理部分第一个结点。每轮必须先保存原后继，最后再令 `cur=next`，否则尚未处理链表可能丢失。

第 6 题 · 结构选择

题目。 某学生档案需要频繁按下标读取第 i 条记录，仅偶尔在末尾追加，且预留或动态扩容的存储空间充足。应优先选择顺序表还是单链表？请用两种操作的时间代价解释。

查看思路与解答

提示：比较主要操作而不是只看插入复杂度。

解答与推导：顺序表；按索引 O(1)，有容量或动态扩容时尾追加通常均摊 O(1)。单链按第 i 项读取要沿链 O(i)。

易错处：笼统认为链表插入快所以任何时候都更好。

进一步理解：比较主要操作：顺序表按下标取元素 O(1)，单链表要从头向后走到第 i 项，代价 O(i)。若偶尔尾追加且可扩容，顺序表具备合适的均摊性能。

复杂度、证明与代码阅读

第 7 题 · 精确次数

题目。 设 n 为非负整数，cnt 初值为 0。运行 for(int i=0;i<n;i++) for(int j=0;j<=i;j++) cnt++;，请给出 cnt 的精确值及其关于 n 的渐进时间阶，并说明内层循环为何执行 i+1 次。

查看思路与解答

提示：第 i 轮内循环执行 i+1 次。

解答与推导：Σ(i+1) 从 i=0 到 n−1 为 n(n+1)/2，故 Θ(n²)。

易错处：把 <= 误看成 <，少算一整行。

进一步理解：第 i 次外循环的 j 值依次为 0…i，共 i+1 项，因此总数为 1+2+…+n=n(n+1)/2。n=0 时循环不执行，公式也得到 0。

第 8 题 · 渐进阶

题目。 设 n 为 2 的正整数次幂，递推式 T(n)=2T(n/2)+n，且 T(1)=Θ(1)。求总时间复杂度和递归调用栈的最大深度，并通过分层工作量解释结论。

查看思路与解答

提示：按层累计工作量。

解答与推导：每层总工作 n，共 log₂n 层，加叶子成本，时间 Θ(nlog n)；单条调用深度 Θ(log n)。

易错处：把总递归调用数当成栈空间。

进一步理解：在第 k 层有 2^k 个规模 n/2^k 的子问题，总工作量 2^k·(n/2^k)=n；非叶层数为 log₂n，叶层总工作仍 Θ(n)。空间只计单条活动调用路径。

第 9 题 · 渐进阶

题目。 设 n≥2，程序执行 for(int i=1;i<n;i*=3) for(int j=0;j<n;++j) work();，其中 work() 代价为 Θ(1)。求整个程序的时间复杂度，并说明外层执行次数。

查看思路与解答

提示：外层约 log₃n 轮，内层每轮 n 次。

解答与推导：Θ(nlog n)，对数底不同不影响阶。

易错处：看见两层就直接写 n²。

进一步理解：外层的 i 依次为 1、3、9…，达到 n 即结束，因此执行 Θ(log₃n) 轮；每轮内层又做 n 次常数工作，乘起来得到 Θ(nlog n)。

第 10 题 · 比较对象

题目。 递归程序在规模为 n 的一层先扫描 n 个元素，再调用一次规模 n−1 的子问题，T(n)=T(n−1)+n，且 T(1)=Θ(1)。求时间复杂度与最大递归深度。

查看思路与解答

提示：写等差和。

解答与推导：T(n)=Σ k=Θ(n²)，递归深度 Θ(n)。

易错处：一处递归调用并不保证线性时间。

进一步理解：展开递推得到 n+(n−1)+…+1，总成本是等差数列的和；同时，每次只打开一层规模减少 1 的调用，最大活动深度为 Θ(n)。

第 11 题 · 空间

题目。 一棵非空二叉树含 n 个结点，高度为 h（以根到最深叶的结点数计）。递归前序遍历依次访问全部结点，求时间复杂度与递归栈最大占用，并分别讨论链状树和高度平衡的情形。

查看思路与解答

提示：所有结点访问一次，同时活动帧数受高度约束。

解答与推导：时间 Θ(n)，递归栈空间 O(h)；链状树 h=Θ(n)，近似平衡树 h=Θ(log n)。

易错处：按树的总结点数直接写 O(n) 栈空间紧确界。

进一步理解：每个结点被访问一次，时间 Θ(n)。栈同时保存的是当前根到正在访问位置的一条路径，空间随高度 h 增长，而不需要同时存储所有 n 个调用。

第 12 题 · 证明

题目。 证明：任意非空二叉树中，度为 0 的结点数 n₀ 与度为 2 的结点数 n₂ 满足 n₀=n₂+1。请从父子边数的两个计数角度完成推导。

查看思路与解答

提示：从父子边总数计算两次。

解答与推导：n=n0+n1+n2，边数 n−1；各结点提供的边数为 n1+2n2；令相等解出 n0=n2+1。

易错处：只引用结论不给推导。

进一步理解：把每条父子边按父结点的孩子数计得到 n₁+2n₂，再按每个非根结点恰有一个父亲计得到 n₀+n₁+n₂−1。两式相等后消掉 n₁ 即可。

第 13 题 · 手工模拟

题目。 车厢只能按 1、2、3、4、5 的顺序进入一个容量足够的栈式旁线，每次可压入下一节或弹出当前栈顶。判断 3、2、5、4、1 能否作为完整出栈序列，并给出逐步入栈/出栈轨迹。

查看思路与解答

提示：写入/出操作事件。

解答与推导：I1 I2 I3 O3 O2 I4 I5 O5 O4 O1，可行。

易错处：只写一个“可”不给证明轨迹。

进一步理解：验证可行性时，模拟操作必须始终保持输入顺序固定，并保证每个 O 操作都弹出当时的栈顶。最后栈应为空且五节车厢全部输出。

第 14 题 · 后缀表达式

题目。 表达式 (A+B)*C−D/E 只有二元加减乘除与括号，乘除优先于加减。把它转换为后缀表达式，保留所有操作数与运算符的先后次序。

查看思路与解答

提示：括号优先，乘与除先于减。

解答与推导：A B + C * D E / -。

易错处：A+B 的加号必须在乘号之前输出。

进一步理解：先将 `(A+B)` 转成 `A B +`，与 C 相乘得到 `A B + C *`，另将 `D/E` 写成 `D E /`，最后输出减号。

第 15 题 · 求值

题目。 按从左到右扫描并使用操作数栈，计算后缀表达式 8 2 / 3 4 * + 5 - 的值。说明除法和减法弹出操作数时谁在左、谁在右。

查看思路与解答

提示：扫描操作数入栈，弹出时后弹为左操作数。

解答与推导：8/2=4，3*4=12，4+12−5=11。

易错处：8/2 写成 2/8。

进一步理解：遇到二元运算符，先弹出的是右操作数，后弹出的是左操作数。计算过程为 8/2=4、3×4=12、4+12=16、16−5=11。

第 16 题 · 一元运算

题目。 表达式 !(A&&B)||C 中，! 为一元逻辑非，&& 优先于 ||，变量均为单字符操作数。写出保持相同计算语义的后缀表达式。

查看思路与解答

提示：把逻辑非作为只取一个操作数的一元运算。

解答与推导：A B && ! C ||。

易错处：把 ! 与减法混成二元操作。

进一步理解：先对 A、B 执行 `&&`，再对这一布尔结果执行单目 `!`，最后才与 C 执行 `||`。后缀式的运算符位置体现真实求值顺序。

第 17 题 · 递归手算

题目。 函数 A 对非负整数按下式定义：A(0,n)=n+1；m>0 时 A(m,0)=A(m−1,1)；m>0、n>0 时 A(m,n)=A(m−1,A(m,n−1))。请逐层求出 A(2,2)，展示必要的嵌套调用。

查看思路与解答

提示：先得到 A(1,n)=n+2。

解答与推导：A(2,0)=3，A(2,1)=A(1,3)=5，A(2,2)=A(1,5)=7。

易错处：先外层计算，遗漏嵌套参数。

进一步理解：先由 A(0,n)=n+1 推出 A(1,n)=n+2，再推得 A(2,0)=3、A(2,1)=5、A(2,2)=7。嵌套式的内层返回值必须先计算。

第 18 题 · 递归证明

题目。 函数 f(0)=1，当 n>0 时返回 n*f(n−1)。请用数学归纳法解释它对所有非负整数 n 返回 n!，明确基例、归纳假设、归纳步骤和终止依据。

查看思路与解答

提示：数学归纳法对应函数结构。

解答与推导：基例 0!=1；归纳假设 f(n−1)=(n−1)!；归纳步 n*f(n−1)=n!，且 n 向 0 下降终止。

易错处：只写终止，不解释返回值怎样正确组合。

进一步理解：基例验证 `f(0)=0!`；归纳假设成立时 `f(n)=n·(n−1)!=n!`。每次递归使 n 下降，最终到达 0。

第 19 题 · 循环队列

题目。 一个长度 m=8 的循环队列只保存 front 和 rear，采用牺牲一格方案；front 指队首、rear 指下一空位，当前二者分别为 6、3。求有效元素个数和队列最大容量。

查看思路与解答

提示：(rear−front+m)%m。

解答与推导：队长 5，最大可存 m−1=7。

易错处：误用 front/count 方案的满容量公式。

进一步理解：由于 `rear` 指向下一空位且保留一个槽位，实际长度为 `(rear-front+m)%m=(3-6+8)%8=5`，最大容量为 m−1=7。

第 20 题 · 循环队列

题目。 一个长度 m=6 的循环队列采用 front、count 表示，允许使用全部六格；现 front=5、count=4。求下次成功入队将写入的数组下标、入队后 count 的值以及是否已满。

查看思路与解答

提示：(front+count)%m。

解答与推导：(5+4)%6=3；入队后 count=5，仍未满。

易错处：把 rear 当实体已存的索引。

进一步理解：本方案的写入下标就是 `(front+count)%m=(5+4)%6=3`；写入后 count=5，尚余一格。`rear` 无需作为独立状态存储。

第 21 题 · 手工模拟

题目。 长度 m=4 的 front/count 循环队列初始为空、front=0。依次入队 A、B、C、D，出队两次，再入队 E、F。要求写出最终 front、count 及从队首到队尾的元素顺序。

查看思路与解答

提示：front 在出队时回绕，count 减后再增。

解答与推导：front=2,count=4，按队首至队尾为 C,D,E,F。

易错处：入 E 时写下标 4 而不取模回绕到 0。

进一步理解：前三步填满数组，出队两次后 front=2、count=2，随后 E、F 写到下标 0、1。最终有效顺序 C、D、E、F，与物理下标的大小顺序无关。

第 22 题 · 代码填空

题目。 长度为 m 的循环队列以 front 指队首、count 指元素数，入队前已确认 count<m。请填写新元素 x 应写入 data 的哪个下标，以及写入后如何更新 count。

查看思路与解答

提示：下一空位离 front 恰 count 步。

解答与推导：data[(front+count)%m]=x; ++count;，前提是 count<m。

易错处：先增加 count 再定位导致跳过一格。

进一步理解：当 count<m 时，新元素应放到队首之后的第 count 个环形位置，故 `data[(front+count)%m]=x`，之后 `++count`。若先加 count，会错开一格。

第 23 题 · 应用

题目。 采用树的层序遍历（根先访问、各层从左到右），应把尚未访问的结点保存在队列还是栈中？用根 A、孩子 B/C、B 的孩子 D/E 的例子解释处理顺序。

查看思路与解答

提示：下一步应处理谁：最早发现的还是最近发现的？

解答与推导：先访问父层结点，再访问后面发现的子层结点，队列 FIFO 保证按层；栈更适合 DFS。

易错处：把栈操作顺序当作层序。

进一步理解：访问 A 后先把 B、C 入队。弹出 B 后队列变成 C、D、E，因此先访问 C 再访问 D/E，恰好形成按层展开的顺序。

第 24 题 · 均摊

题目。 用两个栈 in、out 实现 FIFO 队列：入队压入 in；出队时若 out 为空，就将 in 的元素依次搬过去。分析一次出队的最坏时间及一长串入队、出队操作的均摊时间，说明为何两者不同。

查看思路与解答

提示：每个元素被倒栈次数有限。

解答与推导：当输出栈空时一次搬移 n 项可能 Θ(n)，但每元素只被压入/弹出各栈常数次，整串 m 次操作总 O(m)，均摊 O(1)。

易错处：均摊与单次最坏写成同义。

进一步理解：单次搬移一整栈时可能需要 Θ(n)，但每个元素进入 `in`、转入 `out`、弹出 `out` 的次数都是常数，整段操作可摊销到每个元素上。

第 25 题 · 地址计算

题目。 二维数组 A 有 4 行、6 列，下标均从 0 开始，采用行优先连续存储。求 A[2][3] 相对于 A[0][0] 的元素偏移；若每项占 8 字节，再求字节偏移。

第 27 题 · 对称矩阵

第 29 题 · 快速转置

题目。 稀疏矩阵转置前的原矩阵有 4 列，按列号 0、1、2、3 统计非零项数得到 count=[2,0,1,3]，转置后的三元组按新行号从小到大连续存放。求每个新行的初始写入位置 start（0-based），说明空行如何处理。

解答与推导：起点为 0、1、2，共三处；j=lps[3]=3 继续，而不是清 0。

易错处：只搜索非重叠答案。

核对方法：长度为 4 的模式在长度为 6 的主串中可以从 0、1、2 开始。第一次完成匹配后让 j 变成 `lps[3]=3`，保留已经确认的三个字符重叠边界。

查看思路与解答

第 38 题 · 数组树

题目。 用数组 [A,B,C,@,D,E,F] 按 0-based 完全二叉树位置规则保存一棵普通二叉树，其中 @ 表示该位置没有结点，其他位置不得左移。画出实际父子关系，求中序遍历序列。

查看思路与解答

第 39 题 · 重建

题目。 一棵二叉树结点标签互异，已知前序序列 A B D E C F，中序序列 D B E A C F。请逐步重建二叉树并给出后序遍历，解释右子树中 F 的位置。

查看思路与解答

提示：前序首项为根，按中序左右区间切分。

解答与推导：A 为根；B 左右 D、E；C 的右孩子 F。后序 D E B F C A。

第 40 题 · 度数公式

题目。 某非空二叉树有 10 个度为 2 的结点，度为 1 的结点数量未知。请根据父子边数关系求其叶结点的准确个数，而仅仅给出下界。

查看思路与解答

提示：n0=n2+1 是等式。

解答与推导：恰有 11 个叶；度为 1 的结点数无关。

易错处：将其当作近似不等式。

核对方法：任何非空二叉树满足 n₀=n₂+1，因此 n₂=10 时叶数恰好是 11。度为 1 的结点数会在边数方程中抵消，不影响这个等式。

第 41 题 · 一般树证明

题目。 一棵非空一般树除叶结点外，度为 1、2、3 的结点数分别为 4、3、2，且没有度数大于 3 的结点。求叶结点数，并用父子边数验证结果。

查看思路与解答

提示：对总边数 n−1 两次计数。

解答与推导：n0=1+n2+2n3=1+3+4=8，结点总数 17，边数 16。

易错处：把只适合二叉树的公式 n0=n2+1 用于三叉结点。

核对方法：一棵 n 结点非空树有 n−1 条边。按孩子数计边得 n₁+2n₂+3n₃；与 n₀+n₁+n₂+n₃−1 相等后得 n₀=1+n₂+2n₃=8。

第 42 题 · 非递归算法

题目。 用显式栈遍历一棵普通二叉树，把访问到的每个结点的左右孩子指针交换，实现原地镜像。解释函数为什么应当保存并返回原始 root 指针，以及需要在什么时候把孩子加入栈。

查看思路与解答

提示：最后弹出的不必是根。

解答与推导：初始化保存 root，逐个弹出 p、swap(p->left,p->right)、压入存在的孩子，最后 return root；时间 Θ(n)。

易错处：丢失原根指针。

核对方法：每次弹栈后交换当前结点的 left/right，再将交换后仍存在的真实孩子压栈，两侧均只会访问一次。原根不必等于最后弹出的结点，应在开始时保存。

第 44 题 · 中序后继

题目。 在没有头结点的中序线索二叉树中，结点 p 的 right 指向一个真实右子树。求 p 的中序后继，应沿哪条路径寻找？如果右子树左侧还有真实孩子，为什么不能直接返回右孩子？

查看思路与解答

易错处：直接取右孩子，忽略其左分支。

核对方法：后继是右子树中按中序最先访问的结点，所以需要从 p.right 开始沿真实左孩子走到底。若直接取右孩子，可能跳过其左子树结点。

第 45 题 · 线索标志

易错处：沿着线索继续递归当成子树。

第 46 题 · 森林还原

第 47 题 · Catalan数

题目。 只区分二叉树左右形状、不区分结点标签，设 T₀=1、T₁=1、T₂=2，且 Tₙ=Σ(TₖTₙ₋₁₋ₖ)（k 从 0 到 n−1）。求 T₃，并写出根的左子树有 0、1、2 个结点时各贡献多少种形状。

第 48 题 · 方法选择

题目。 一般树采用 firstChild/nextSibling 组织结点。给定根 A，请描述遍历 A 的所有直接孩子的循环过程，要求说明起始指针、每轮输出内容与移动指针的规则，避免误入孙结点。

第 53 题 · Top-K

题目。 有 n=100000 个整数成绩陆续到来，只需要始终保留到目前为止最大的 k=20 个值，不要求这 20 项内部排好序。请选择一个维护空间为 O(k) 的堆方案，说明新值到来时的动作和总时间复杂度。

查看思路与解答

提示：候选中最小者应最快被淘汰。

解答与推导：容量 20 的最小堆；新项大于堆顶才替换。时间 O(nlog20)，额外空间 O(20)。

易错处：想取最大 k 项就误选最大堆。

核对方法：维护 20 项最小堆，堆顶就是当前入选集合中的最小者。新值不大于堆顶则舍弃，否则替换堆顶并下沉；时间 O(nlog20)，额外 O(20)。

第 54 题 · 复杂度

题目。 给定 n 项数组，采用自底向上 siftDown 建立最大堆。为什么虽然单个结点最多需要 O(log n) 次下沉，整个建堆仍可达到 Θ(n)？从各高度结点数量与下沉步数的关系解释。

查看思路与解答

提示：叶子没有下沉工作，低层结点多但可下沉短。

解答与推导：按高度 h 的结点数约 n/2^{h+1}，每项最多下沉 h，总代价 nΣh/2^h=Θ(n)。

易错处：对所有结点都按 log n 的最坏高度收费。

核对方法：高度为 h 的结点大致只有 n/2^(h+1) 个，其下沉工作不超过 O(h)，汇总为 O(n·Σh/2^h)=O(n)。绝大多数结点靠近叶层，几乎不需要下沉。

第 55 题 · 构造

题目。 四个字符的正权值分别为 2、3、5、8。用哈夫曼算法每轮取出最小两项、建立一个新结点并放回候选。列出全部合并权值，计算最终 WPL，并区分 WPL 与根权值。

查看思路与解答

提示：每步合并两最小，合并成本求和。

解答与推导：2+3=5；5+5=10；8+10=18，WPL=5+10+18=33。

易错处：生成的新 5 忘记加入候选集合。

核对方法：先合并 2+3=5，再合并原来的 5 与新生成的 5 得 10，最后 8+10=18。所有合并权值之和 5+10+18=33，即 WPL；18 是根权值。

第 58 题 · 前缀码

题目。 设计二进制前缀码时，把字符 A 编为 0、B 编为 01。判定这两个码字能否构成前缀无歧义编码，说明从左到右读比特时产生的歧义，并给出如何判断一般码字集合。

查看思路与解答

提示：A 的码字是 B 的前缀。

解答与推导：读到比特 0 时，不知道这是 A 的完整码字，还是 B 的开头，所以不满足前缀码条件。

易错处：只检查码字不同，忽略前缀关系。

第 59 题 · 证明

题目。 对一组正权值构造最优前缀二叉树。请解释为什么能够选择一棵最优树，使最小的两个权值放在最深的一对兄弟叶上；指出权值交换为什么不会增加加权路径长度。

查看思路与解答

提示：将低权与深处高权交换，不增加 WPL。

解答与推导：更深位置的路径乘数更大，小权占更深位置不比大权贵；可通过交换构造一棵同样不劣的最优树，再把该兄弟对合并成缩小的最优子问题。

易错处：用一次实验结果代替贪心正确性证明。

核对方法：把深处的大权与较浅的小权交换，WPL 变化由两项权值差与深度差决定：更小权值去更深处不会使成本变大。通过这种交换可把两最小权安放在一对最深兄弟叶上。

第 60 题 · 算法实现

第 61 题 · ASL

题目。 一个无序顺序表有 n=7 个互异关键码，顺序查找从第一项开始逐个比较，保证查找成功且每个关键码被查找的概率都为 1/7。求成功 ASL，并说明比较次数序列。

查看思路与解答

第 11 题 · 15 分

题目。 一棵二叉树存为指针结点 Node{key,left,right}。要求不用递归，对所有结点交换左右子树，返回原树的新根地址。给出完整 C++ 核心函数及时间和辅助空间复杂度。

查看思路、解答与评分点

解题思路：使用一个显式栈保存待处理结点，每次弹出后交换左右孩子，并将新的两个真实孩子压栈。

参考解答与评分：关键是用栈保存待处理结点，每次弹出后交换左右孩子（10 分），维护 root 并最终返回原 root（2 分）；每结点入出栈一次，时间 Θ(n)、栈空间 O(h)，其中 h 是二叉树高度（3 分）。

#include <stack>
#include <utility>
struct Node{int key;Node* left;Node* right;};
Node* mirror(Node* root){
    if(!root)return nullptr;
    std::stack<Node*> st;
    st.push(root);
    while(!st.empty()){
        Node* p=st.top();st.pop();
        std::swap(p->left,p->right);
        if(p->left)st.push(p->left);
        if(p->right)st.push(p->right);
    }
    return root;
}

若函数末尾直接 return p，p 是最后弹出的某结点，未必是根。使用上面的深度优先栈，未处理结点数量受每条路径上的未访问分支数约束，最坏 O(h)。

过程复核：循环中应把交换后存在的左、右孩子压入栈；它们的左右相对位置已交换，因此用新的指针即可。始终保存最初的 root 并返回它，不要返回最后一次弹出的临时结点。

查看思路与解答

使用后序遍历，在计算高度时同时检查平衡性。以－1 作为失衡信号；正常高度均非负。

def isBalanced(root):
    def height(node):
        if node is None:
            return 0
        lh = height(node.left)
        if lh == -1:
            return -1
        rh = height(node.right)
        if rh == -1 or abs(lh - rh) > 1:
            return -1
        return max(lh, rh) + 1

    return height(root) != -1

        q->next = A->next;
        A->next = q;
    }
}

每轮从剩余结点中取当前最小值并头插，得到非递增结果。循环覆盖一表先空、两表均空与重复值；B 的头结点保留且 next 为空。时间 O(m＋n)，额外空间 O(1)。

第 28 题 · 10 分 · 重复值边界查找：整体实现

题目。 给定非递减整数数组 a，长度 n≥0，编写 findRange(a,n,x)（Python 可省略参数 n），返回 x 的第一次和最后一次出现下标；不存在则返回 (-1,-1)。 要求最坏时间复杂度 O(log n)，额外空间 O(1)。不能调用现成二分查找函数，不能找到任意一个 x 后向两侧线性扫描。写出代码与复杂度。 例：[1,2,2,2,5]，x＝2，返回 (1,3)；空数组返回 (-1,-1)。C 可使用输出参数或自定义二元组结构。

评分：左边界查找 3 分；右边界查找 3 分；空数组和不存在情况 2 分；复杂度与边界收敛正确 2 分。

查看思路与解答

解题思路。 找第一个等于目标的下标时，命中也可能继续向左查；处理空数组与不存在的目标。

参考答案与评分。

采用左闭右开区间 [lo,hi)，分别查找首个大于等于 x 与首个大于 x 的位置。

def findRange(a, x):
    n = len(a)
    lo, hi = 0, n
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    first = lo
    if first == n or a[first] != x:
        return (-1, -1)

    lo, hi = first, n
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] <= x:
            lo = mid + 1
        else:
            hi = mid
    return (first, lo - 1)

左边界循环 3 分；右边界循环及转换为最后下标 3 分；空数组和不存在判断共 2 分；每轮严格缩小区间 1 分，时间 O(log n)、额外空间 O(1) 共 1 分。n＝0 时直接常数时间返回。 使用两个闭区间二分或保存答案的写法同样接受。避免以 x＋1 求右边界而在有限整数类型中溢出。

第 29 题 · 10 分 · 严格 AVL 树判定：整体实现

题目。 给定二叉链式存储的任意二叉树，编写 isAVL(root)，判断它是否同时满足： （a）任意结点的左子树所有关键字严格小于该结点，右子树所有关键字严格大于该结点； （b）每个结点左右子树的高度差不超过 1。 空树返回 true。结点值可重复，存在重复值时不满足严格 BST 要求；值域可覆盖有符号整数的全部范围。 要求时间 O(n)，辅助空间 O(h)，h 为树高。可用上下界、子树最大最小值或中序序列的递归状态；不得只比较直接孩子，不得把所有中序结果存入长度 n 的数组。不得用“关键字±1”构造界限而引入溢出。

// C/C++ node fields:
struct Node {
    int data;
    Node *left, *right;
};
// Python: node.data, node.left, node.right
// Empty child: NULL in C/C++, None in Python.

评分：全局 BST 条件 4 分；高度与平衡判定 3 分；边界、空树、重复值处理 1 分；时间与空间分析 2 分。

查看思路与解答

解题思路。 同时证明全局 BST 约束与逐结点高度平衡，避免只比较相邻父子键值。

参考答案与评分。

一次后序遍历同时携带祖先给出的严格上下界并计算高度。None 表示没有相应界限，避免用整数极值充当界限而误拒绝合法极值。

def isAVL(root):
    def visit(node, lower, upper):
        if node is None:
            return 0
        x = node.data
        if lower is not None and x <= lower:
            return -1
        if upper is not None and x >= upper:
            return -1

        lh = visit(node.left, lower, x)
        if lh == -1:
            return -1
        rh = visit(node.right, x, upper)
        if rh == -1 or abs(lh - rh) > 1:
            return -1
        return max(lh, rh) + 1

    return visit(root, None, None) != -1

全局 BST 条件共 4 分：正确传递上下界 2 分，严格比较与继承祖先约束 2 分。后序求高并检查每个结点 2 分，异常状态向上传递 1 分。空树、重复值、完整整数值域处理共 1 分。每个结点访问至多一次、时间 O(n) 为 1 分；递归栈 O(h) 为 1 分。

C 语言可用“是否存在界限”的标志加 int 值表示上下界；也可递归返回合法性、高度、是否为空及最小最大值。若使用更宽的整数类型，必须确保界限严格覆盖 int 全域，且不发生加减溢出。中序遍历携带前驱状态，同时求高的 O(h) 解法也接受。

典型反例：根 10，左孩子 5，5 的右孩子 12，右孩子 15。各直接父子比较看似合理，但 12 位于 10 的左子树且大于 10，因此不满足 BST。检查平衡性正确也无法弥补这一错误。
