#### 第 21 题 · 5 分 · 算法效率比较

**题目。** 以下两个算法均计算 1!＋2!＋…＋n!。假定乘法与加法均为常数时间，不考虑整数溢出。
```text
Algorithm I:
    p = 1; s = 0
    for i = 1..n:
        p = p * i
        s = s + p

Algorithm II:
    s = 0
    for i = 1..n:
        p = 1
        for j = 1..i:
            p = p * j
        s = s + p
```
（1）分别写出乘法的执行次数与时间复杂度。（3 分）
（2）说明算法 I 避免了哪类重复计算。（2 分）

<details class="question"><summary>查看思路与解答</summary>

**解题思路。** 两段算法都算阶乘；对比它们重复计算了哪些乘积，以及每个内循环的总次数。

**参考答案与评分。**

算法 I：乘法执行 n 次，时间 Θ(n)。（1 分）
算法 II：乘法执行 n(n＋1)/2 次，时间 Θ(n²)。（2 分，次数和阶各 1 分）
算法 I 保留上一轮的 (i－1)!，只乘 i 即得到 i!，避免每轮从 1 开始重复计算阶乘的前缀乘积。（2 分）
按题目采用单位代价模型，不讨论大整数位数增长。

</details>

#### 第 29 题 · 10 分 · 二叉树高度与平衡性：整体实现

**题目。** 使用二叉链式存储，编写 isBalanced(root)，判断每个结点的左右子树高度差是否均不超过 1。空树返回 true。本题只检查高度平衡性，无须检查二叉搜索树性质。
要求总时间复杂度 O(n)，并写出辅助空间复杂度。可自定义辅助函数，不得对每个结点重复计算整棵子树的高度。
```cpp
// C/C++ node fields:
struct Node {
    int data;
    Node *left, *right;
};
// Python: node.data, node.left, node.right
// Empty child: NULL in C/C++, None in Python.
```
评分：递归边界与高度计算 3 分；失衡识别与向上传递 4 分；总时间及空间分析 3 分。允许任何满足要求的等价算法。

<details class="question"><summary>查看思路与解答</summary>

**解题思路。** 让一次递归同时回传高度与平衡状态，避免为每个结点重复扫描子树。

**参考答案与评分。**

使用后序遍历，在计算高度时同时检查平衡性。以－1 作为失衡信号；正常高度均非负。
```python
def isBalanced(root):
    def height(node):
        if node is None:
            return 0
        lh = height(node.left)
        if lh == -1:
            return -1
        rh = height(node.right)
        if rh == -1 or abs(lh - rh) > 1:
            return -1
        return max(lh, rh) + 1

    return height(root) != -1
```
递归边界 1 分，子树高度获取与父结点高度 2 分；当前结点高度差判定 2 分，子树失衡向上传递并形成正确返回值 2 分；每个结点最多处理一次、时间 O(n) 为 2 分，递归栈 O(h) 为 1 分。最坏链状树的 h＝n。

C 语言可用返回整数的辅助函数，外层将结果与－1 比较；没有 bool 类型时使用 0/1 同样接受。显式后序栈方案如满足要求也接受。

易错点：只检查根；用“结点总数差”代替高度差；每个结点重算整棵子树高度导致最坏 O(n²)；把空树判断为不平衡。
