# 期中复习路线：把学过的知识真正用到陌生题里

> **适用对象**：已经阅读过相应正文章节，正在准备闭卷期中考试的同学。这里帮助你回忆方法、辨认题型、在有限时间里推演算法，并依据错题回到正文补足薄弱环节。  
> **模拟考试设置**：每套 120 分钟，总分 100 分。此为复习资料的训练安排，最终以教师公布的正式考试信息为准。  
> **范围说明**：本版沿用项目此前采用的“散列之前的课程内容”范围：绪论、线性表、栈和递归、队列、数组和串、KMP、树、堆、哈夫曼、静态查找、BST 与 AVL。集合、并查集和散列不进入模拟卷。如果教师最终要求考试只到普通二叉树，应跳过后续相关专题，并相应调整模拟卷的使用方式。这是资料沿用的范围假设，尚不能当作教师已经确认的公告。

## 一、复习时究竟要练什么

你可能已经知道什么是链表、栈、二叉树或 AVL，但在一份没有提示算法名称的试卷上，仍然会遇到困难：题目给出一段数据，你应怎样选择结构？一个指针改向后，原来的后继还在吗？AVL 删除后，哪一层的高度变化需要继续向上传播？

解决这些问题，需要练习**从题目条件还原操作规则**。读到“原地合并两条升序链表，结果应当降序”时，先从“原地”“两个表头有序”“结果方向相反”三个限制推理：当前最小值可以从两表头之间选出；将取出的结点接到结果表头，就能逐步形成降序链。整个过程中需要分别保存两个未处理表头以及结果表头。先做出这套选择，再写代码，才有机会保证 Θ(m+n) 时间和 Θ(1) 额外结点空间。

另一道题可能要求“删除 BST 中拥有两个孩子的结点，必须使用中序后继”。此时应先进入右子树寻找最小项，随后将该项复制到删除位置，再在原后继位置删除它。对于 AVL，删除动作结束后还要检查回溯路径上的结点高度。若只写“找后继”，关键的回接与平衡修复仍然缺失。

因此，每道题都应追问四件事：**有哪些对象与限制、下一步可以做什么、操作后状态怎样变化、最终如何检验结果**。先理解这四个问题，再去记算法模板。

## 二、做题前必须确认的约定

| 对象 | 先确认什么 | 最有用的核对动作 |
|---|---|---|
| 顺序表 | 位置从 0 还是 1 编号；插入第 i 项之前还是数组下标 i | 从末尾向前写移动轨迹 |
| 单链表 | 是否带头结点；能否新建数据结点；是否共享结点 | 改动 next 前保存旧后继 |
| 栈 | top 指最后有效项还是下一空位 | 写出空栈初值、压入和弹出的顺序 |
| 循环队列 | 浪费一格的 front/rear，还是满容量的 front/count | 先定义空与满，再计算取模 |
| 矩阵 | 下标、行列优先、上三角还是下三角 | 推出前面已经存储的整行/整列数 |
| KMP | LPS、−1 型 next 或 nextval 的具体定义 | 检查失配时代码修改哪个下标 |
| 二叉树数组 | @ 是否表示空位置，能否压紧占位 | 按父子下标还原结构 |
| 堆 | 逐项插入上浮还是自底向上筛选 | 写出每轮比较与交换的数组 |
| 哈夫曼 | 同权时选取顺序、左右边 0/1 约定 | 区分根权与合并成本之和 |
| BST | 重复关键码规则；前驱还是后继删除 | 重做中序遍历检查大小顺序 |
| AVL | 平衡因子的正负定义、旋转后高度是否继续变化 | 记录旋后新根和各侧高度 |
| ASL | 成功/失败事件、概率模型、比较次数定义 | 分别统计每个成功键或失败间隙 |

举一个常见的误区：同样是 front=rear，采用牺牲一个槽位的循环队列通常表示空；采用 front/count 的实现还要看 count 的数值。答案与讲义相差一个下标时，先核对约定，再判断是否算错。还有一个容易被忽视的差别：**新增 C、D 卷明确采用 BF＝左高－右高**，而教学版的一些 AVL 例子采用右高－左高。判断 LL、RR、LR、RL 时须先画实际树形和高低关系，避免单凭平衡因子的正负号套另一套代码。

## 三、专项题与模拟卷怎样配合

先从三组专项题中选择自己的薄弱题型，每题的**完整题干始终显示**。请先在纸上写出结果、关键步骤和条件，再点击展开“思路与解答”。展开后的第一段提示适合真正卡住时使用；第二段推导和后续复核用于检查自己的过程。

对于手工模拟题，得分经常落在中间状态。例如堆的两种建堆方法可能得到不同的合法最终数组；如果题目指定逐项插入，就必须按次序记录上浮结果。写出一个满足堆性质的最终数组，并不能自动替代题目要求的构造过程。

对于代码题，先写清指针、数组和返回值的语义，再测试空结构、单元素、正常输入和容易失败的边界。对于 BST 或 AVL 删除等会改变子树根的操作，尤其要确认递归结果是否回接给父结点。

完成专题训练后，建议按难度与题型依次使用四套模拟卷。原有 A、B 卷每套有 12 道综合题，适合练习解释、推导和长步骤演算；新增 C、D 卷来自你提供的完整模拟试卷，每套均有 10 道选择、10 道填空、6 道问答和 3 道代码题，能够检验换题型以后是否依然会独立解题。先做 A 卷，再做 C 卷基础巩固；检查错题后做 B、D 两套提高训练。每套建议严格计时 120 分钟，交卷后才打开答案。

## 四、120 分钟训练的参考安排

| 阶段 | 参考时间 | 任务 |
|---|---:|---|
| 浏览试卷 | 5 分钟 | 看清范围、题型和有无额外约定 |
| 概念与简答 | 15 分钟 | 给出定义、必要条件和反例 |
| 短状态模拟 | 25 分钟 | 追踪栈、队列、矩阵、KMP、堆 |
| 树与复杂度 | 25 分钟 | 树形重建、旋转、递推与 ASL |
| 写算法与读代码 | 40 分钟 | 指针改接、边界、返回值和复杂度 |
| 核对 | 10 分钟 | 重新遍历树、复核数组和重要数值 |

这是一个起点，可根据自己的速度和教师实际题型调整。某道长题完全卡住时，先在草稿上留下已确认条件与下一个问题，暂时处理其他题。返回时沿记录继续推理，可减少反复从头阅读题干的时间。

## 五、如何把一次错题变成真正的进步

每做完一题，可按以下四档记录状态：

- **A：独立完成。** 没有提示，结果正确，也能解释关键分支。
- **B：翻讲义后完成。** 方法选对了，但某个定义、下标或边界想不起来。
- **C：看提示才能启动。** 理解题意，却无法自己找到第一步，或中途卡住。
- **D：看答案后仍无法解释。** 需要回到首次教学正文，找到最早出现的理解断点。

记录具体原因。例如“把 KMP 的 lps[j−1] 误写为 lps[j]”，比笼统地写“串匹配错了”有用；“把 AVL 的 RL 当成 RR，忘了先旋孩子”，也能直接指导下一题的复核。

隔一天再选一道数值变化、方法相同的题目独立完成。如果仍需要提示，就重读对应正文的关键推导；如果已经可以无提示完成，再把精力转到其他薄弱点。

## 六、七天与十四天安排

| 七天安排 | 复习主线 | 当天至少应完成的任务 |
|---|---|---|
| 第 1 天 | 指针、链表、复杂度 | 指针改接题和复杂度计数题 |
| 第 2 天 | 栈、表达式、递归、队列 | 入出栈轨迹和循环队列取模状态 |
| 第 3 天 | 矩阵、字符串、KMP | 压缩下标推导和 LPS 回退 |
| 第 4 天 | 树、线索树、森林 | 前中序重建及孩子兄弟关系还原 |
| 第 5 天 | 堆、哈夫曼、查找、ASL | 两种建堆、WPL 和概率平均 |
| 第 6 天 | BST、AVL；模拟卷 A | 记录旋转、删除和限时答题错因 |
| 第 7 天 | 错题变式；新增模拟卷 C | 用完整选择、填空、问答、代码结构检验知识迁移 |

若有十四天，可用前七天补基础，第 8—9 天复做第一次卡住的变式，第 10 天做 A 卷，第 11 天做 C 卷并复盘，第 12 天做 B 卷，第 13 天做新增 D 卷，第 14 天集中复盘四卷中重复出现的失误。四套卷均为 120 分钟训练，若时间不够，应优先完整做完其中一套，并认真核对解题过程。时间有限时，优先保证亲手写出几道题的完整解题过程；只读答案容易高估自己在考场独立启动算法的能力。

本专题与教学版互相支持：遇到陌生概念时回到教学版学习具体操作；已懂概念但做题慢时，继续在这里练方法选择与状态追踪。
