```c

    for (int j = 0; j < i; ++j)
        ++s;
```


- **A.** Θ(log n)　　

- **B.** Θ(n)　　

- **C.** Θ(n log n)　　

- **D.** Θ(n²)

#### 第 21 题 · 5 分 · KMP 匹配过程

**题目。** 主串 T＝"abababac"，模式串 P＝"ababac"。定义 pi 为最长相等真前后缀长度数组。采用以下流程：
```text
j = 0
for each character T[i]:
    while j > 0 and T[i] != P[j]:
        j = pi[j-1]
    if T[i] == P[j]:
        j += 1
    if j == len(P):
        report i-len(P)+1
        j = pi[j-1]
```
（1）写出 P 的 pi 数组。（2 分）
（2）写出处理 T[5] 时 j 的回退及重新匹配过程，并给出唯一匹配的起始下标。（2 分）
（3）解释该过程中主串下标为何不必回退。（1 分）

<details class="question"><summary>查看思路与解答</summary>

**解题思路。** 把匹配到的前缀与主串当前字符逐位对齐，回退 j 后保持主串当前位置。

**参考答案与评分。**

P＝ababac 的 pi 为 [0,0,1,2,3,0]。（2 分）
处理 T[5] 前，已匹配 ababa，j＝5。T[5]＝b 与 P[5]＝c 失配，令 j＝pi[4]＝3；随后 T[5] 与 P[3]＝b 匹配，j 增为 4。继续处理 T[6]＝a、T[7]＝c，达到 j＝6，匹配起点 7－6＋1＝2。（回退与重配 1 分，起点 1 分。）
已匹配前缀的后缀可由 pi 找到与模式前缀相等的部分；回退只改变模式位置，主串当前位置仍可用于比较，已经扫描过的主串字符无需重新读取。（1 分）

#### 第 23 题 · 5 分 · 堆的建立与删除

（2）删除堆顶，以末元素补根并筛选，写出结果数组。（1 分）
（3）说明自底向上建堆时间为 O(n) 的原因。（1 分）

<details class="question"><summary>查看思路与解答</summary>

**解题思路。** 建堆时从最后一个非叶结点向根筛选；删除堆顶时用末尾值下沉。

#### 第 28 题 · 10 分 · 重复值边界查找：整体实现

**题目。** 给定非递减整数数组 a，长度 n≥0，编写 findRange(a,n,x)（Python 可省略参数 n），返回 x 的第一次和最后一次出现下标；不存在则返回 (-1,-1)。
要求最坏时间复杂度 O(log n)，额外空间 O(1)。不能调用现成二分查找函数，不能找到任意一个 x 后向两侧线性扫描。写出代码与复杂度。
例：[1,2,2,2,5]，x＝2，返回 (1,3)；空数组返回 (-1,-1)。C 可使用输出参数或自定义二元组结构。

评分：左边界查找 3 分；右边界查找 3 分；空数组和不存在情况 2 分；复杂度与边界收敛正确 2 分。

<details class="question"><summary>查看思路与解答</summary>

**解题思路。** 找第一个等于目标的下标时，命中也可能继续向左查；处理空数组与不存在的目标。

**参考答案与评分。**

采用左闭右开区间 [lo,hi)，分别查找首个大于等于 x 与首个大于 x 的位置。
```python
def findRange(a, x):
    n = len(a)
    lo, hi = 0, n
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    first = lo
    if first == n or a[first] != x:
        return (-1, -1)

    lo, hi = first, n
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] <= x:
            lo = mid + 1
        else:
            hi = mid
    return (first, lo - 1)
```
左边界循环 3 分；右边界循环及转换为最后下标 3 分；空数组和不存在判断共 2 分；每轮严格缩小区间 1 分，时间 O(log n)、额外空间 O(1) 共 1 分。n＝0 时直接常数时间返回。
使用两个闭区间二分或保存答案的写法同样接受。避免以 x＋1 求右边界而在有限整数类型中溢出。

#### 第 29 题 · 10 分 · 严格 AVL 树判定：整体实现

**题目。** 给定二叉链式存储的任意二叉树，编写 isAVL(root)，判断它是否同时满足：
（a）任意结点的左子树所有关键字严格小于该结点，右子树所有关键字严格大于该结点；
（b）每个结点左右子树的高度差不超过 1。
空树返回 true。结点值可重复，存在重复值时不满足严格 BST 要求；值域可覆盖有符号整数的全部范围。
要求时间 O(n)，辅助空间 O(h)，h 为树高。可用上下界、子树最大最小值或中序序列的递归状态；不得只比较直接孩子，不得把所有中序结果存入长度 n 的数组。不得用“关键字±1”构造界限而引入溢出。
```cpp
// C/C++ node fields:
struct Node {
    int data;
    Node *left, *right;
};
// Python: node.data, node.left, node.right
// Empty child: NULL in C/C++, None in Python.
```
评分：全局 BST 条件 4 分；高度与平衡判定 3 分；边界、空树、重复值处理 1 分；时间与空间分析 2 分。

<details class="question"><summary>查看思路与解答</summary>

**解题思路。** 同时证明全局 BST 约束与逐结点高度平衡，避免只比较相邻父子键值。

**参考答案与评分。**

一次后序遍历同时携带祖先给出的严格上下界并计算高度。None 表示没有相应界限，避免用整数极值充当界限而误拒绝合法极值。
```python
def isAVL(root):
    def visit(node, lower, upper):
        if node is None:
            return 0
        x = node.data
        if lower is not None and x <= lower:
            return -1
        if upper is not None and x >= upper:
            return -1

        lh = visit(node.left, lower, x)
        if lh == -1:
            return -1
        rh = visit(node.right, x, upper)
        if rh == -1 or abs(lh - rh) > 1:
            return -1
        return max(lh, rh) + 1

    return visit(root, None, None) != -1
```
全局 BST 条件共 4 分：正确传递上下界 2 分，严格比较与继承祖先约束 2 分。后序求高并检查每个结点 2 分，异常状态向上传递 1 分。空树、重复值、完整整数值域处理共 1 分。每个结点访问至多一次、时间 O(n) 为 1 分；递归栈 O(h) 为 1 分。

C 语言可用“是否存在界限”的标志加 int 值表示上下界；也可递归返回合法性、高度、是否为空及最小最大值。若使用更宽的整数类型，必须确保界限严格覆盖 int 全域，且不发生加减溢出。中序遍历携带前驱状态，同时求高的 O(h) 解法也接受。

典型反例：根 10，左孩子 5，5 的右孩子 12，右孩子 15。各直接父子比较看似合理，但 12 位于 10 的左子树且大于 10，因此不满足 BST。检查平衡性正确也无法弥补这一错误。

</details>
