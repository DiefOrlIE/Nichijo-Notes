# AVL 树：四类旋转、插入和删除
<!-- id: ch14 | source: 6-Search Tree，第 55—100 页 -->
AVL 在 BST 的有序规则上再限制高度。先看插入、删除让哪一侧变高或变矮，再用局部旋转恢复平衡；尤其要完整追踪删除后的祖先更新。


## 为什么 BST 需要 AVL：高度与平衡因子 {#ch14-balance}
普通 BST 只保证键大小，仍可能因为有序插入退化成链。AVL 在每个结点维护左右子树高度差的绝对值不超过 1。本课件定义 bf=右高−左高，所以 bf=+2 表示右边太高、bf=−2 表示左边太高，先判断符号才能决定旋转方向。

<p><strong>本节能力任务：</strong>理解 bf=右高−左高，绝不和另一种符号约定混淆。</p>
<div class="lesson-body">
<p><strong>AVL 树</strong>是满足任意结点左右子树高度差绝对值≤1 的 BST。课件定义平衡因子 <code>bf=height(right)−height(left)</code>。正常结点的 bf∈{−1,0,+1}；当绝对值达到 2，就要调整。</p>
<p>BST 在持续有序插入时会退化为链，搜索可从 O(log n) 变成 O(n)。AVL 要求每个结点都保持高度平衡。旋转改变少数几条父子链接，又保持中序顺序，因此能同时保留 BST 的搜索性质和较小树高。</p><div class="diagram"><pre class="tree-diagram">插入 10,20,30 前：
10 (bf=+2)
  \
   20 (bf=+1)
     \
      30
插入后通过左旋：
     20
    /  \
   10  30</pre></div>
<p>若叶结点高度为 1、空树高度为 0，则 <code>h(p)=1+max(h(p.left),h(p.right))</code>。例如右高 3、左高 1 时 bf=+2，右边过高；左高 4、右高 2 时 bf=−2，左边过高。</p><div class="question"><div class="qtitle">题：结点左右子树高度分别为 4、3，按本课程约定 bf 是多少？</div><details id="q14-1"><summary>展开答案与推导</summary><div class="answer">bf=3−4=−1，仍平衡。若某资料写成 +1，很可能采用左高−右高的相反约定。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>AVL 高度 O(log n)：设高度 h 的 AVL 最少结点数 N(h)，使结点数最小可让左右高度分别为 h−1、h−2，因此 <code>N(h)=1+N(h−1)+N(h−2)</code>，取 N(0)=0、N(1)=1。它与 Fibonacci 增长同阶，从而 h=O(log n)。</p>
</details>

## LL、RR、LR、RL 四种失衡与旋转 {#ch14-rotations}
从首次失衡结点往偏高方向走两步：左左 LL、右右 RR 是直线形，可以单旋；左右 LR、右左 RL 是折线形，要先旋孩子再旋祖先。旋转保持中序大小顺序，因为夹在两个旋转结点之间的子树仍被接到正确的中间位置。

<p><strong>本节能力任务：</strong>看到失衡结点及较高孩子的方向，就能判型并独立画出旋转结果。</p>
<div class="lesson-body">
<p><strong>LL</strong>：左孩子的左侧增高，失衡结点右旋；<strong>RR</strong>：右孩子的右侧增高，左旋；<strong>LR</strong>：左孩子的右侧增高，先左旋孩子再右旋祖先；<strong>RL</strong>：右孩子的左侧增高，先右旋孩子再左旋祖先。</p>
<p>记忆方式：两个字母是“从最先失衡结点往下走的两步方向”。LL/RR 三个关键结点排成直线，一次反方向单旋；LR/RL 呈折线，需要先拉直，再整体旋转。旋转不会凭空增加或删除结点。</p><div class="diagram"><pre class="tree-diagram">LL:         RR:         LR:         RL:
 30           10           30           10
 /              \          /              \
20              20        10               30
/                 \         \              /
10                 30       20            20

四者平衡后都可得到：
      20
     /  \
    10  30</pre></div>
<p>旋转要保留子树：右旋时令 y=x.left、T=y.right，再使 y.right=x、x.left=T，返回 y。T 的所有键介于 y 与 x 之间，仍在 BST 应有的位置。左旋完全对称。</p><pre><code>struct AVLNode{
    int key, height=1;
    AVLNode *left=nullptr,*right=nullptr;
    explicit AVLNode(int x):key(x){}
};
int H(AVLNode* p){return p?p-&gt;height:0;}
int BF(AVLNode* p){return p?H(p-&gt;right)-H(p-&gt;left):0;}
void update(AVLNode* p){
    if(p)p-&gt;height=1+std::max(H(p-&gt;left),H(p-&gt;right));
}
AVLNode* rotateRight(AVLNode* x){
    AVLNode* y=x-&gt;left;
    AVLNode* middle=y-&gt;right;
    y-&gt;right=x; x-&gt;left=middle;
    update(x);update(y);return y;
}
AVLNode* rotateLeft(AVLNode* x){
    AVLNode* y=x-&gt;right;
    AVLNode* middle=y-&gt;left;
    y-&gt;left=x;x-&gt;right=middle;
    update(x);update(y);return y;
}</code></pre><div class="question"><div class="qtitle">题：插入 30、10、20，哪个结点首次失衡？做哪类旋转？</div><details id="q14-2"><summary>展开答案与推导</summary><div class="answer">30 首次失衡；从 30 向左到 10，再向右到 20，属于 LR。先对 10 左旋，再对 30 右旋，20 成根。</div></details></div><div class="question"><div class="qtitle">题：插入 10、30、20，应该怎样旋转？</div><details id="q14-3"><summary>展开答案与推导</summary><div class="answer">RL，先对 30 右旋，再对 10 左旋，根变 20。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>严谨检查旋转对 BST 有序性：设 LL 中 x 左孩子 y，子树依次满足 <code>T₁&lt;y&lt;T₂&lt;x&lt;T₃</code>。右旋后 y 为根、x 为右孩子，T₂ 变成 x 的左子树；所有不等式保持不变。双旋同理由连续两次合法单旋组成。</p>
</details>

## AVL 插入：从插入点回溯、首个失衡祖先 {#ch14-insert}
插入时从根按 BST 规则走到空位，再沿原路径回溯更新高度。遇到第一个平衡因子超出 ±1 的祖先，按更高孩子的方向选择单旋或双旋。关键是旋转后要返回新的局部根给上层，原始 root 也可能改变。

<div class="lesson-body">
<p>插入新键时先执行 BST 式插入；回溯时依次更新高度及 bf。若 bf=−2 或 +2，观察偏高孩子的 bf，决定单旋或双旋。完成第一次必要调整后，此次插入通常可以结束。</p>
<p>课件使用 bf=右−左：当 p.bf=−2（左高），若左孩子 bf≤0，右旋（LL）；若左孩子 bf>0，先左后右（LR）。当 p.bf=+2（右高），若右孩子 bf≥0，左旋（RR）；若右孩子 bf<0，先右后左（RL）。插入情况下失衡孩子的 bf 常为 ±1。</p>
<pre><code>AVLNode* rebalance(AVLNode* p){
    update(p);
    if(BF(p)&lt;-1){                 // 左侧高
        if(BF(p-&gt;left)&gt;0)         // LR
            p-&gt;left=rotateLeft(p-&gt;left);
        return rotateRight(p);   // LL 或完成 LR
    }
    if(BF(p)&gt;1){                  // 右侧高
        if(BF(p-&gt;right)&lt;0)        // RL
            p-&gt;right=rotateRight(p-&gt;right);
        return rotateLeft(p);    // RR 或完成 RL
    }
    return p;
}
AVLNode* insertAVL(AVLNode* p,int x){
    if(!p)return new AVLNode(x);
    if(x&lt;p-&gt;key)p-&gt;left=insertAVL(p-&gt;left,x);
    else if(x&gt;p-&gt;key)p-&gt;right=insertAVL(p-&gt;right,x);
    else return p; // 不存重复键
    return rebalance(p);
}
// 依赖上一节 H、BF、update、rotateLeft/Right。</code></pre><p>这套“返回新的子树根”写法避免显式 parent 指针。当某个旋转改变局部根时，上层递归用返回值更新对应孩子指针；根节点的调用也要接收返回值。</p><div class="question"><div class="qtitle">题：插入顺序 3,2,1,4，最后 AVL 树是什么形状？</div><details id="q14-4"><summary>展开答案与推导</summary><div class="answer">前三个形成 LL，右旋后 2 为根，左 1、右 3；插入 4 成为 3 的右孩子。最终根 2，左 1，右 3（其右为 4），仍平衡。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>插入一次的搜索沿一条路径 O(log n)，旋转最多常数次（单旋或双旋），更新高度沿路径 O(log n)。插入完成后首个失衡祖先的子树高度会恢复到插入前的高度，因此更上层祖先无需继续旋转，但代码仍可以回溯更新高度。</p>
</details>

## AVL 删除：为何可能连续调整到根 {#ch14-delete}
删除某个叶子会让其一条祖先路径上的子树高度降低。某个祖先若从平衡因子 ±1 变成 0，它所在子树高度也可能降低，变化会继续传到更高祖先；因此 AVL 删除可能发生多次平衡调整，不能在首次旋转后无条件结束。

<p><strong>本节能力任务：</strong>逐层判断 shorter，专门理解失衡子树根 bf=0 时为何旋转后高度不下降。</p>
<div class="lesson-body">
<p>AVL 删除先按 BST 删除：若结点有两孩子，用中序前驱/后继替换，再删除替代结点。之后沿递归返回路径更新高度并恢复平衡。与插入相比，<strong>删除后可能需要在多个祖先处旋转</strong>。</p>
<p>删除会让某棵子树的高度减 1。原先 bf=0 的父结点变为 ±1，整体高度保持不变，可停止向上；原先 bf=±1 的较高子树被缩短后变为 0，整体高度减 1，要继续向上；若原先较矮子树被缩短，则 bf 变为 ±2，必须旋转。</p><div class="diagram"><pre class="tree-diagram">删除让 p 的左侧缩短 → p.bf=+2
若右孩子 q 的 bf ≥ 0：左单旋
若右孩子 q 的 bf &lt; 0：先对 q 右旋，再对 p 左旋
对称地，左侧过高时按 q 的 bf 选择右旋或 LR</pre></div>
<p><strong>特殊考点：失衡孩子 q 的 bf=0。</strong> 例如 p 的右侧高 2 层且 q 左右一样高，删除 p 的左边后对 p 左旋。旋转后新子树整体高度通常与删除前相同，因而 <code>shorter=false</code>，可以停止向上。若 q.bf=+1（同向），单旋后高度确实下降，需继续检查祖先；q.bf=−1（反向），双旋后也可能继续下降。</p><div class="question"><div class="qtitle">题：删除后 p.bf=+2，q=p.right，q.bf=−1，应该怎么旋转？</div><details id="q14-5"><summary>展开答案与推导</summary><div class="answer">RL：先对右孩子 q 做右旋，再对 p 做左旋。</div></details></div><div class="question"><div class="qtitle">题：删除使某结点 bf 从 0 变为 +1，是否应继续沿祖先更新平衡？</div><details id="q14-6"><summary>展开答案与推导</summary><div class="answer">不用继续传播高度缩短，因为该结点子树整体高度没有变化（按经典 shorter 状态机语义）。</div></details></div>
</div>

<h4>AVL 删除的特殊情况：失衡孩子平衡因子为 0</h4>
<p>考虑 BST/AVL 树，根 2，左孩子 1，右子树根 4，4 的左右孩子分别是 3 和 5。删除叶子 1 后，结点 2 左高从 1 变为 0，右高仍为 2，按本课件 <code>bf=右高−左高</code>，得到 bf=+2；右孩子 4 的 bf=0。</p>
<div class="diagram"><pre>删除前：         删除 1 后：      对 2 左旋后：
   2                2                 4
  / \                \               / \
 1   4                4             2   5
    / \              / \             \
   3   5            3   5             3</pre></div>
<p>旋转后新子树的高度与删除前一样，因而这次高度缩短不必继续传播到更高祖先。这是旧式用 <code>shorter</code> 标志实现 AVL 删除时必须认识的分支。更容易写对的现代递归版本会在回溯时重新计算高度并调用 rebalance，自动处理这一特殊情形。</p>

<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>使用存储实际高度的递归版本可以免去手工维护 shorter：每次递归删结点返回时 recompute 高度并调用 rebalance；若高度未变，后续祖先的值自然保持不变。时间仍为 O(log n)，局部旋转次数在一次删除中可能多于一次。</p>
</details>

## 完整 AVL 删除代码、边界与例题 {#ch14-deletecode}
完整删除算法先执行 BST 删除，找到双孩子结点时以中序后继替换并在原位置删除后继；随后每层返回都重新计算左右子树高度，必要时旋转，再返回新的根。单独跟踪一个删除根的例子，可以验证为何调用者必须写 root=eraseAVL(root,key)。

<div class="lesson-body">
<p>删除代码约定：返回操作后新的子树根；删除不存在的键则原树不变；有两个孩子时采用右子树最小值作为后继。</p>
<p>算法伪代码：<code>delete(root,x)</code> → 比较 x 与 root.key，递归进入一侧；若找到结点，按 BST 规则替换或释放；若子树仍存在，更新高度 → 检查 bf → 可能旋转 → 返回新的根。</p>
<pre><code>AVLNode* minNode(AVLNode* p){
    while(p&amp;&amp;p-&gt;left)p=p-&gt;left;
    return p;
}
AVLNode* eraseAVL(AVLNode* p,int x){
    if(!p)return nullptr;
    if(x&lt;p-&gt;key)p-&gt;left=eraseAVL(p-&gt;left,x);
    else if(x&gt;p-&gt;key)p-&gt;right=eraseAVL(p-&gt;right,x);
    else{
        if(!p-&gt;left||!p-&gt;right){
            AVLNode* child=p-&gt;left?p-&gt;left:p-&gt;right;
            delete p;return child;
        }
        AVLNode* succ=minNode(p-&gt;right);
        p-&gt;key=succ-&gt;key;
        p-&gt;right=eraseAVL(p-&gt;right,succ-&gt;key);
    }
    return rebalance(p); // 必须接住旋转后的新根
}
void clearAVL(AVLNode* p){
    if(!p)return;
    clearAVL(p-&gt;left);clearAVL(p-&gt;right);delete p;
}
int main(){
    AVLNode* root=nullptr;
    for(int x:{16,3,7,11,9,26,18,14,15})
        root=insertAVL(root,x);
    root=eraseAVL(root,11);
    clearAVL(root);
}
// 编译时与前面声明/实现置于同一翻译单元，
// 并加 #include &lt;algorithm&gt; 和 #include &lt;initializer_list&gt;。</code></pre><div class="question"><div class="qtitle">题：为什么必须写 <code>root=eraseAVL(root,x)</code>，不能只写 <code>eraseAVL(root,x)</code>？</div><details id="q14-7"><summary>展开答案与推导</summary><div class="answer">当删除根或对根做旋转时，新的根指针可能变化。忽略返回值会使调用者继续持有旧的（甚至已释放的）根地址。</div></details></div>

<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>示范高度追踪：原先某结点 p 的左高 2、右高 3，bf=+1；若右边删除后右高降到 2，bf=0，p 的高度由 4 降到 3，祖先必须复查。对比原本左右都高 3（bf=0），右边删除后变为左 3、右 2，p 高度仍为 4，祖先无需继续传播“高度缩短”。</p><div class="question"><div class="qtitle">题：为什么 AVL 删除最坏仍是 O(log n)，即使可能发生多次旋转？</div><details id="q14-8"><summary>展开答案与推导</summary><div class="answer">访问的祖先最多为 AVL 高度 h=O(log n)，每个祖先更新高度、计算 bf 和最多常数次局部旋转都是 O(1)，所以总体仍为 O(log n)。</div></details></div><p>可以把 BST 有序性、结点缓存高度正确性、AVL 平衡条件三项合在一起做删除后的单元测试，尤其覆盖删除根、删除单子女、连续向上旋转和失衡孩子 bf=0 四种边界情形。</p>
</details>

## 章节练习：基础、典型与迁移 {#ch14-extra-exercises}
先独立解题；所有提示与答案默认折叠。

<details class="question"><summary>【基础】采用 bf=右高−左高，结点左高 3、右高 1，bf 与是否失衡？</summary>
<p><strong>选择思路：</strong>右高减左高。</p><p><strong>计算与结果：</strong>bf=1−3=−2，左重，需要检查左孩子以确定 LL 或 LR。</p><p><strong>易错点：</strong>本课件 bf 正负方向与部分教材相反。</p>
</details>

<details class="question"><summary>【巩固】依次插入 30,10,20，失衡类型与旋转结果？</summary>
<p><strong>选择思路：</strong>从首次失衡的根 30 往下是左、右。</p><p><strong>计算与结果：</strong>LR：先对 10 左旋，再对 30 右旋，最终 20 为根，左 10、右 30。</p><p><strong>易错点：</strong>折线型必须双旋。</p>
</details>

<details class="question"><summary>【作业同级】依次插入 10,30,20,40,50，最终 AVL 形态怎样？</summary>
<p><strong>选择思路：</strong>前三个 RL 得根 20，再插入 40、50 检查 30 的 RR。</p><p><strong>计算与结果：</strong>前三个形成 20(左10,右30)；插 40 在 30 右；插 50 后 30 右重 +2，左旋 30，最终根 20，左 10、右 40(左30,右50)。</p><p><strong>易错点：</strong>每次插入仅需从插入点向上寻找失衡祖先。</p>
</details>

<details class="question"><summary>【作业同级】删除导致结点 p 的 bf=+2，右孩子 q 的 bf=−1，该做哪种旋转？</summary>
