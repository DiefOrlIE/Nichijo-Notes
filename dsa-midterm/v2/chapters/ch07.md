# 字符串与 KMP：从前后缀到失配跳转
<!-- id: ch07 | source: 4-String，第 50—84 页；4a-KMP Algorithm，第 1—24 页 -->
模式串找不到匹配时，从头再比会浪费已经确认的字符。KMP 的核心就是证明哪些比较可以省略，再把这份证明落实为 LPS 与 next 数组。


## 字符串、子串、朴素匹配 {#ch07-string}
找子串与找子序列不是一回事：主串 ABCDE 中 BC 是子串，BD 仅是子序列。模式匹配要求连续窗口与模式字符逐项对应。朴素算法每次失败就换一个起点，先自己模拟两次失败再考虑优化。

<div class="lesson-body">
<p>字符串是有限字符序列。<strong>子串</strong>由连续字符构成；<strong>子序列</strong>只要求相对顺序，不必连续。模式匹配是在主串 S 中寻找模式串 P 的出现位置。</p>
<p>朴素匹配把 P 对齐到 S 的每个可能起点，再依次比较字符。若在较靠后位置才失败，大量前缀需要重新比较，最坏达到 O(nm)（主串长 n、模式长 m）。</p>
<pre><code>#include &lt;string&gt;
int bruteFind(const std::string&amp; s,const std::string&amp; p){
    if(p.empty())return 0;
    for(size_t i=0;i+p.size()&lt;=s.size();++i){
        size_t j=0;
        while(j&lt;p.size()&amp;&amp;s[i+j]==p[j])++j;
        if(j==p.size())return (int)i;
    }
    return -1;
}</code></pre><div class="question"><div class="qtitle">题：主串 ABABABC，模式 ABABC，朴素匹配首次成功的 0-based 起点是多少？</div><details id="q07-1"><summary>展开答案与推导</summary><div class="answer">起点 2：主串下标 2..6 为 A B A B C。</div></details></div>
</div>

<p>空模式串的返回位置取决于接口设计：本讲义约定返回 0，与 std::string::find 的常见行为相容。用 C 字符数组时还必须考虑末尾的 <code>'\0'</code> 和缓冲容量。</p>
</details>

## 公共真前后缀：LPS 究竟记录什么 {#ch07-border}
模式串 ABAB 中，前面的 AB 与末尾 AB 相同。主串已经与 ABAB 匹配成功时，这种重复说明主串末尾 AB 不用再比较一遍，也能确定它与模式开头 AB 对齐。LPS 数组正是逐位置记录可复用的最长边界长度。

<div class="lesson-body">
<p>对于字符串 X，<strong>真前缀</strong>和<strong>真后缀</strong>都不能包含整个 X。<strong>LPS[i]</strong> = P[0..i] 的最长相等真前缀与真后缀的长度。最短的非空前缀只有 1 字符，所以 LPS[0]=0。</p>
<p>例如 <code>ababab</code> 的公共真前后缀包括 <code>ab</code>、<code>abab</code>，最长为 <code>abab</code>，故长度 4。它在开头出现一次，在末尾也出现一次；这条重复结构可供 KMP 失配复用。</p><div class="diagram"><pre class="tree-diagram">P =  a b a b a b c a
索引  0 1 2 3 4 5 6 7
LPS   0 0 1 2 3 4 0 1</pre></div>
<p>逐格推导：P[0..2]=aba，前缀 a 等于后缀 a → LPS[2]=1；P[0..3]=abab，前缀 ab=后缀 ab → LPS[3]=2；继续可得 3、4；P[0..6]=abababc，新字符 c 使已有长度 4 的边界不再成立，逐级尝试长度 2、0，均不匹配，得到 0。</p><div class="question"><div class="qtitle">题：P='aabaaab' 的 LPS 数组？</div><details id="q07-2"><summary>展开答案与推导</summary><div class="answer">0,1,0,1,2,2,3。检查前缀长度 6 的 'aabaaa'：最长公共真前后缀 'aa' 长度 2；最后 'aabaaab' 的 'aab' 前后相同，长度 3。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>将某个字符串的所有“相等真前后缀”长度看成一条链：若长度 k 的边界失效，下一可用候选是这个 k 字符前缀自身的最长边界，长度为 <code>LPS[k−1]</code>；它仍然是原串的边界。这个<strong>边界套边界</strong>的性质，同时支撑构造 LPS 和 KMP 匹配。</p>
</details>

## 为什么构造 LPS 用 len=LPS[len−1] {#ch07-construct}
构造 LPS 时假设目前有长度 len 的公共前后缀。如果新字符不匹配，长度 len 已经不可用；但更短的候选必须仍然既是这段前缀的后缀又是模式开头。最长这样的候选恰是 LPS[len−1]，跳转不会漏掉合法候选。

<p><strong>读完这一节要能做：</strong>能够用“最长可能的候选边界”解释回退，自己手推连续失配。</p>
<div class="lesson-body">
<p>构造 LPS 时，<code>len</code> 表示已处理前缀末尾的<strong>最长公共真前后缀长度</strong>。比较 <code>P[i]</code> 与 <code>P[len]</code>：相等时扩展；失配时缩短候选边界。</p>
<p>假设已经知道 P[0..i−1] 的最长相等真前后缀长度为 len。现在追加 P[i]。若字符不等，这个长边界无法延长；要尝试的下一个最长候选，必须仍同时是“已匹配后缀”与“模式前缀”。而长度 <code>LPS[len−1]</code> 恰好是原长度 len 的边界内部最长的边界。<code>len--</code> 可能产生根本不存在的边界，需要重复无效尝试；直接跳过去才能线性。</p><div class="diagram"><pre class="tree-diagram">已知边界长度 len=4：
已处理后缀：   a b a b
模式开头：     a b a b
若下一个字符失配，长度 3 对应的
前后部分不相等；长度 2 'ab' 有资格继续试
于是 len = LPS[3] = 2</pre></div>
<pre><code>#include &lt;string&gt;
#include &lt;vector&gt;
std::vector&lt;int&gt; makeLPS(const std::string&amp; p){
    std::vector&lt;int&gt; lps(p.size(),0);
    int len=0;
    for(int i=1;i&lt;(int)p.size();){
        if(p[i]==p[len])lps[i++]=++len;
        else if(len&gt;0)len=lps[len-1];
        else lps[i++]=0;
    }
    return lps;
}</code></pre><p>每次循环只发生以下一种事情：匹配成功，len++ 且 i++；失配且 len>0，len 跳到更短的合法边界，i 不动；失配且 len=0，当前位置 LPS=0，i++。i 最多增加 m−1 次，len 总增加次数也有限，所以 O(m)。</p><div class="question"><div class="qtitle">题：构造 'abababca' 时，i=6、len=4，P[6]='c' 不等于 P[4]='a'，如何继续？</div><details id="q07-3"><summary>展开答案与推导</summary><div class="answer">先 len=LPS[3]=2，比较 P[6]='c' 和 P[2]='a' 仍失配；再 len=LPS[1]=0；比较 P[6] 和 P[0]='a' 仍失配，设置 LPS[6]=0 并 i++。</div></details></div>
</div>

<h4>一张表看清“为什么跳到 LPS[len−1]”</h4>
<p>取模式 <code>P=aabaaab</code>，下标依次为 0 至 6。构造结果为 <code>[0,1,0,1,2,2,3]</code>。关键在 i=5：此前处理前缀 <code>aabaa</code>，最长公共边界是 <code>aa</code>，所以 len=2。新字符仍是 a，但 P[len]=P[2]=b，无法继续扩展长度 2 的边界。</p>
<div class="diagram"><pre>i = 5，当前字符 P[5]='a'
候选长度 len=2：需比较 P[2]='b' → 不匹配
跳 len=LPS[1]=1：需比较 P[1]='a' → 匹配
因此 LPS[5]=2，处理下一位置 i=6。</pre></div>
<p>如果直接执行 len--，本例巧合只回退一格，但对于更长的边界会尝试许多根本不满足“前缀等于后缀”的长度。LPS[len−1] 记录的正是最长可行的下一个候选；主串匹配失效时可以用同一理由复用已经确认的字符。</p>

<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>为什么不会遗漏 len−1 等值？假设存在一个严格介于 LPS[len−1] 与 len 之间的合法边界 q，那么 q 也是长度 len 的已知边界字符串的真前后缀，从而与“LPS[len−1] 是其最长边界”矛盾。回退指针总指向下一可行长度；因此算法既正确又高效。</p>
</details>

## KMP 主匹配的状态机与完整执行 {#ch07-match}
主串指针 i 停在首次失配字符，模式指针 j 代表此前连续匹配的长度。回退 j=LPS[j−1] 后，S[i] 还没有与新 P[j] 比过，所以不能让 i 跟着动。把这次停顿当作一次“改变模式对齐位置”更直观。

<div class="lesson-body">
<p><strong>KMP</strong> 匹配时主串指针 i 保持向前或暂停，模式指针 j 表示已连续匹配字符数。失配且 j>0：<code>j=LPS[j−1]</code>；失配且 j=0：i++。</p>
<p>当 j=6，代表此前匹配成功的 6 个字符等于 <code>P[0..5]</code>。主串这 6 个字符的末尾如果包含与 P 前缀相同的一段，就可以把 P 的前端直接对齐过去。LPS[5]=4，故把 j 重设为 4；原主串 i 所在字符尚未尝试新的 P[j]，所以 i 不动。</p><div class="diagram"><pre class="tree-diagram">S: a b a b a b a b c a
P: a b a b a b c a
               ↑ i=6，对 c 失败
原先 j=6 → LPS[5]=4，i 保持 6
重新尝试 S[6]='a' 对 P[4]='a'
最终匹配起点 2</pre></div>
<pre><code>int kmpFind(const std::string&amp; s,const std::string&amp; p){
    if(p.empty())return 0;
    auto lps=makeLPS(p);
    int i=0,j=0;
    while(i&lt;(int)s.size()){
        if(s[i]==p[j]){++i;++j;
            if(j==(int)p.size())return i-j;
        }else if(j&gt;0)j=lps[j-1];
        else ++i;
    }
    return -1;
}</code></pre><div class="question"><div class="qtitle">题：S='ababababca'，P='abababca'，首次失配在主串 i=6，模式 j=6。j 跳到几？最终起点？</div><details id="q07-4"><summary>展开答案与推导</summary><div class="answer">LPS[5]=4，跳到 j=4，i=6 不动。此后继续匹配得到首次完整出现起点 i−m=10−8=2。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>复杂度 O(n+m)：预处理 LPS 需 O(m)；主匹配中 i 最多增加 n 次，j 的回退不能无限发生，因为每一次回退都要由此前的递增“支付”。最坏空间 O(m) 保存 LPS。若要找所有匹配，成功后记录起点并令 <code>j=LPS[j−1]</code>，继续匹配以允许重叠出现。</p>
</details>

## 课件 next、LPS 与 nextval 的版本辨析 {#ch07-next}
同一个单词 next 在不同教材里可能指完全不同的数组。先看代码中失败后执行 j=next[j] 还是 j=LPS[j−1]，再看首项是 −1 还是 0。用模式 ABABC 逐格核对两条数组，就能发现它们通常有一格偏移。

<div class="lesson-body">
<p>本章统一用<strong>0-based LPS</strong>：失配 j>0 时令 <code>j=LPS[j−1]</code>。主课件使用首值 <code>next[0]=−1</code> 的版本，写 <code>j=next[j]</code>；两种表必须分别按定义计算。</p>
<p>对于课件所用 <code>next[0]=−1</code> 且 j 从 0 开始比较的经典版本，常有 <code>next[j]=LPS[j−1]</code>（j≥1）。所以 LPS[0] 对应 next[1]；不能直接把整条 LPS 数组当 next 使用。某些教材把 next 的第一项记为 0 或 1，甚至将 nextval 优化数组也称 next，务必先确认代码行为。</p><div class="diagram"><pre class="tree-diagram">P = A B A B C
位置       0   1   2   3   4
LPS       0   0   1   2   0
课件 next -1   0   0   1   2
说明：next[4]=LPS[3]=2</pre></div>
<pre><code>// 课件风格 next[0]=-1 (不使用 nextval 优化)
std::vector&lt;int&gt; makeNext(const std::string&amp; p){
    if(p.empty())return {};
    std::vector&lt;int&gt; nxt(p.size(),0);
    nxt[0]=-1;
    int j=0,k=-1;
    while(j+1&lt;(int)p.size()){
        if(k==-1 || p[j]==p[k]) {
            ++j;++k;nxt[j]=k;
        }else k=nxt[k];
    }
    return nxt;
}
// 搜索时若 j==-1，则 i++,j++
// 否则字符相等 i++,j++；失配 j=next[j]。</code></pre><div class="question"><div class="qtitle">题：P='ABABC'，写出 LPS 与教材 -1 型 next。</div><details id="q07-5"><summary>展开答案与推导</summary><div class="answer">LPS=[0,0,1,2,0]；-1 型 next=[-1,0,0,1,2]。其中 next[4]=2，因为前 4 字符 'ABAB' 的最长公共真前后缀长度为 2。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p><strong>nextval</strong> 是针对相同字符比较的进一步优化：若按 next 回退后字符仍相同，可能再产生无意义比较，因此可继续沿 next 链回退。不同实现的 nextval 下标含义有所不同，不能套用固定数列。区分前缀函数 π、LPS、课件 next 和 nextval，最稳妥的方法是先写出失配执行语句及首项含义。</p>

## 作业重点：C 字符串指针、strlen、puts 和输出顺序 {#ch07-c-string-pointer}
C 字符串多一格 '\0' 终止符；strlen 返回的长度不含这一格。指向 name+strlen(name) 的指针初始停在终止符上，先减一才能打印末尾单字符。循环结束边界还要注意：指针不能越过数组开头。

<div class="lesson-body">
<p>字符串字面量初始化字符数组时，末尾会额外有 <code>'\0'</code>。<code>strlen(name)</code> 返回可见字符数；<code>name+strlen(name)</code> 指向结尾的 <code>'\0'</code>。<code>puts(p)</code> 从 p 指向的位置一直输出到下一个空终止符，并额外输出换行。</p>
<p>假设 <code>char name[]="ALEX";</code>，物理数组为 <code>['A','L','E','X','\0']</code>。指针开始指向下标 4；先执行 <code>--ptr</code> 才比较，于是第一次指向 X、打印 "X"；第二次指向 E、打印 "EX"，依此类推。</p><div class="diagram"><pre>下标：   0    1    2    3    4
字符：  'A'  'L'  'E'  'X' '\0'
ptr 初始指向 4
--ptr → 3：puts("X")
--ptr → 2：puts("EX")
--ptr → 1：puts("LEX")
--ptr → 0：puts("ALEX")</pre></div>
<pre><code>#include &lt;cstdio&gt;
#include &lt;cstring&gt;
int main(){
    char name[]="ALEX";
    char* ptr=name+std::strlen(name);
    while(ptr&gt;name){
        --ptr;
        std::puts(ptr);

## 章节练习：从基础操作到陌生题 {#ch07-extra-exercises}
这些题目的思路和答案默认收起。先独立写出结果，再展开提示核查；一道题若仅能跟着答案做，说明还应回看相应操作示范。

<details class="question"><summary>【基础】空串和含两个空格的字符串的长度各为多少？</summary>
<p><strong>选方法的提示：</strong>空格也属于字符。</p>
<p><strong>完整推理与结果：</strong>分别为 0 和 2。</p>
<p><strong>最容易错的地方：</strong>空串与空白串不同。</p>
</details>

<details class="question"><summary>【巩固】S='ABCDEFG'，按 1-based SubString(S,3,3) 是什么？</summary>
<p><strong>选方法的提示：</strong>从第 3 个字符开始取 3 个。</p>
<p><strong>完整推理与结果：</strong>CDE。</p>
<p><strong>最容易错的地方：</strong>课程 1-based 与 std::string 0-based 不要混用。</p>
</details>

<details class="question"><summary>【作业同级】P='aabaaca' 的 LPS 数组？</summary>
<p><strong>选方法的提示：</strong>各位置求最长相等真前后缀长度。</p>
<p><strong>完整推理与结果：</strong>[0,1,0,1,2,0,1]。最后 'a' 与开头 'a' 相同，最大公共真前后缀长度为 1。</p>
<p><strong>最容易错的地方：</strong>构造时失配应沿 LPS[len−1] 回退。</p>
</details>

<details class="question"><summary>【作业同级】S='ababababca'、P='abababca'，在 i=6,j=6 失配，如何回退？</summary>
<p><strong>选方法的提示：</strong>已经匹配 j=6 个字符，查看 LPS[5]。</p>
<p><strong>完整推理与结果：</strong>LPS[5]=4，于是 j=4、i 保持 6；最终匹配下标为 2。</p>
<p><strong>最容易错的地方：</strong>不要同时移动 i 和 j。</p>
</details>

<details class="question"><summary>【提高】P='aaaa' 在 S='aaaaaa' 中允许重叠匹配出现多少次？成功后 j 怎样变化？</summary>
<p><strong>选方法的提示：</strong>匹配成功后复用最后一个边界。</p>
<p><strong>完整推理与结果：</strong>出现 3 次，起点 0、1、2。LPS=[0,1,2,3]，成功后 j=3。</p>
<p><strong>最容易错的地方：</strong>成功后直接清零 j 会漏重叠。</p>
</details>
