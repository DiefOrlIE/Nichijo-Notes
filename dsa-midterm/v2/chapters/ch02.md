## 顺序表：插入删除为什么要移动 {#ch02-seq}
试着在 [2,4,6,8] 的第 2 个位置前插入 3：必须从末项 8 起向后移动，最后再放 3；如果从左向右移，旧值可能先被覆盖。这个小实验解释了为什么按索引访问常数时间，插入删除却常常线性时间。

<div class="lesson-body">
<p>线性表 <code>(a₁,…,aₙ)</code> 是有次序的有限序列。顺序表把元素相继放在连续存储单元中。若首地址为 base、每项占 b 字节，0-based 元素 <code>a[i]</code> 的地址为 <code>base+i·b</code>。</p>
<p>顺序表可以用数组实现。想在 0-based 位置 i 插入新元素，必须先从最后一项向右挪，最后放新值；删除则把后面的项依次左移。<strong>插入从右往左，删除从左往右</strong>，避免覆盖未搬运的数据。</p><div class="diagram"><pre class="tree-diagram">插入 7 于下标 2：
[2,4,8,9,_] → [2,4,8,8,9] → [2,4,7,8,9]</pre></div>
<pre><code>#include &lt;vector&gt;
#include &lt;stdexcept&gt;
using namespace std;
void insertAt(vector&lt;int&gt;&amp; a,int i,int value){
    if(i&lt;0 || i&gt;(int)a.size()) throw out_of_range("index");
    a.push_back(0);                 // 先扩容一格
    for(int j=(int)a.size()-1;j&gt;i;--j) a[j]=a[j-1];
    a[i]=value;
}
void eraseAt(vector&lt;int&gt;&amp; a,int i){
    if(i&lt;0 || i&gt;=(int)a.size()) throw out_of_range("index");
    for(int j=i;j+1&lt;(int)a.size();++j) a[j]=a[j+1];
    a.pop_back();
}</code></pre><p>原长 n，在 0-based 位置 i 插入，要移动 <code>n−i</code> 项；删除当前位置 i，要移动 <code>n−i−1</code> 项。按课件<strong>第 i 个元素为 1-based</strong>时，插入移动 n−i+1 项、删除移动 n−i 项。</p><div class="question"><div class="qtitle">题：长度 8 的顺序表，在第 3 个元素之前插入和删除第 3 个元素，各移动几项？</div><details id="q02-1"><summary>展开答案与推导</summary><div class="answer">按 1-based 计数：插入移动 8−3+1=6 项；删除移动 8−3=5 项。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>随机访问 O(1)，按值顺序查找 O(n)，一般位置插入/删除 O(n)。如果采用动态数组扩容，末尾追加的均摊成本可为 O(1)，但单次扩容会复制 O(n) 项。顺序存储的逻辑相邻元素通常物理相邻，便于缓存局部性。</p>
</details>

## 单链表：画箭头后写代码 {#ch02-linked}
沿着 A→B→C 看一次插入。你已经有指向 A 的 p，新结点 x 先记住 B：x.next=p.next；再让 A 指向 x：p.next=x。删除则先保存 B，令 A 跨过 B 接到 C，最后释放 B。所有链表题都可以归结为这些箭头操作及不变量。

<div class="lesson-body">
<p>单链表用 <code>data</code> 和 <code>next</code> 字段串联结点。已知前驱 p，在其后插入 x：<code>x-&gt;next=p-&gt;next; p-&gt;next=x;</code>。删除 p 的后继：保存被删地址、跨接链接、释放结点。</p>
<p>插入顺序至关重要：先让新结点接住后面的链，再让前驱指向新结点。若先修改 <code>p-&gt;next</code>，旧后继可能丢失。<strong>带头结点</strong>的链表多了一个不计入表长的哨兵，空表和删除首元时可共享操作流程。</p><div class="diagram"><pre class="tree-diagram">插入前： p ─────→ q ─────→ r
             x (新结点)
① x.next=q
② p.next=x
插入后： p ─────→ x ─────→ q ─────→ r</pre></div>
<pre><code>struct Node { int data; Node* next; };
void insertAfter(Node* p,int x){
    if(!p) return;
    Node* q=new Node{x,p-&gt;next}; // 新结点先连原后继
    p-&gt;next=q;                  // 再让 p 连 q
}
bool removeAfter(Node* p,int&amp; value){
    if(!p || !p-&gt;next) return false;
    Node* q=p-&gt;next;
    value=q-&gt;data;
    p-&gt;next=q-&gt;next;
    delete q;
    return true;
}
// 若 head 是不存数据的头结点，insertAfter(head,x)
// 即头插；removeAfter(head,value) 即删除首元。</code></pre><div class="question"><div class="qtitle">题：单链表中已知 p 指向某结点，为什么不能直接 O(1) 删除其前驱？</div><details id="q02-2"><summary>展开答案与推导</summary><div class="answer">单链表结点没有指向前驱的指针，通常要从表头遍历寻找前驱，最坏 O(n)。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>定位第 i 个结点需要从头沿 <code>next</code> 走 i 次，故按位置操作一般 O(n)。已知操作点的前驱时，局部插删 O(1)。要区分“不带头结点时头指针就是首元”和“带头结点时 head 指向哨兵”。删除尾结点还须谨慎更新尾指针（若维护）。</p>
</details>

## 前插法、后插法与一次完整的链表实现 {#ch02-build}
输入 1、2、3，逐个把新结点插到头结点后，最终顺序是 3、2、1；每次接到尾指针后则是 1、2、3。最容易犯的错是维护了尾指针却忘记让新尾的 next 为空，或者为空链表建尾节点时没更新 head。

<div class="lesson-body">
<p><strong>前插法</strong>每次将新结点放在表头后，输入顺序会反过来；<strong>后插法</strong>使用尾指针，把新结点接到后面，保持输入次序。</p>
<p>例如依次输入 1、2、3：前插产生 3→2→1，后插产生 1→2→3。带头结点时，前插固定修改两根指针；后插需要维护 tail。</p>
<pre><code>#include &lt;iostream&gt;
struct Node{int data;Node* next;};

    Node* head;               // 哨兵（不保存逻辑元素）
    Node* tail;

    List():head(new Node{0,nullptr}),tail(head){}
    ~List(){while(head){Node* old=head;head=head-&gt;next;delete old;}}
    List(const List&amp;)=delete;

## 循环链表、双向链表与静态链表 {#ch02-variants}
把尾结点 next 改成指向头，就得到循环链表；这时遍历的终止条件也随之改变，不能继续只靠 nullptr 判断。双向链表删除 q 时要同时更新 q.prev.next 和 q.next.prev；边界结点缺少邻居时要先判断。

<div class="lesson-body">
<p><strong>循环单链表</strong>的尾结点链接回头部；<strong>双向链表</strong>同时保存前驱与后继指针；<strong>静态链表</strong>用数组下标模拟指针。</p>
<p>循环链表没有自然的 <code>nullptr</code> 终点，遍历需检测是否回到起点。双向链表删除 p：先令 <code>p-&gt;prev-&gt;next=p-&gt;next</code>，再令 <code>p-&gt;next-&gt;prev=p-&gt;prev</code>，并处理边界或设置双向哨兵。</p><div class="diagram"><pre class="tree-diagram">双向： A ⇄ B ⇄ C
循环： A → B → C ┐
       ↑__________│</pre></div>
<pre><code>struct DNode { int x; DNode *prev,*next; };
// p 有合法前驱与后继哨兵：将 x 插入 p 前面
void insertBefore(DNode* p,DNode* x){
    DNode* before=p-&gt;prev;
    x-&gt;prev=before; x-&gt;next=p;
    before-&gt;next=x; p-&gt;prev=x;
}
// 两端都有哨兵时可统一处理边界
void unlink(DNode* p){
    p-&gt;prev-&gt;next=p-&gt;next;
    p-&gt;next-&gt;prev=p-&gt;prev;
}</code></pre><div class="question"><div class="qtitle">题：长度 1 的不带头结点循环单链表，它的 next 指向哪里？</div><details id="q02-4"><summary>展开答案与推导</summary><div class="answer">指向自身；否则无法形成单结点的循环。带头结点设计可能让首元 next 指向头结点，视约定而定。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>课件还讨论静态链表（通过数组中的整型游标记录“下一个结点”）。它适用于不便用原生指针的固定存储环境，但寻找前驱仍需遍历。双向链表已知结点时可 O(1) 删除；空间上每结点通常多一个指针字段。</p>
</details>

## 多项式与集合运算 {#ch02-poly}
当多项式 P(x)=3x²+5 与 Q(x)=−3x²+x+2 相加时，不需要把每一项展开到稠密数组。按指数比较两个链表：指数相同就加系数，得零的项直接跳过，其余项保持指数顺序，结果为 x+7。

<div class="lesson-body">
<p>稀疏多项式可以用按指数排序的链表保存非零项：结点包含 <code>(系数,指数,next)</code>。同指数的项相加，系数变为 0 时应删除该项。</p>
<p>例如 <code>A=2x³+3x+1</code>、<code>B=−2x³+4x²−3x</code>。从两条按指数降序排列的链表头部逐项比较：指数大的先输出；相等则合并系数，得到 <code>4x²+1</code>。</p>
<pre><code>// 输入两组按指数从大到小排列的 (指数,系数)
#include &lt;vector&gt;
#include &lt;utility&gt;
using Term=std::pair&lt;int,int&gt;;
std::vector&lt;Term&gt; addPoly(const std::vector&lt;Term&gt;&amp; a,
                          const std::vector&lt;Term&gt;&amp; b){
    std::vector&lt;Term&gt; out;size_t i=0,j=0;
    while(i&lt;a.size()||j&lt;b.size()){
        if(j==b.size()||(i&lt;a.size()&amp;&amp;a[i].first&gt;b[j].first))
            out.push_back(a[i++]);
        else if(i==a.size()||b[j].first&gt;a[i].first)
            out.push_back(b[j++]);
        else {
            int coef=a[i].second+b[j].second;
            if(coef)out.push_back({a[i].first,coef});
            ++i;++j;
        }
    }
    return out;
}</code></pre><div class="question"><div class="qtitle">题：两个各有 m、n 个非零项的有序多项式归并求和，复杂度是多少？</div><details id="q02-5"><summary>展开答案与推导</summary><div class="answer">每一步至少消耗一条输入链表的一项，各项只访问一次，时间 Θ(m+n)。输出需要最多 m+n 项的额外空间。</div></details></div>
</div>

## 单链表逆置：三指针完整推演 {#ch02-reverse}
逆置 A→B→C 时，如果先把 A.next 指回去，却没有保存 B，剩余链会丢失。三个工作指针分成“已经逆好的部分”“当前结点”“尚未处理部分”；每轮只翻转一条边，直到未处理部分为空。

<div class="lesson-body">
<p>逆置单链表的核心是逐结点翻转 next 指向：原 <code>A→B→C→null</code> 变为 <code>C→B→A→null</code>。需要保存下一个结点，以免断链。</p>
<p>用 <code>prev</code> 指向已逆置链表的头，<code>cur</code> 指向待处理结点，<code>next</code> 临时保存剩余链表。循环不变量：prev 链上的每条边已倒转，cur 及后面的边仍是原方向。</p>
<pre><code>struct Node{int data;Node* next;};
Node* reverse(Node* head){
    Node* prev=nullptr;Node* cur=head;
    while(cur){
        Node* next=cur-&gt;next; // 保住未处理的链
        cur-&gt;next=prev;      // 只反转当前一条边
        prev=cur;            // 已处理区前进
        cur=next;            // 未处理区前进
    }
    return prev;
}</code></pre><div class="question"><div class="qtitle">题：逆置单链表时，为什么必须在 cur->next=prev 之前保存 next？</div><details id="q02-6"><summary>展开答案与推导</summary><div class="answer">因为修改 next 以后，原来的后继链接被覆盖。若未保存就无法找到剩余待处理链表。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>时间 Θ(n)，额外空间 Θ(1)。若链表有哨兵结点，应只逆置头结点之后的数据结点，再将哨兵 next 指向新首元，不能把哨兵也逆置进数据链。</p>
</details>

## 作业重点：两条升序链表原地逆序归并 {#ch02-reverse-merge}
给定两个从小到大排序的链表，要求合成从大到小的链表，容易想到“先合并再整体逆置”，但可以一次遍历完成。每次取出剩余的最小结点，直接头插到结果链；新结点永远不大于已经取过的元素，故头插保证结果从大到小。注意重复元素不能丢失，也不能为了省事创建新数据结点。

<p><strong>读完这一节要能做：</strong>不创建新数据结点，逐句填写 pa/pb/q/p 的空位，输出包含重复值的非递增链表。</p>
<div class="lesson-body">
<p>给两条<strong>带头结点</strong>、非递减排序的单链表，把它们合并成一条非递增链表，保留所有重复值，<strong>复用原有数据结点</strong>。技巧是：每次从两条链表头取较小者，然后<strong>头插</strong>到结果链表。因为取出的值是从小到大，头插自然把它们逆转成从大到小。</p>
<p>先把两条待处理链的首指针保存为 pa、pb，再使结果头结点的 <code>next=nullptr</code>。循环中必须先将被取结点的游标前进，才能修改该结点的 next；否则原剩余链可能丢失。主循环之后，另一条链还可能有剩余部分，继续逐个头插。</p><div class="diagram"><pre>原表 A：1 → 3 → 5
原表 B：2 → 3 → 4
取出次序：1,2,3,3,4,5
结果每步头插：
1
2→1
3→2→1
3→3→2→1
4→3→3→2→1
5→4→3→3→2→1</pre></div>
<p>伪代码：<code>while pa≠null and pb≠null: q=值较小的头；相应指针前进；q.next=result.next；result.next=q</code>。最后对未耗尽的链重复头插。两个游标每一步恰前进一步，因此 O(m+n) 时间、O(1) 辅助空间。</p><pre><code>struct Node { int value; Node* next; };
void mergeDescending(Node* ha, Node* hb) {
    if (!ha || !hb || ha == hb) return; // 带头结点、两表独立
    Node *pa=ha->next, *pb=hb->next;
    ha->next=nullptr; hb->next=nullptr;
    while (pa && pb) {
        Node* q;
        if (pa->value <= pb->value) {q=pa;pa=pa->next;}
        else {q=pb;pb=pb->next;}
        q->next=ha->next;
        ha->next=q;
    }
    Node* p=pa ? pa : pb;
    while (p) {
        Node* q=p;
        p=p->next;
        q->next=ha->next;
        ha->next=q;
    }
}</code></pre><p>原题模板八个空依次是：① <code>pb!=NULL</code>，② <code>pa=pa-&gt;link</code>，③ <code>pb=pb-&gt;link</code>，④ <code>q-&gt;link=first-&gt;link</code>，⑤ <code>pa?pa:pb</code>，⑥ <code>p!=NULL</code>，⑦ <code>q-&gt;link=first-&gt;link</code>，⑧ <code>first-&gt;link=q</code>。原题中链接域为 <code>link</code>，示例使用 <code>next</code>，意义一致。</p><div class="question"><strong>同类自测：</strong>链表 A=1→1→6、B=1→4，逆序归并后的数据序列？<details><summary>展开答案</summary>6→4→1→1→1。所有三枚 1 均保留，算法不分配新数据结点。</details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>循环不变量：结果链表始终非递增；结果中元素恰是从原两表已取出的结点且无重复遗漏；两条未处理链依然非递减。因每次取全体剩余最小项并头插，它不大于之前所有取出的元素，故新链表仍非递增。每步处理一个结点，有限终止。注意题目中“无需额外空间”通常指辅助空间 O(1) 且复用结点；原表 B 的头结点如何处置属于链表所有权约定，本例保留空头结点供调用方管理。</p>
</details>

## 章节练习：从基础操作到陌生题 {#ch02-extra-exercises}
这些题目的思路和答案默认收起。先独立写出结果，再展开提示核查；一道题若仅能跟着答案做，说明还应回看相应操作示范。

<details class="question"><summary>【基础】顺序表长 9，在第 4 个元素之前（1-based）插入，移动多少项？</summary>
<p><strong>选方法的提示：</strong>第 4 个到第 9 个都要向后移动。</p>
<p><strong>完整推理与结果：</strong>9−4+1=6 项。</p>
<p><strong>最容易错的地方：</strong>别把插入与删除的移动公式混用。</p>
</details>

<details class="question"><summary>【巩固】链表 2→6→8 先后头插 1、3，最后顺序？</summary>
<p><strong>选方法的提示：</strong>每次插入头结点之后。</p>
<p><strong>完整推理与结果：</strong>3→1→2→6→8。</p>
<p><strong>最容易错的地方：</strong>头插多次时，新输入部分逆序。</p>
</details>

<details class="question"><summary>【作业同级】升序链表 A=1→4→7，B=2→4→5，复用原结点头插归并为降序，最终序列？</summary>
<p><strong>选方法的提示：</strong>选剩余最小结点，然后头插到结果。</p>
<p><strong>完整推理与结果：</strong>取出 1,2,4,4,5,7，最终 7→5→4→4→2→1。</p>
<p><strong>最容易错的地方：</strong>重复的 4 必须保留两个。</p>
</details>

<details class="question"><summary>【作业同级】已知带头结点链表中 p 的后继存在，写删除该后继的代码与复杂度。</summary>
<p><strong>选方法的提示：</strong>保存待删地址，先跨接再释放。</p>
<p><strong>完整推理与结果：</strong><code>Node* q=p-&gt;next; p-&gt;next=q-&gt;next; delete q;</code>，时间 O(1)。</p>
<p><strong>最容易错的地方：</strong>删除后不能再访问 q。</p>
</details>

<details class="question"><summary>【提高】为什么单链表已知结点 q 时无法 O(1) 找其前驱？双向链表怎样改进？</summary>
<p><strong>选方法的提示：</strong>单链只保存指向后继的箭头。</p>
<p><strong>完整推理与结果：</strong>单链通常从头搜索，最坏 O(n)；双向结点有 prev，可在 O(1) 取得前驱并完成局部改接。</p>
<p><strong>最容易错的地方：</strong>已知 q 不等于已知它的前驱。</p>
</details>
