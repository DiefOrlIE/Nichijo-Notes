# 堆：两种建堆方法、插入与删除
<!-- id: ch10 | source: 5-Tree，第 126—146 页；3-Stack&Queue 优先级队列部分 -->
当任务反复要求取最大项或最小项时，为每次取值重新排序很浪费。堆利用完全二叉树的形状和父子大小关系，用少量比较保持堆顶有效。


## 最小堆与最大堆、数组索引 {#ch10-definition}
最大堆 [9,7,8,3,5,6] 里，9 作为根大于所有结点，但 7 与 8 谁先出现无关紧要。堆只约束父与孩子的大小，并要求形状为完全二叉树；因此用数组即可定位父下标和左右孩子下标。

<div class="lesson-body">
<p><strong>堆</strong>是一棵满足堆序性质的完全二叉树。最小堆每个父结点值≤子结点值；最大堆则≥。堆顶是全局最小或最大值，但同层元素未必排序。</p>
<p>用数组存堆无需显式孩子指针：根 a[0]，结点 i 的左孩子 <code>2i+1</code>、右孩子 <code>2i+2</code>，双亲下标 <code>(i−1)/2</code>（i&gt;0）。这就是二叉树的完全形态带来的定位优势。</p><div class="diagram"><pre class="tree-diagram">最小堆：        2
              /   \
             5     4
            / \   /
           9   7 8
数组 [2,5,4,9,7,8]</pre></div>
<p>判定数组是否为最小堆：对每个 i&gt;0，检查 <code>a[parent(i)]≤a[i]</code> 即可；或只枚举内部结点比较孩子。注意堆保证父子顺序，<strong>没有保证左右孩子之间排序</strong>。</p><div class="question"><div class="qtitle">题：[2,7,4,9,8,6] 是否是最小堆？</div><details id="q10-1"><summary>展开答案与推导</summary><div class="answer">是。父 2≤7、4；7≤9、8；4≤6。数组整体不是升序仍满足最小堆。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>完全二叉树数组最后一个非叶结点下标是 <code>floor(n/2)−1</code>（n≥2）；之后结点都是叶子。对 1-based 堆，下标规则变为左 2i、右 2i+1、父 i/2，需要与 0-based 代码分开。</p>
</details>

## 向上调整、向下调整与堆顶删除 {#ch10-operations}
插入元素时，先把它放到数组末尾，满足完全二叉树的形状，再向上比较父结点。删除堆顶时，取末尾元素补到根，形状仍正确，但可能破坏父子顺序；此时一路与更合适的孩子交换，恢复堆序。

<div class="lesson-body">
<p>最小堆<strong>插入</strong>：新值放数组末尾，反复与父比较，若更小则交换（向上调整）；<strong>删除堆顶</strong>：将末尾值移到根，弹掉末尾，反复与较小孩子交换（向下调整）。</p>
<p>插入只能在完全二叉树允许的最后位置增加结点；先满足形状，再恢复堆序。删根时也先用末尾值补根，保留完全二叉树形态，再重新沿一个向下的路径恢复顺序。</p><div class="diagram"><pre class="tree-diagram">最小堆插入 1：
[2,5,4,9,7,8] → 末尾加 1
[2,5,4,9,7,8,1]
1&lt;4 交换 → [2,5,1,9,7,8,4]
1&lt;2 交换 → [1,5,2,9,7,8,4]</pre></div>
<pre><code>#include &lt;vector&gt;
#include &lt;algorithm&gt;
#include &lt;stdexcept&gt;
class MinHeap {
    std::vector&lt;int&gt; a;
    void up(int i){
        while(i&gt;0){
            int p=(i-1)/2;
            if(a[p]&lt;=a[i])break;
            std::swap(a[p],a[i]); i=p;
        }
    }
    void down(int i){
        int n=(int)a.size();
        while(2*i+1&lt;n){
            int c=2*i+1;
            if(c+1&lt;n &amp;&amp; a[c+1]&lt;a[c])++c;
            if(a[i]&lt;=a[c])break;
            std::swap(a[i],a[c]);i=c;
        }
    }
public:
    void push(int x){a.push_back(x);up((int)a.size()-1);}
    int popMin(){
        if(a.empty())throw std::underflow_error("empty heap");
        int x=a[0];a[0]=a.back();a.pop_back();
        if(!a.empty())down(0);
        return x;
    }
};</code></pre><div class="question"><div class="qtitle">题：对最小堆 [1,5,2,9,7,8,4] 删除堆顶后的数组？</div><details id="q10-2"><summary>展开答案与推导</summary><div class="answer">末尾 4 补根 → [4,5,2,9,7,8]；与较小的右孩子 2 交换 → [2,5,4,9,7,8]，完成。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>向上、向下都最多经过树高 O(log n) 层，故最坏 O(log n)。堆顶读取 O(1)。若两孩子相等，选左或右均可保持堆序，但可能产生不同的合法堆。</p>
</details>

## 插入法建堆 vs 筛选法（Floyd）建堆 {#ch10-build}
为什么底向上建堆只需 O(n)？最后一半结点已经是叶子，完全不需要下沉；再往上，多数结点也只能移动一两层。对不同高度的结点分别计数，才能得到紧确界。逐项插入则不同，新值可能反复向根上浮。

<p><strong>本节能力任务：</strong>独立手工建堆、区分 O(nlogn) 和 O(n)，解释为什么底向上建堆是线性的。</p>
<div class="lesson-body">
<p>建堆有两种方法：<strong>逐个插入</strong>（从左到右把元素依次插入空堆）与<strong>底向上筛选</strong>（数组先整体放好，从最后一个非叶结点向根执行 siftDown）。最终堆可能不同。</p>
<p>插入法：依次构造越来越大的堆，新结点向上找正确位置。筛选法：把末层叶子视为已满足堆序的小堆，从倒数第二层往上，每一步把当前结点及其孩子组成合法堆；最终整个数组成堆。</p><div class="diagram"><pre class="tree-diagram">原数组 [9,5,8,2,7,4]
底向上：从 i=floor(6/2)-1=2 开始
 i=2: [9,5,4,2,7,8]
 i=1: [9,2,4,5,7,8]
 i=0: [2,5,4,9,7,8]（最终最小堆）
逐个插入得到 [2,5,4,9,7,8]（该例巧合相同）</pre></div>
<pre><code>void siftDown(std::vector&lt;int&gt;&amp; a,int i){
    int n=(int)a.size();
    while(2*i+1&lt;n){
        int c=2*i+1;
        if(c+1&lt;n&amp;&amp;a[c+1]&lt;a[c])++c;
        if(a[i]&lt;=a[c])break;
        std::swap(a[i],a[c]);i=c;
    }
}
void buildHeap(std::vector&lt;int&gt;&amp; a){
    for(int i=(int)a.size()/2-1;i&gt;=0;--i)
        siftDown(a,i);
}
// 逐项插入：for(auto x:input) heap.push(x)</code></pre><div class="question"><div class="qtitle">题：为什么底向上建堆从 floor(n/2)-1 开始？</div><details id="q10-3"><summary>展开答案与推导</summary><div class="answer">因为后面的结点均为叶子，单结点天然满足堆序，无须下滑调整。首个可能有孩子的位置是最后一个非叶结点。</div></details></div>
</div>

<h4>底向上筛选：每调整一个下标都保存数组</h4>
<p>要将 [9,5,8,2,7,4] 建成最小堆，最后非叶结点下标为 <code>floor(6/2)-1=2</code>。先处理下标 2 的 8，它的左孩子 4 更小，交换；再处理下标 1 的 5，它的孩子 2 和 7 中 2 最小；最后处理根 9，需要连续向下交换两次。</p>
<div class="diagram"><pre>原始       [9,5,8,2,7,4]
处理 i=2   [9,5,4,2,7,8]
处理 i=1   [9,2,4,5,7,8]
处理 i=0   [2,5,4,9,7,8]</pre></div>
<p>为什么最后一步不能只交换一次？根 9 与子 2 交换后，9 到了下标 1，但其孩子为 5 和 7；9 仍大于孩子 5，还必须继续下沉。每一轮都要检查当前结点，直到两个孩子都不比它更合适或已经到叶子。</p>

<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>逐个插入上界 <code>n·O(log n)=O(nlogn)</code>；底向上筛选实际 O(n)：距叶子高度为 h 的结点个数约 n/2^(h+1)，各自下滑最多 h 次，总工作 ≤ <code>n Σ(h/2^(h+1))=O(n)</code>。可直观理解为“大多数结点离叶子很近，根附近虽贵但很少”。</p><div class="question"><div class="qtitle">题：为什么不能把所有结点的 siftDown 都按 O(log n) 估算并认为复杂度恰好 Θ(nlogn)？</div><details id="q10-4"><summary>展开答案与推导</summary><div class="answer">那样得到的是有效但不紧确的上界。绝大多数结点只需要下滑 0、1、2 层；对各高度的结点分别求和，可得到 Θ(n)。</div></details></div>
</details>

## Top-K 与优先级队列 {#ch10-application}
从持续到达的成绩中维护最高的 10 个时，最重要的是随时知道“当前前十名中最差的成绩”。因此采用大小为 10 的最小堆，堆顶成为新成绩是否应该替换的门槛。反过来求最小的 K 项，则用最大堆。

<div class="lesson-body">
<p>找 n 个数中最大的 k 个，常用大小为 k 的<strong>最小堆</strong>：堆顶是当前保留的 k 个数里最小的。如果来了更大的新元素，替换堆顶并调整。</p>
<p>为什么保存最大 k 项时要用最小堆？因为只有“当前入选项里最弱的一个”值得与新候选竞争。其值位于堆顶，比较和替换很高效。</p>
<pre><code>#include &lt;queue&gt;
#include &lt;vector&gt;
#include &lt;functional&gt;
std::vector&lt;int&gt; largestK(const std::vector&lt;int&gt;&amp; nums,int k){
    if(k&lt;=0)return {};
    std::priority_queue&lt;int,std::vector&lt;int&gt;,std::greater&lt;int&gt;&gt; pq;
    for(int x:nums){
        if((int)pq.size()&lt;k)pq.push(x);
        else if(x&gt;pq.top()){pq.pop();pq.push(x);}
    }
    std::vector&lt;int&gt; res;
    while(!pq.empty()){res.push_back(pq.top());pq.pop();}
    return res; // 从小到大排列的 k 个最大元素
}</code></pre><div class="question"><div class="qtitle">题：n=100000,k=10，为什么不一定需要对整个数组排序？</div><details id="q10-5"><summary>展开答案与推导</summary><div class="answer">维持规模为 10 的小根堆，扫描所有数据共 O(nlog k)，额外空间 O(k)；整体排序通常 O(nlog n)。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>如果 k≈n，堆方法相对排序的优势可能减小。Quickselect 平均 O(n) 也能找第 k 大，但最坏实现与稳定性需另外分析。堆的特点是适于<strong>持续到达的数据流</strong>，可随时维护候选集合。</p>
</details>

## 作业重点：最大堆逐项插入的每一步数组 {#ch10-max-heap-practice}
手工建最大堆之前先明确题目要求的是“逐项插入”还是“原数组底向上筛选”。两者可以得到不同的合法结果。按逐项插入时，每写一行都保存当前数组，再从新加入的最后一项开始沿父索引上浮。

<div class="lesson-body">
<p>原作业要求将 <code>{1,2,5,8,3,6,10,14}</code> 调整为最大堆并展示“每个数据调整后”的变化。若按<strong>逐项插入法</strong>理解，先把元素放末尾，再向上同父结点比较，父较小时交换。</p>
<p>注意题目没有明确“逐项插入法”还是“底向上筛选法”。因为要求每加入一个数据都记录状态，插入法最符合题面；讲义同时提供两种方法，防止题意在课堂中另有约定。</p>

## 章节练习：基础、典型与迁移 {#ch10-extra-exercises}
先独立解题；所有提示与答案默认折叠。

<details class="question"><summary>【基础】数组 [9,7,8,3,5,6] 是合法最大堆吗？</summary>
<p><strong>选择思路：</strong>检查每个父结点都不小于孩子。</p><p><strong>计算与结果：</strong>是：9≥7,8；7≥3,5；8≥6。数组整体无需有序。</p><p><strong>易错点：</strong>左右孩子间大小不受堆序约束。</p>
</details>

<details class="question"><summary>【巩固】最大堆 [9,7,8,3,5,6] 插入 10 后数组？</summary>
<p><strong>选择思路：</strong>新元素放末尾，再与父比较、向上交换。</p><p><strong>计算与结果：</strong>[9,7,8,3,5,6,10] → 和父 8 交换：[9,7,10,3,5,6,8] → 和根 9 交换：[10,7,9,3,5,6,8]。</p><p><strong>易错点：</strong>必须始终保持完全二叉树形状。</p>
</details>

<details class="question"><summary>【作业同级】对输入 [2,9,4,7,6] 采用逐项插入建立最大堆，列出每次插入后的数组。</summary>
<p><strong>选择思路：</strong>新元素上浮，不必全数组重排。</p><p><strong>计算与结果：</strong>插入 2：[2]；9：[9,2]；4：[9,2,4]；7：[9,7,4,2]；6：[9,7,4,2,6]。</p><p><strong>易错点：</strong>每步只沿新项到根的路径调整。</p>
</details>

<details class="question"><summary>【作业同级】使用底向上筛选法，将 [2,9,4,7,6] 调成最大堆，列出各非叶结点调整后数组。</summary>
<p><strong>选择思路：</strong>0-based 最后非叶下标 floor(5/2)−1=1。</p><p><strong>计算与结果：</strong>初始 [2,9,4,7,6]；i=1：9≥7,6，无变化；i=0：与较大孩子 9 交换 → [9,2,4,7,6]，2 再与 7 交换 → [9,7,4,2,6]。</p><p><strong>易错点：</strong>筛选必须选择较大的孩子交换。</p>
</details>

<details class="question"><summary>【提高】在 n=100000 个流式整数中持续维护最大的 k=20 个值，选什么堆，复杂度？</summary>
<p><strong>选择思路：</strong>保留 k 个赢家，堆顶存赢家中最弱者。</p><p><strong>计算与结果：</strong>用 20 项最小堆；每来一个 x 若超过堆顶则替换。时间 O(nlog k)，额外空间 O(k)。</p><p><strong>易错点：</strong>找最大 k 项需要最小堆作为候选淘汰门槛。</p>
</details>
