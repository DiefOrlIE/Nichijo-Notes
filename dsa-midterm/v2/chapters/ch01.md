# 数据结构、抽象数据类型与复杂度
<!-- id: ch01 | source: 1-Intro，第 19—96 页 -->
算法分析从一个真正的选择开始：相同的任务为什么会有快慢差异？先确认数据、允许的操作与输入规模，再计算循环和递归的工作量。


## 数据、逻辑结构、存储结构与运算 {#ch01-three}
例如给定课堂学生名单，我们可以用编号序列说明谁在第几个位置，也可以用连续数组或链式结点在内存中实现。前者是逻辑上的顺序，后者决定了读第 i 项、插入一项需要多少实际操作。选结构之前先把“需要哪些操作、各操作有多频繁”写出来。

<div class="lesson-body">
<p><strong>数据元素</strong>是研究的基本单位，元素可由多个<strong>数据项</strong>构成。数据结构可以概括为数据集合与元素关系：<code>DS=(D,R)</code>。每种结构要明确逻辑关系、物理存储与允许的操作。</p>
<p>同样一份学生名单，逻辑上是一条线性序列，内存里却能用连续数组或分散结点表示。逻辑结构回答“谁挨着谁”，存储结构回答“如何找到谁”，运算回答“我要做什么”。线性表、树、图分别体现一对一、层次性、多对多联系。</p>
<div class="table-scroll"><table><tr><th>角度</th><th>例子</th><th>考点</th></tr><tr><td>逻辑</td><td>线性表 (a,b,c)</td><td>先后次序存在</td></tr><tr><td>存储</td><td>顺序表 / 链表</td><td>连续内存或链接</td></tr><tr><td>运算</td><td>按下标读、插入、删除</td><td>接口与代价</td></tr></table></div><div class="question"><div class="qtitle">判断：“链表是一种逻辑结构，线性表是一种存储结构。”</div><details id="q01-1"><summary>展开答案与推导</summary><div class="answer">错误。线性表主要描述逻辑关系；链表是实现这种逻辑关系的一类存储结构。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>同一逻辑结构可以有多种存储表示；算法性能取决于<strong>数据、操作频率和实现选择</strong>。例如频繁随机访问偏向顺序表，已知插入点时频繁局部修改偏向链表。单凭“链表插入 O(1)”不能推出“按序号插入 O(1)”，因为定位结点还要花时间。</p>
</details>

## ADT 与算法的五种性质 {#ch01-adt}
假设“栈”只承诺 push、pop、top 和 empty，使用者可以先据此写括号匹配算法；至于后端用数组还是链表，只有容量管理与性能差异会影响实现。学抽象数据类型的目标，是先把问题与操作约定说清，再分别评价各实现。

<div class="lesson-body">
<p>抽象数据类型 <strong>ADT</strong> 描述数据对象及其允许的操作，并对外隐藏实现细节。算法具有输入、输出、有穷性、确定性和可行性等性质。</p>
<p>例如“栈”只承诺压入、弹出、读栈顶，具体可以用数组实现，也可以用链表实现。客户端无需关心数据在哪个地址。<strong>接口规定做什么，实现决定怎样做。</strong></p>
<p>伪代码：<code>Stack: push(x), pop(), top(), empty()</code>。练习：如果 <code>pop</code> 在空栈上调用，是返回错误、抛异常，还是由前置条件禁止？这些都属于接口规范，要写清楚。算法的“有穷性”要求正常定义的输入上执行有限步骤后结束。</p><div class="question"><div class="qtitle">题：为什么一个无限执行的程序不满足一般算法的有穷性？</div><details id="q01-2"><summary>展开答案与推导</summary><div class="answer">算法作为解决特定问题的有限步骤描述，需要按定义终止；一个永远执行的服务进程是程序的常见形态，但这种整体行为不满足该有穷性表述。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>“程序 = 数据结构 + 算法”用来强调<strong>数据的组织形式</strong>与<strong>处理步骤</strong>共同影响实现。考虑约瑟夫环：可以数组循环模拟，也可以循环链表逐人删除。后者在已定位前驱时单次删结点很快，但找第 m 人仍需要行走，且访问模式决定总复杂度。</p>
</details>

## 时间复杂度、空间复杂度的推导 {#ch01-asymptotic}
先对小规模 n 手数运行次数，再把规律写成求和式。比如外循环第 i 轮执行 i 次内循环，总工作是 1+2+⋯+(n−1)。写 Θ(n²) 之前，要知道平方项从哪里产生；同时说明临时数组、递归栈等额外空间，不能把输入自身大小算作全部辅助空间。

<p><strong>读完这一节要能做：</strong>读代码求数量级，掌握并列相加、嵌套相乘、递归深度与辅助空间。</p>
<div class="lesson-body">
<p><strong>时间复杂度</strong>描述随输入规模 n 增长的操作数量。大 O 记号给出渐近上界：<code>O(1)</code> 常数、<code>O(log n)</code> 对数、<code>O(n)</code> 线性、<code>O(n log n)</code>、<code>O(n²)</code>、<code>O(2ⁿ)</code>。空间复杂度经常统计额外辅助存储。</p>
<p>分析先确定<strong>基本操作</strong>和<strong>问题规模</strong>。顺序走 n 个结点要比较 n 次；每次把剩余搜索区间减半，大概只需 log₂n 次；两重各执行 n 次的循环产生 n×n 次迭代。删掉低阶项和常数系数，是关注增长趋势的简化。</p><pre><code>for (int i=0;i&lt;n;++i) work();          // Θ(n)
for (int i=1;i&lt;n;i*=2) work();          // Θ(log n)
for (int i=0;i&lt;n;++i)
    for(int j=0;j&lt;i;++j) work();       // Θ(n²)</code></pre>
<p>严谨地算第三段：内层次数分别为 0,1,2,…,n−1，总次数为 <code>n(n−1)/2</code>，因此 <code>Θ(n²)</code>。第四种循环 <code>for(i=0;i&lt;n;i++) for(j=0;j&lt;n;j*=2)</code> 需先确保 j 初始为 1，才有 <code>Θ(n log n)</code>。空间上，迭代累加一般额外 <code>O(1)</code>，长度 n 的递归链有 <code>O(n)</code> 调用栈。</p><div class="question"><div class="qtitle">题：for(i=1;i<n;i*=3) 的次数与复杂度？</div><details id="q01-3"><summary>展开答案与推导</summary><div class="answer">取 i=1,3,9,...,3^k，满足 3^k&lt;n，因此次数约为 ⌈log₃n⌉，复杂度 Θ(log n)。</div></details></div><div class="question"><div class="qtitle">题：for(i=0;i<n;i++) for(j=0;j<i*i;j++) work();</div><details id="q01-4"><summary>展开答案与推导</summary><div class="answer">次数为 Σi²=(n−1)n(2n−1)/6，所以是 Θ(n³)。不能看见两层循环便直接写 O(n²)。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>大 O 只保证上界，<code>Θ</code> 表示上下界同阶，<code>Ω</code> 给渐近下界。例如 <code>3n²+8n+1</code> 既是 O(n²) 也是 Θ(n²)，同时也是 O(n³)，但写 O(n³) 无法给出紧确量级。</p><p>递归式可用递归树理解：<code>T(n)=T(n−1)+O(1)</code> 为 Θ(n)；<code>T(n)=2T(n/2)+O(n)</code> 每层总工作 Θ(n)，共有 Θ(log n) 层，所以 Θ(n log n)。后者还有 Θ(log n) 的递归栈深度（不计额外数组）。</p>
</details>

## 结构选择、常见陷阱和约瑟夫问题 {#ch01-tradeoffs}
结构之间没有脱离任务的绝对冠军。已排序数组查找快，但插入中间要移动；链表局部插入快，但按序号访问要从头走。遇到“做约瑟夫问题”时，应根据删除频率和循环移动判断最值得优化的步骤，而非只背某结构的单次复杂度。

<div class="lesson-body">
<p>优化操作要考虑“先找到位置”的代价。数组按下标读 O(1)，中间插入 O(n)；链表沿指针找第 i 个 O(n)，已知前驱时插入 O(1)。</p>
<p>约瑟夫问题：n 人围成一圈，从指定位置开始循环报数，数到 m 的人出列，再从下一人继续。它自然对应循环关系，既可以用求模数组，也可以用循环链表实现。</p>
<pre><code>// Josephus 的递推解法：返回 0-based 幸存者编号
int survivor(int n, int m) {
    int ans = 0;
    for (int k=2; k&lt;=n; ++k) ans = (ans + m) % k;
    return ans;
}</code></pre><p>因为 k−1 人问题中的编号向 k 人问题恢复时，原先的新 0 号对应淘汰者下一位，故整体编号平移 m 并对 k 取模。</p><div class="question"><div class="qtitle">题：n=5,m=2，从 1 开始报数，最后幸存的是几号？</div><details id="q01-5"><summary>展开答案与推导</summary><div class="answer">按 1 开始编号，依次淘汰 2、4、1、5，剩下 3。递推返回的 0-based 结果是 2。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>选择算法时还需核对输入分布、失败情形、最坏/平均复杂度、是否原地、额外空间和边界条件。实际优化通常先改进算法的数量级，再考虑常数级优化。</p>
</details>

## 章节练习：从基础操作到陌生题 {#ch01-extra-exercises}
这些题目的思路和答案默认收起。先独立写出结果，再展开提示核查；一道题若仅能跟着答案做，说明还应回看相应操作示范。

<details class="question"><summary>【基础】for(i=1;i&lt;n;i*=2) 的时间复杂度？</summary>
<p><strong>选方法的提示：</strong>每次迭代使 i 翻倍。</p>
<p><strong>完整推理与结果：</strong>循环次数约 log₂n，所以 Θ(log n)。</p>
<p><strong>最容易错的地方：</strong>循环上界是 n 不代表运行 n 次。</p>
</details>

<details class="question"><summary>【巩固】for(i=0;i&lt;n;i++) for(j=0;j&lt;i;j++) ++c; 精确执行次数？</summary>
<p><strong>选方法的提示：</strong>内层第 i 次执行 i 次。</p>
<p><strong>完整推理与结果：</strong>总和为 0+1+…+(n−1)=n(n−1)/2，复杂度 Θ(n²)。</p>
<p><strong>最容易错的地方：</strong>区分 j&lt;i 和 j≤i。</p>
</details>

<details class="question"><summary>【作业同级】两个长度 m、n 的有序链表复用结点线性归并，时间与辅助空间？</summary>
<p><strong>选方法的提示：</strong>每次最少推进一条链表的一个结点。</p>
<p><strong>完整推理与结果：</strong>总计处理 m+n 项，时间 Θ(m+n)；常数个工作指针，辅助空间 Θ(1)。</p>
<p><strong>最容易错的地方：</strong>已知当前指针时改接是 O(1)，定位时可能有额外成本。</p>
</details>

<details class="question"><summary>【作业同级】T(n)=2T(n/2)+n（n 为 2 的幂），证明运行时间数量级。</summary>
<p><strong>选方法的提示：</strong>每层所有递归子问题的工作和都为 n。</p>
<p><strong>完整推理与结果：</strong>递归树有 log₂n 层非叶工作，总代价 Θ(nlog n)，叶子总代价 Θ(n)。</p>
<p><strong>最容易错的地方：</strong>不要把单条递归深度直接当总时间。</p>
</details>

<details class="question"><summary>【提高】递归每次先执行 n 次常数操作，再递归到 n−1，求时间与栈空间。</summary>
<p><strong>选方法的提示：</strong>写出 T(n)=T(n−1)+Θ(n)。</p>
<p><strong>完整推理与结果：</strong>Σ_{i=1}^n i=Θ(n²)，同时调用链深 Θ(n)，辅助栈 Θ(n)。</p>
<p><strong>最容易错的地方：</strong>只有一处递归调用仍可能是平方时间。</p>
</details>
