# 队列、循环队列与优先级队列
<!-- id: ch05 | source: 3-Stack&Queue，第 33—92 页 -->
排队时最早到达者先被处理。用数组实现这一规则却不能无限右移，于是出现循环下标；这里先固定 front 和 rear 的定义再谈公式。


## 队列与顺序／链式实现 {#ch05-fifo}
食堂排队时，先入队的同学先离开。数组实现时不必真的把所有后续元素左移一次，只要维护 front 指向现队首、rear 指向下一空位，出队时把 front 向前挪就够了。先明确这一约定再看代码。

<div class="lesson-body">
<p>队列遵守先进先出 <strong>FIFO</strong>：队尾入队 <code>enqueue</code>，队头出队 <code>dequeue</code>。它适用于广度优先搜索、任务排队与层次遍历。</p>
<p>队列像排队买票。若顺序队列只把 rear 向右移动，队头删除后前面的空位难以利用，于是需要把数组首尾当作一个环，用模运算绕回 0。</p>
<pre><code>#include &lt;queue&gt;
#include &lt;iostream&gt;
int main(){
    std::queue&lt;int&gt; q;
    q.push(10);q.push(20);q.push(30);
    std::cout&lt;&lt;q.front()&lt;&lt;"\n"; // 10
    q.pop();                      // 删除 10
    std::cout&lt;&lt;q.front()&lt;&lt;"\n"; // 20
}</code></pre><p>链式队列维护 <code>front</code>、<code>rear</code> 两个指针；在队尾插入 O(1)，在队头删除 O(1)。删除最后一个结点后必须同时正确处理两者，否则 rear 会悬空。</p><div class="question"><div class="qtitle">题：入队 A,B，出队一次，再入队 C,D，然后全部出队，顺序是什么？</div><details id="q05-1"><summary>展开答案与推导</summary><div class="answer">第一次出队 A；最后依次 B,C,D。队列无论如何交替操作，都保留尚未出队元素的入队先后关系。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>队列实现中经常有“rear 指向最后一个元素”或“rear 指向下一个空位置”的不同约定，必须先确认，否则公式虽看似相同，操作更新顺序和判满方式会不同。</p>
</details>

## 循环队列：空、满、队长公式 {#ch05-circular}
容量 5 的数组，当队尾到了位置 4，下次入队可能回到位置 0，公式中的取模就是把它绕回去。只用 front/rear 判断空满时会遇到两者相等的歧义；可以浪费一个槽，或另存 count，两种方案公式不同。

<div class="lesson-body">
<p>一种常用定义：<code>front</code> 指向队首元素，<code>rear</code> 指向下一空位，数组容量为 m；<strong>浪费一格</strong>区分空与满。</p><p><code>空：front==rear</code>；<code>满：(rear+1)%m==front</code>；<code>队长：(rear-front+m)%m</code>。</p>
<p>为什么浪费一格？如果 m 格全占满，rear 又会追上 front，与空状态的下标完全相同。牺牲一个位置可只用两个指针区分两种情形；也可以另外维护元素个数 count 来使用全部 m 格。</p><div class="diagram"><pre class="tree-diagram">容量 m=5（最多存 4 项）
下标： 0   1   2   3   4
状态： A   B   C   _   _
front=0,rear=3,队长=3
出队 A,B 后 front=2；入 D,E,F：
状态： F   _   C   D   E
front=2,rear=1，队长=(1-2+5)%5=4</pre></div>
<pre><code>#include &lt;vector&gt;
#include &lt;stdexcept&gt;
class RingQueue {
    std::vector&lt;int&gt; a;
    int front=0,rear=0,m;
public:
    explicit RingQueue(int usable):a(usable+1),m(usable+1){
        if(usable&lt;1) throw std::invalid_argument("capacity");
    }
    bool empty()const{return front==rear;}
    bool full()const{return (rear+1)%m==front;}
    int size()const{return (rear-front+m)%m;}
    bool push(int x){if(full())return false;
        a[rear]=x;rear=(rear+1)%m;return true;}
    bool pop(int&amp; x){if(empty())return false;
        x=a[front];front=(front+1)%m;return true;}
};</code></pre><div class="question"><div class="qtitle">题：容量 8（浪费一格）的循环队列，front=6,rear=2，队长多少？</div><details id="q05-2"><summary>展开答案与推导</summary><div class="answer"><code>(2−6+8)%8=4</code>，有效元素可能分布在 6、7、0、1 四个位置。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>若用 count 判空满，空为 count=0，满为 count=m，队长=count；若用单独 boolean 标识，也可让队首队尾相等时再检查上次操作。不能把“浪费一格”的空满公式直接套用到 count 方案。</p>
</details>

## 杨辉三角、层次遍历与优先级队列 {#ch05-uses}
需要按层遍历二叉树时，访问根后要先处理根的孩子，再处理下一层后代，因此用队列保存“已经发现但尚未处理”的结点。优先级队列则改变弹出规则，不以到达先后决定谁出列，通常由堆支持。

<div class="lesson-body">
<p>队列擅长按生成顺序逐批处理任务，例如杨辉三角逐行更新。优先级队列每次删除优先级最高的项，遵守“按优先级”，不要求严格 FIFO。</p>
<p>树的层序遍历使用 FIFO：根入队；循环取队首访问，再把其左右孩子依次入队。先进入的上一层结点先处理，因此天然逐层。</p>
<pre><code>struct Tree{int val;Tree* left;Tree* right;};
void levelOrder(Tree* root){
    if(!root)return;
    std::queue&lt;Tree*&gt; q;q.push(root);
    while(!q.empty()){
        Tree* p=q.front();q.pop();
        std::cout&lt;&lt;p-&gt;val&lt;&lt;" ";
        if(p-&gt;left) q.push(p-&gt;left);
        if(p-&gt;right)q.push(p-&gt;right);
    }
}</code></pre><div class="question"><div class="qtitle">题：二叉树 A 的孩子为 B,C；B 的孩子为 D,E；层序序列？</div><details id="q05-3"><summary>展开答案与推导</summary><div class="answer">A,B,C,D,E。第 1 层 A，第 2 层 B,C，第 3 层 D,E。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p><code>std::priority_queue&lt;int&gt;</code> 默认将最大元素置于堆顶，可通过比较器改成最小堆。优先级队列的 push/pop 通常 O(log n)、top O(1)，这一性能来自后面的堆结构。</p><pre><code>#include &lt;queue&gt;
#include &lt;vector&gt;
#include &lt;functional&gt;
std::priority_queue&lt;int&gt; maxQ;
std::priority_queue&lt;int,std::vector&lt;int&gt;,std::greater&lt;int&gt;&gt; minQ;</code></pre>
</details>

## 杨辉三角的队列模拟 {#ch05-yanghui}
杨辉三角每行中间值来自上一行的相邻两项。要打印下一行，可把上一行保存下来、依次取出两项求和，并在头尾补 1。任何试图原地改写的算法都要防止已经更新的值污染尚未计算的位置。

<div class="lesson-body">
<p>杨辉三角每行首尾是 1，内部项由上一行相邻两项相加得到：<code>C(n,k)=C(n−1,k−1)+C(n−1,k)</code>。</p>
<p>队列实现可逐行处理：读取上一行各项，生成下一行的边界 1 和内部和。按行推进时只需要暂存相邻项，不必保存整个三角。</p>
<pre><code>#include &lt;vector&gt;
#include &lt;iostream&gt;
void pascal(int rows){
    std::vector&lt;long long&gt; line{1};
    for(int r=0;r&lt;rows;++r){
        for(auto x:line)std::cout&lt;&lt;x&lt;&lt;" ";
        std::cout&lt;&lt;"\n";
        std::vector&lt;long long&gt; next(r+2,1);
        for(int j=1;j&lt;=r;++j)
            next[j]=line[j-1]+line[j];
        line=std::move(next);
    }
}</code></pre><div class="question"><div class="qtitle">题：杨辉三角第 4 行（从第 0 行算）是什么？</div><details id="q05-4"><summary>展开答案与推导</summary><div class="answer">1、4、6、4、1。上一行 1、3、3、1，相邻两项求和得到内部 4、6、4。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>课堂队列版本着重展示先进先出更新次序；上述 vector 版本等价地按上一行顺序生成下一行，便于对照。若直接原地更新，必须选正确方向防止新旧项互相覆盖。</p>
</details>

## 作业重点：只有 front 和 count 的循环队列 {#ch05-front-count}
只有 front 和 count 时，front 仍代表最早的元素，而 count 告诉我们现有多少项。数过 count 个位置便到达下一空位，所以入队下标是 (front+count)%m；出队让 front+1 并使 count−1。此法可以使用全部 m 格，满条件不再需要与 rear 比较。

<p><strong>读完这一节要能做：</strong>推导 rear=(front+count)%m，并解释为什么能装满所有 m 个位置。</p>
<div class="lesson-body">
<p>循环队列可以只维护队首下标 <code>front</code> 和元素个数 <code>count</code>。若数组长度 m，则<strong>下一个队尾空位</strong>可直接计算为 <code>(front+count)%m</code>。空条件为 count=0，满条件为 count=m，因此最多容纳 m 个元素。</p>
<p>从 front 起沿循环方向走 count 步，恰好到第一个未占用位置。因为 count 已经单独区分空与满，当 front 与推导出的 rear 相等时，通过 count=0 或 count=m 即可判别，无须浪费最后一格。</p><div class="diagram"><pre>m=5，front=3，count=3
有效下标依次：3,4,0
下次入队位置：(3+3)%5=1
入队后 count=4，再入队可达 count=5（满）</pre></div>
<pre><code>#include &lt;array&gt;
template &lt;class T,int M&gt;
struct FrontCountQueue {
    static_assert(M&gt;0);
    std::array&lt;T,M&gt; q{};
    int front=0, count=0;
    bool empty()const{return count==0;}
    bool full()const{return count==M;}
    bool push(const T&amp; x){
        if(full())return false;
        q[(front+count)%M]=x;
        ++count;
        return true;
    }
    bool pop(T&amp; x){
        if(empty())return false;
        x=q[front];
        front=(front+1)%M;
        --count;
        return true;
    }
};</code></pre><p>伪代码：<code>判空: count==0；入队: 若 count==m 则失败，否则 q[(front+count)%m]←x，count++；出队: 若 count==0 则失败，否则输出 q[front]，front←(front+1)%m，count--</code>。</p><div class="question"><strong>同类自测：</strong>m=6、front=5、count=4，下一次入队写哪个下标？<details><summary>展开答案</summary>(5+4)%6=3。加入后 count=5，仍可再入队一个，直到 count=6 才满。</details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>和“仅靠 front、rear 并牺牲一格”的方案对比：后者最大存 m−1 项；本题额外存 count，最大存 m 项。不能把“满：(rear+1)%m=front”直接应用于 front+count 的版本；那会错误地少用一个数组单元。每次入/出队都进行常数次运算，时间 O(1)，额外控制变量 O(1)。</p>
</details>

## 章节练习：从基础操作到陌生题 {#ch05-extra-exercises}
这些题目的思路和答案默认收起。先独立写出结果，再展开提示核查；一道题若仅能跟着答案做，说明还应回看相应操作示范。

<details class="question"><summary>【基础】队列入 1,2,3，出队一次，再入 4，队首到尾？</summary>
<p><strong>选方法的提示：</strong>首先移除 1。</p>
<p><strong>完整推理与结果：</strong>2,3,4。</p>
<p><strong>最容易错的地方：</strong>FIFO 与 LIFO 区分。</p>
</details>

<details class="question"><summary>【巩固】循环队列容量 8、浪费一格，front=6,rear=3，队长多少？</summary>
<p><strong>选方法的提示：</strong>(rear−front+8)%8。</p>
<p><strong>完整推理与结果：</strong>(3−6+8)%8=5，最多有效容量 7。</p>
<p><strong>最容易错的地方：</strong>不要直接计算负长度。</p>
</details>

<details class="question"><summary>【作业同级】只用 front=4,count=3 的 m=6 循环队列，下次入队下标？</summary>
<p><strong>选方法的提示：</strong>下次空位为 (front+count)%m。</p>
<p><strong>完整推理与结果：</strong>(4+3)%6=1。</p>
<p><strong>最容易错的地方：</strong>本实现满条件为 count=m。</p>
</details>

<details class="question"><summary>【作业同级】m=4、初始 front=0,count=0，入 A B C D，出两项，再入 E F，最终怎样？</summary>
<p><strong>选方法的提示：</strong>出队两次使 front=2；后来从下标 0 再放。</p>
<p><strong>完整推理与结果：</strong>最终 front=2,count=4，队列由前到后 C,D,E,F。</p>
<p><strong>最容易错的地方：</strong>该实现不用故意浪费一格。</p>
</details>

<details class="question"><summary>【提高】用两个栈实现队列，分析出队的单次最坏与均摊时间。</summary>
<p><strong>选方法的提示：</strong>仅当输出栈空时把输入栈整批倒入。</p>
<p><strong>完整推理与结果：</strong>单次倒栈最坏 Θ(n)，但每个元素最多经过有限次进出两个栈操作，因此均摊 O(1)。</p>
<p><strong>最容易错的地方：</strong>均摊不代表所有单次调用都 O(1)。</p>
</details>
