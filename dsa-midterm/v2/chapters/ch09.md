# 线索二叉树、一般树与森林
<!-- id: ch09 | source: 5-Tree，第 66—125 页 -->
普通二叉链表的空指针里其实还能保存遍历的前驱、后继；一般树也能借助“第一个孩子、下一个兄弟”的规则转化为二叉结构。


## 为什么需要线索，空指针怎样被利用 {#ch09-thread}
一棵 n 结点的普通二叉链表有 2n 个孩子指针域，可用来连接孩子的只有 n−1 条树边，留下 n+1 个空域。线索化利用这些空域存放遍历序列中的前驱和后继，但必须另加标志说明当前指针是孩子还是线索。

<div class="lesson-body">
<p>具有 n 个结点的二叉链表有 2n 个孩子指针域，非空域 n−1 个，因此空域 <code>n+1</code> 个。线索二叉树利用某些空指针记录遍历序列中的前驱与后继，并用 tag 区分指针含义。</p>
<p>以中序为例，某结点没有左孩子时，它的 left 可以指向中序前驱；没有右孩子时，right 可以指向中序后继。缺少前驱或后继时通常为 null 或指向哨兵。线索指针不可当真实孩子递归进入，否则会发生环。</p>
<pre><code>struct TNode{
    char val;
    TNode *left=nullptr,*right=nullptr;
    bool ltag=false,rtag=false; // false=孩子，true=线索
};
void threadInorder(TNode* cur,TNode*&amp; pre){
    if(!cur)return;
    if(!cur-&gt;ltag) threadInorder(cur-&gt;left,pre);
    if(!cur-&gt;left){cur-&gt;ltag=true;cur-&gt;left=pre;}
    if(pre &amp;&amp; !pre-&gt;right){pre-&gt;rtag=true;pre-&gt;right=cur;}
    pre=cur;
    if(!cur-&gt;rtag)threadInorder(cur-&gt;right,pre);
}
// 前提：传入原始二叉树，pre 初始 nullptr；原树尚未线索化。</code></pre><div class="question"><div class="qtitle">题：二叉树有 10 个结点，二叉链表初始有多少个空孩子域？</div><details id="q09-1"><summary>展开答案与推导</summary><div class="answer">2n−(n−1)=n+1=11 个。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>线程建立过程必须避免沿新写入的线索再次当作孩子深入，因此遍历下一子树时需检查 tag。本示例每次处理右子树前检查 rtag，但更稳健的工程实现还可显式保存原右孩子指针。中序的线索化用一次遍历，时间 O(n)，递归辅助栈 O(h)。</p>
</details>

## 中序线索树找前驱和后继 {#ch09-succ}
已知中序遍历次序是左、根、右，求结点 p 的后继分两种情形：若原本没有右孩子，可以直接使用 p 的右线索；若有真实右子树，下一个访问的是那棵右子树里最左的结点。判断 tag 的操作不可省略。

<div class="lesson-body">
<p>中序后继：若 rtag=1，right 直接是后继；否则进入真实右子树并沿真实左孩子一直走到最左。前驱完全对称。</p>
<p>例如树根 A、左 B、右 C；中序为 B,A,C。B 无右孩子，其右线索指向 A；A 的右是实际孩子 C，找 A 的后继需进右树寻找最左结点。</p><div class="diagram"><pre class="tree-diagram">     A
    / \
   B   C
中序：B → A → C
B.right 线索 → A
C.left 线索 → A</pre></div>
<pre><code>TNode* successor(TNode* x){
    if(!x)return nullptr;
    if(x-&gt;rtag)return x-&gt;right;
    x=x-&gt;right;
    while(x &amp;&amp; !x-&gt;ltag &amp;&amp; x-&gt;left)x=x-&gt;left;
    return x;
}
TNode* predecessor(TNode* x){
    if(!x)return nullptr;
    if(x-&gt;ltag)return x-&gt;left;
    x=x-&gt;left;
    while(x &amp;&amp; !x-&gt;rtag &amp;&amp; x-&gt;right)x=x-&gt;right;
    return x;
}</code></pre><div class="question"><div class="qtitle">题：中序线索二叉树里，如果结点没有真实右子树，如何得到后继？</div><details id="q09-2"><summary>展开答案与推导</summary><div class="answer">检查 rtag=1 时直接使用 right 指向的线索；不存在后继时可能得到 nullptr（取决于是否采用哨兵）。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>前序和后序线索也能建立，但“找到前驱/后继”可能需要父指针或从根搜索；后序线索寻找后继尤其依赖父关系。不要把“线索树所有序列的前驱后继都 O(1)”当成普遍结论。</p>
</details>

## 树的双亲表示、孩子表示与孩子兄弟表示 {#ch09-representation}
一般树的一个结点可能拥有五个孩子，但二叉结点仅两根链接。把第一根指向最左孩子，把第二根指向右侧下一兄弟，沿着兄弟链就能找到同一父亲的全部孩子。这样我们可以复用二叉链式结点来存森林。

<div class="lesson-body">
<p>一般树结点可以有任意多个孩子，常见存储有双亲数组、孩子链表、定长孩子指针和<strong>孩子-兄弟表示</strong>（firstChild / nextSibling）。</p>
<p>孩子-兄弟表示中，一根指针向下指首个孩子，另一根指针向右指下一兄弟。无论某结点有多少孩子，结点都只需两个链接域。这一表示可作为二叉树来处理。</p><div class="diagram"><pre class="tree-diagram">一般树：    A
           /|\
          B C D
         / \
        E   F
孩子兄弟：A.left→B→right→C→right→D
            B.left→E→right→F</pre></div>
<pre><code>template&lt;class T&gt;
struct GeneralNode{
    T data;
    GeneralNode* firstChild=nullptr;
    GeneralNode* nextSibling=nullptr;
};
void preorderForest(GeneralNode&lt;int&gt;* root){
    for(auto* p=root;p;p=p-&gt;nextSibling){
        std::cout&lt;&lt;p-&gt;data&lt;&lt;" ";
        preorderForest(p-&gt;firstChild);
    }
}</code></pre><div class="question"><div class="qtitle">题：孩子兄弟表示中，某结点的 left 是它的什么？right 是什么？</div><details id="q09-3"><summary>展开答案与推导</summary><div class="answer">left 指第一个孩子，right 指下一个兄弟。这是把一般树映射成二叉树时两根边的含义。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>双亲表示用一个数组，每个结点记录 parent 下标；直接找双亲 O(1)，找所有孩子可能需要扫数组。孩子链表反过来便于枚举孩子。存储方案选择直接决定查找父子关系的时间成本。</p>
</details>

## 一般树和森林转二叉树，遍历顺序的对应 {#ch09-forest}
将两棵一般树的根 A、D 视为兄弟，因此在二叉表示中 A.right=D。另一侧 A.left 则保存 A 的第一个孩子。把二叉树的 right 都误认成原树的右孩子，会把森林错误地合并成一棵树。

<div class="lesson-body">
<p>森林由零棵或多棵相互独立的树组成。转二叉树的规则：<strong>左指首孩子，右指下一兄弟</strong>；森林中各树根按兄弟关系串起来。</p>
<p>为什么森林先根遍历等同于其孩子兄弟二叉树前序？前序先访问结点、再沿左处理它的全部孩子，再沿右处理其兄弟，恰对应一般树“访问根、依次处理各子树”。</p>
<p>课程采用的对照关系：一般树或森林的<strong>先根次序</strong>对应其二叉树表示的<strong>前序</strong>；一般树或森林的<strong>后根次序</strong>对应其二叉树表示的<strong>中序</strong>。</p><div class="question"><div class="qtitle">题：森林 T₁ 的根 A、孩子 B,C；T₂ 只有根 D。转换后二叉树的结构？</div><details id="q09-4"><summary>展开答案与推导</summary><div class="answer">A.left=B，B.right=C，A.right=D（其余无子女及兄弟）。前序结果 A B C D，对应森林先根遍历。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>还原森林：取二叉树根作为第一棵树的根；沿其右链不断取新的树根；每棵树根的左分支生成其孩子森林。不能把对应二叉树中所有“右孩子”都解释为原树子女，右边表示兄弟。</p>
</details>

## 作业重点：静态孩子兄弟表如何还原整片森林 {#ch09-forest-table-practice}
静态孩子—兄弟表中的 llink、rlink 保存结点编号。先沿根的 rlink 找每棵树的根；进入一棵树后，再从 firstChild 开始沿兄弟链枚举所有直接孩子。所有连线必须有明确“孩子/兄弟”的含义，才能根据表无歧义地画出森林。

<div class="lesson-body">
<p>题目给出每个结点的编号、数据、<code>llink</code>（第一个孩子编号）和 <code>rlink</code>（下一个兄弟编号），以 −1 表示空指针。还原时<strong>先沿根结点的 rlink 找出森林各棵树的根</strong>，再沿每个结点的 llink 走到第一个孩子，继续沿孩子的 rlink 枚举它的兄弟。</p>
<p>原题静态表：0 A 的 llink=1、rlink=5，因此 A 的第一个孩子是 1 B，下一棵树的根是 5 F；5 F 的 rlink=7，因此第三棵树根是 7 H。再追踪 1→2→3 这个兄弟链，A 的孩子依次是 B、C、D；3 D 的 llink=4，于是 E 是 D 的孩子。</p>
<div class="diagram"><pre>树一              树二       树三
    A              F           H
  / | \             |          / \
 B  C  D            G         I   J
       |                      |
       E                      K

验证编号：A0 B1 C2 D3 E4 F5 G6 H7 I8 K9 J10</pre></div><p>树三的 H 左孩子 I（编号 8），I 的左孩子 K（编号 9），I 的右兄弟 J（编号 10）。注意 I.right 代表<strong>兄弟 J</strong>，不是 I 的右子女。</p><pre><code>#include &lt;vector&gt;
#include &lt;iostream&gt;
struct StaticNode{char data;int firstChild,nextSibling;};
void printTree(const std::vector&lt;StaticNode&gt;&amp; a,int p,int depth){
    if(p&lt;0)return;
    for(int i=0;i&lt;depth;++i)std::cout&lt;&lt;"  ";
    std::cout&lt;&lt;a[p].data&lt;&lt;'\n';
    for(int c=a[p].firstChild;c!=-1;c=a[c].nextSibling)
        printTree(a,c,depth+1);
}
void printForest(const std::vector&lt;StaticNode&gt;&amp; a,int root){
    for(int r=root;r!=-1;r=a[r].nextSibling)
        printTree(a,r,0);
}</code></pre><div class="question"><strong>同类自测：</strong>若 A.firstChild=B，B.nextSibling=C，B.firstChild=D，森林第一个树的形态？<details><summary>展开答案</summary>A 的孩子 B、C；B 还有孩子 D。D 属于 B 的下一层；C 是 B 的兄弟。</details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>不变量：对于父结点 p，遍历 <code>c=p.firstChild; c=c.nextSibling</code> 时每个 c 都是 p 的直接孩子。根的 nextSibling 链则列举森林的各棵树。由此也可以从静态表唯一还原结构，前提是索引合法、不存在非法环、同一结点不会被多次作为孩子引用。</p>
</details>

## 章节练习：基础、典型与迁移 {#ch09-extra-exercises}
先独立解题；所有提示与答案默认折叠。

<details class="question"><summary>【基础】n=12 的二叉链表共有多少个空左右孩子域？</summary>
<p><strong>选择思路：</strong>总共 2n 个孩子指针，树边 n−1 条。</p><p><strong>计算与结果：</strong>2n−(n−1)=n+1=13 个。</p><p><strong>易错点：</strong>n 个结点的非空树只有 n−1 条边。</p>
</details>

<details class="question"><summary>【巩固】中序线索树结点 p 的 rtag=1，如何求中序后继？</summary>
<p><strong>选择思路：</strong>rtag=1 代表右指针保存线索。</p><p><strong>计算与结果：</strong>直接取 p-&gt;right；若无后继，按实现可能为空或指向头哨兵。</p><p><strong>易错点：</strong>此时 right 不是实际右孩子。</p>
</details>

<details class="question"><summary>【作业同级】森林的 A 第一孩子 B、B 下一兄弟 C、A 下一兄弟 D、B 第一孩子 E。还原森林的树根及每树子女。</summary>
<p><strong>选择思路：</strong>先沿根 A 的 nextSibling 找各树根；再从首孩子枚举兄弟。</p><p><strong>计算与结果：</strong>共有两棵树：A 为第一根，孩子 B、C，且 B 的孩子 E；D 为第二棵的单结点根。</p><p><strong>易错点：</strong>B 的 nextSibling=C 表示 C 与 B 同属 A 的孩子。</p>
</details>

<details class="question"><summary>【作业同级】用显式栈实现二叉树镜像操作，说明访问顺序与返回值要求。</summary>
<p><strong>选择思路：</strong>每弹出一个结点交换左右指针，再压入其非空孩子。</p><p><strong>计算与结果：</strong>初始化栈压 root；循环弹出 p 并 swap(p.left,p.right)，将 p.left/p.right 依次入栈；最终返回最初的 root。时间 Θ(n)，深度优先栈空间 O(h)。</p><p><strong>易错点：</strong>若返回循环中的 p，可能返回末次访问的结点，而非树根。</p>
</details>

<details class="question"><summary>【提高】为什么二叉树的中序后继在有真实右子树时，须走到右子树最左结点？</summary>
<p><strong>选择思路：</strong>中序的访问顺序是左、根、右。</p><p><strong>计算与结果：</strong>根访问后，右子树最先输出的元素是其最左后裔。若没有右子树且有线索，才能沿右线索直接找到后继。</p><p><strong>易错点：</strong>右子树根不一定就是中序后继。</p>
</details>
