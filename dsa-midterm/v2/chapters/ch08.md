树是把大问题拆成子问题的自然结构。这章要学会从根与左右子树恢复形态，写出三种遍历、证明结点数公式，并使用数组与指针表示树。


## 一般树与二叉树的基本概念 {#ch08-tree}
用课程目录想象一般树：第一层是课程，第二层是章节，第三层是知识点。每个结点可以有任意多个孩子，且不能形成回路。二叉树每个结点有两个固定的孩子位置，即使某位置为空，也不能随意把另一孩子换到这边。

<div class="lesson-body">
<p>树由一个根及若干互不相交的子树递归组成。结点的<strong>度</strong>是子女数；叶子度为 0；树的度是所有结点度的最大值。二叉树每个结点最多有左右两个有序位置，缺少左孩子与缺少右孩子属于不同结构。</p>
<p>树的“层数”从 1 开始时，根是第 1 层。课件将结点深度记为结点层次、叶子高度记为 1，因此树的高度等于最大层数。其他资料常令根深度为 0、叶高度为 0，计算题必须看清约定。</p><div class="diagram"><pre class="tree-diagram">        A          根，度 3
      / | \
     B  C  D       B,C,D 同层
    / \    |
   E   F   G       E,F,G 为叶（若无子女）</pre></div>
<p><strong>满二叉树</strong>（课件含义：每层结点数均达到 2^(层数−1)）高度为 h 时共 <code>2^h−1</code> 结点；<strong>完全二叉树</strong>则只允许最后一层从右往左依次空缺，前面各层全部填满。满二叉树必完全，完全未必满。</p><div class="question"><div class="qtitle">题：根在第 1 层、高度 4 的满二叉树有多少结点？</div><details id="q08-1"><summary>展开答案与推导</summary><div class="answer">1+2+4+8=15。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>一般树的子女没有“左、右空位”限制；二叉树还要求左右子树顺序不能任意交换。英文 full binary tree 在部分教材中指每个内部结点恰有两个孩子，和课件“所有层都满”的用法存在术语差异，判断题应根据定义作答。</p>

## 二叉树的五个经典性质与完全二叉树下标 {#ch08-props}
高度与结点数公式源于每个结点最多产生两个孩子。根层最多 1 个，第 2 层最多 2 个，第 3 层最多 4 个，持续相加就得到 2^h−1。度为 0 与度为 2 的结点关系则应从总边数 n−1 推出，避免把它当成神秘记忆题。

<div class="lesson-body">
<p>根为第 1 层，第 i 层最多 <code>2^(i−1)</code> 个结点；高度 h 最多 <code>2^h−1</code> 个。任意<strong>非空</strong>二叉树若 n₀ 为叶数、n₂ 为度为 2 的结点数，则 <code>n₀=n₂+1</code>。</p>
<p>证明 n₀=n₂+1：总结点 n=n₀+n₁+n₂；树的边数 e=n−1。另一方面每个度 1 结点贡献一条边，度 2 贡献两条，所以 e=n₁+2n₂。两式相等立即推出 n₀=n₂+1。</p>
<p>完全二叉树用 0-based 数组储存：父下标 <code>floor((i−1)/2)</code>（i&gt;0），左孩子 <code>2i+1</code>、右孩子 <code>2i+2</code>（超过 n−1 则不存在）。含 n&gt;0 结点的完全二叉树高度为 <code>floor(log₂n)+1</code>，也等于 <code>ceil(log₂(n+1))</code>。</p><div class="question"><div class="qtitle">题：二叉树度为 2 的结点有 7 个，叶子结点有几个？</div><details id="q08-2"><summary>展开答案与推导</summary><div class="answer">8 个。恒等式不依赖树的平衡程度。</div></details></div><div class="question"><div class="qtitle">题：n=12 的完全二叉树，数组下标 4 的左右孩子下标是几？</div><details id="q08-3"><summary>展开答案与推导</summary><div class="answer">左 2×4+1=9，右 2×4+2=10，二者均小于 12。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>在完全二叉树的 1-based 编号法下：父为 ⌊i/2⌋，孩子为 2i 与 2i+1。两个版本不能混用。由高度公式推断最少结点数时也要记住最后一层可能只有最左侧一个结点。</p>
</details>

## 前序、中序、后序与层序遍历 {#ch08-traverse}
不要死背前中后三个字母。把“访问根节点”这一动作分别放在“递归左子树、递归右子树”的前面、中间和后面，自然形成前、中、后序。层序要求按层推进，故使用队列；每个结点的孩子只有在其父结点出队后才入队。

<p><strong>本节能力任务：</strong>能分别写出递归与非递归遍历，理解“根访问的位置”决定遍历名称。</p>
<div class="lesson-body">
<p><strong>前序 VLR</strong>：根、左、右；<strong>中序 LVR</strong>：左、根、右；<strong>后序 LRV</strong>：左、右、根；<strong>层序</strong>：按层自左到右（队列）。</p>
<p>把“访问根”的一步放在递归处理左右子树的前、中、后位置，便得到三种深度优先遍历。不要把后序误当成反向前序：右、左、根与左、右、根不同。</p><div class="diagram"><pre class="tree-diagram">       A
      / \
     B   C
    / \   \
   D   E   F
前序 A B D E C F
中序 D B E A C F
后序 D E B F C A
层序 A B C D E F</pre></div>

## 前序 + 中序重建，空结点标记与唯一性 {#ch08-rebuild}
给出前序 ABDECF 和中序 DEBACF，前序首项必为根 A；中序里 A 左边有三个结点，说明左子树恰有三个结点，然后再切前序中的三个位置。每一步先找根、再按中序拆区间、最后对子区间递归，切分就不会凭空猜。

<div class="lesson-body">
<p>结点值互不相同的二叉树，<strong>前序+中序</strong>或<strong>后序+中序</strong>可唯一重建；仅有前序与后序通常无法唯一确定左右结构。</p>
<p>步骤固定：① 前序首个字符确定根；② 在中序查根，左侧全部属于左子树、右侧属于右子树；③ 根据左子树长度切开前序的剩余部分；④ 对左右部分递归。</p><div class="diagram"><pre class="tree-diagram">前序：A B D E C F
中序：D B E | A | C F
根 A；左树含 D B E；右树含 C F
左树前序 B D E → 根 B，左右 D,E
右树前序 C F → 根 C，右子 F</pre></div>
<pre><code>#include &lt;string&gt;
#include &lt;unordered_map&gt;
#include &lt;stdexcept&gt;
struct Node{char v;Node* l;Node* r;};
Node* build(const std::string&amp; pre,const std::string&amp; in,
            int ps,int is,int len,
            const std::unordered_map&lt;char,int&gt;&amp; where){
    if(len==0)return nullptr;
    char root=pre[ps];
    auto it=where.find(root);
    if(it==where.end())throw std::invalid_argument("inconsistent");
    int k=it-&gt;second, left=k-is;
    if(left&lt;0||left&gt;=len)throw std::invalid_argument("inconsistent");
    Node* p=new Node{root,nullptr,nullptr};
    p-&gt;l=build(pre,in,ps+1,is,left,where);
    p-&gt;r=build(pre,in,ps+1+left,k+1,len-left-1,where);
    return p;
}
// 本算法假定节点值互异、输入序列合法且长度一致。
// 创建 where：for(int i=0;i&lt;n;++i) where[in[i]]=i;</code></pre><div class="question"><div class="qtitle">题：前序 ABDECF、中序 DEBACF，重建根结点左子树。</div><details id="q08-5"><summary>展开答案与推导</summary><div class="answer">根为 A，左中序 DEB，左前序 BDE，因此左子树根 B，B 的左子树根 D，D 的右孩子为 E；B 无右孩子。右子树 C 的右孩子是 F。</div></details></div><div class="question"><div class="qtitle">题：只有前序 AB、后序 BA，结构唯一吗？</div><details id="q08-6"><summary>展开答案与推导</summary><div class="answer">不唯一。B 可以是 A 的左孩子，也可以是 A 的右孩子，两者的前/后序都分别为 AB、BA。</div></details></div>

<h4>两份遍历序列如何逐段切分</h4>
<p>给前序 <code>A B D E C F</code>、中序 <code>D E B A C F</code>。前序首项 A 必是根。在中序 A 左侧正好有 <code>D E B</code> 三项，所以前序随后三项 <code>B D E</code> 也必属于左子树；余下 <code>C F</code> 是右子树。</p>
<div class="diagram"><pre>             A
           /   \
          B     C
         /       \
        D         F
         \
          E

左树前序 B D E；左树中序 D E B
B 是左树根；D E 都在 B 左侧
D 是其左子树根，中序 D E 表明 E 在 D 的右侧。</pre></div>
<p>重建中最常见错误是把中序 <code>DEB</code> 误当成 <code>DBE</code>，于是错误地把 E 画成 B 的右孩子。最后应将自己画出的树重新前序与中序各走一遍，确认同时与原输入完全一致。</p>

<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>只给“带空标记的前序串”时可以唯一重建，因为 <code>@</code> 明确记录缺失的左右孩子。示例 <code>A B @ @ C @ @</code>：先建 A，再建左 B，两次 @ 表示 B 的左右均空；随后建右 C，两次 @ 表示 C 左右均空。若键重复，普通前序+中序在无额外信息时一般可能不唯一。</p>
</details>

## 二叉树递归计数与 Catalan 数 {#ch08-count}
为什么 3 个结点有 5 种二叉树形态？先选根，再决定左边用 0、1、2 个结点，每一种分法里左、右子树的形态数相乘。把所有分法相加就得到 Catalan 递推，这也解释了为什么前序加后序一般不能唯一确定树。

<div class="lesson-body">
<p>有 n 个结点的不同有序二叉树结构数量是 Catalan 数：<code>C₀=1</code>，<code>Cₙ=Σ Cᵢ Cₙ₋₁₋ᵢ</code>（i=0..n−1），也等于 <code>binom(2n,n)/(n+1)</code>。</p>
<p>把根固定后，剩余 n−1 个结点分成左子树 i 个、右子树 n−1−i 个。左右形态独立选择，因此该分法有 Cᵢ·Cₙ₋₁₋ᵢ 种；枚举所有 i 相加。</p>
<pre><code>#include &lt;vector&gt;
long long catalan(int n){
    std::vector&lt;long long&gt; c(n+1,0);c[0]=1;
    for(int k=1;k&lt;=n;++k)
        for(int i=0;i&lt;k;++i)
            c[k]+=c[i]*c[k-1-i];
    return c[n]; // n 较大时 long long 会溢出
}</code></pre><div class="question"><div class="qtitle">题：3 个结点能构成多少棵不同的有序二叉树？</div><details id="q08-7"><summary>展开答案与推导</summary><div class="answer">C₃=C₀C₂+C₁C₁+C₂C₀=2+1+2=5。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>对 n 个互异关键码，中序结果固定为升序时，二叉搜索树可取的不同形态数量也为 Cₙ。该“有序”特征是计数的必要条件；若左右孩子不可区分，计数问题不同。</p>
</details>

## 作业重点：带 @ 空位的数组二叉树与中序遍历 {#ch08-sparse-array-tree}
用完全二叉树数组位置存储一般二叉树时，@ 只表示这个位置没有结点，后面下标仍要按 2i+1、2i+2 找孩子。若按顺序将非空元素紧凑地重新摆放，原来的左右父子关系就被破坏，遍历答案也会跟着改变。

## 作业重点：一般树的度数与叶子数公式 {#ch08-general-leaf-formula}
要计算一般树有多少叶子，先数边：每个度为 k 的结点向下提供 k 条边，所以总边数等于 Σk·n_k；同一棵非空树还有 N−1 条边。让这两种计数相等并解出 n₀，即可得到所有度数对叶数的贡献。

<div class="lesson-body">
<p>有一棵非空一般树，n₀ 个度为 0 的结点，n₁ 个度为 1 的结点，…，nₘ 个度为 m 的结点。证明：<code>n₀=1+Σ(k−1)nₖ</code>（k=1..m），即 <code>n₀=1+n₂+2n₃+...+(m−1)nₘ</code>。</p>
<p>推导只用两件事：①树有 <code>N=Σnₖ</code> 个结点，因此边数 <code>N−1</code>；②每个度为 k 的结点贡献 k 条指向孩子的边，所以总边数也等于 <code>Σk*nₖ</code>。令二者相等，单独解出 n₀。</p><div class="diagram"><pre>Σ(k*n_k)= (n0+n1+...+nm)-1
0*n0 + n1 + 2n2 + 3n3 + ... + m*nm
   = n0 + n1 + n2 + ... + nm - 1
→ n0 = 1 + (2-1)n2 + (3-1)n3 + ... + (m-1)nm</pre></div>
<p>例：度为 1 的结点 4 个、度为 2 的结点 3 个、度为 3 的结点 2 个，则叶结点数 <code>1+3+2×2=8</code>；n₁ 的系数为 0，正好抵消。</p><div class="question"><strong>同类自测：</strong>若某树有 2 个度为 3 的结点、5 个度为 1 的结点，其余为叶，求叶数和总结点数。<details><summary>展开答案</summary>n₀=1+2×2=5，N=5+5+2=12；边数 11，度数和 5+6=11，核对正确。</details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>令最大度 m=2 就退化为二叉树的 <code>n₀=n₂+1</code>。此证明仅对单棵非空树成立；若是有 t 棵树的森林，边数为 N−t，推广为 <code>n₀=t+Σ(k−1)nₖ</code>。</p>

## 作业重点：使用显式栈非递归交换二叉树左右子树 {#ch08-mirror-stack}
二叉树镜像需要交换每一个结点的左右指针。递归版本天然深入每个孩子；题目禁止递归时，就自己建栈保存尚未交换的结点。要保持一个关键不变量：栈里留下的结点以后都还会访问，已经弹出的结点左右已交换。

<div class="lesson-body">
<p>二叉树镜像变换是对<strong>每个结点</strong>交换左右孩子。递归可写成交换当前结点、再分别递归处理两个孩子；考试要求非递归实现时，改用栈保存尚未访问的结点指针。</p>
<p>显式栈中保存待处理结点，弹出一个 p，就交换 p.left 与 p.right，然后将交换之后存在的左右孩子压栈，直到栈空。这里的顺序只影响访问顺序，对最后镜像结果没有影响。</p><div class="diagram"><pre>原树：       A            镜像：     A
            / \                     / \
           B   C                   C   B
          / \   \                 /   / \
         D   E   F               F   E   D

交换全部结点的 left/right；只交换根不够。</pre></div>
<pre><code>#include &lt;stack&gt;
#include &lt;utility&gt;
struct Node{char val;Node* left;Node* right;};
Node* mirrorIterative(Node* root){
    if(!root)return nullptr;
    std::stack&lt;Node*&gt; pending;
    pending.push(root);
    while(!pending.empty()){
        Node* p=pending.top();pending.pop();
        std::swap(p-&gt;left,p-&gt;right);
        if(p-&gt;left)pending.push(p-&gt;left);
        if(p-&gt;right)pending.push(p-&gt;right);
    }
    return root;
}</code></pre><p>这里 <code>std::stack&lt;Node*&gt;</code> 保存指针的副本，指针指向原树里的结点，因此交换会修改原结点。原作业提供的填空框架<strong>最后写 <code>return node;</code></strong>，但 node 在循环过程中持续变化；对一般输入不能保证仍为根，需明确改为 <code>return root;</code>，否则即使填对中间空位也可能返回错误指针。</p><div class="question"><strong>同类自测：</strong>把镜像函数对同一棵树连续执行两次，结果怎样？<details><summary>展开答案</summary>恢复原树；因为每个结点的左右指针都交换两次。</details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>每个结点入栈一次、出栈一次，时间 Θ(n)，栈空间最坏 O(h) 到 O(n) 取决于访问策略及树形（本例普通深度优先栈中待访问结点数最多可达 O(h) 对二叉树）。更精确地，本例每层最多积压一个未访问分支，故 O(h)。原题片段还混合使用名为 Stack 的课堂接口与 <code>std::stack</code>，需要按最终选择的接口统一 Push/Pop 或 push/pop。</p>
</details>

## 章节练习：基础、典型与迁移 {#ch08-extra-exercises}
先独立解题；所有提示与答案默认折叠。

<details class="question"><summary>【基础】非空二叉树有 7 个度为 2 的结点，叶子共有多少？</summary>
<p><strong>选择思路：</strong>利用 n₀=n₂+1。</p><p><strong>计算与结果：</strong>n₀=8。此等式来自边数 n−1 与度数和 n₁+2n₂ 相等。</p><p><strong>易错点：</strong>度为 1 的结点个数不会改变该等式。</p>
</details>

<details class="question"><summary>【巩固】二叉树根 A，左 B、右 C，B 的右孩子 D。前序、中序、后序？</summary>
<p><strong>选择思路：</strong>分别将根访问放在最前、中间、最后。</p><p><strong>计算与结果：</strong>前序 A B D C；中序 B D A C；后序 D B C A。</p><p><strong>易错点：</strong>B 无左孩子时，中序先访问 B 再 D。</p>
</details>

<details class="question"><summary>【作业同级】数组 [A,B,C,@,D,E,F] 按完全二叉树位置存放，求中序序列。</summary>
<p><strong>选择思路：</strong>0-based 的左/右孩子分别 2i+1、2i+2，@ 是空位。</p><p><strong>计算与结果：</strong>A 左子树 B 只有右孩子 D → B D；右子树 C 有 E,F → E C F；全树中序 B D A E C F。</p><p><strong>易错点：</strong>空位不可被后面的结点填补。</p>
</details>

<details class="question"><summary>【作业同级】前序 A B D E C F，中序 D B E A C F，重建二叉树，并写后序序列。</summary>
<p><strong>选择思路：</strong>前序首项 A 是根；在中序 A 处分割左右子树。</p><p><strong>计算与结果：</strong>左中序 D B E、前序 B D E → B 左 D 右 E；右中序 C F、前序 C F → C 右 F。后序 D E B F C A。</p><p><strong>易错点：</strong>左右子树的切片长度必须保持一致。</p>
</details>

<details class="question"><summary>【提高】一般树度为 1 的结点有 4 个、度为 2 的有 3 个、度为 3 的有 2 个，其他全是叶。求叶数和总点数。</summary>
<p><strong>选择思路：</strong>树边数 N−1 同时等于各点孩子数之和。</p><p><strong>计算与结果：</strong>n₀=1+n₂+2n₃=1+3+4=8；总点数 8+4+3+2=17。验证边数 16、度数和 4+6+6=16。</p><p><strong>易错点：</strong>二叉树的 n₀=n₂+1 不能直接照搬到度可大于 2 的一般树。</p>
</details>
