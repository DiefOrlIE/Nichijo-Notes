# 栈：限制存取位置的线性结构
<!-- id: ch03 | source: 3-Stack&Queue，第 1—32 页（栈及表达式部分） -->
当数据只能从一端进出，会出现什么问题？表达式括号、列车调度和函数调用都需要“最近进入的先处理”，栈的结构正是为此服务。


## 栈与顺序栈、链栈 {#ch03-basic}
先模拟 push(A)、push(B)、pop()：输出一定是 B。这一限制让栈可以用一个 top 下标实现，入栈前判满、出栈前判空；用链表实现时对应的是把栈顶指针挪到新结点或它的 next。两种实现提供同一组操作。

<div class="lesson-body">
<p>栈只允许在<strong>栈顶</strong>插入和删除。规则为后进先出 <strong>LIFO</strong>。基本操作：<code>push(x)</code>、<code>pop()</code>、<code>top()</code>、<code>empty()</code>。</p>
<p>一叠盘子只能从上面放和拿。顺序栈用数组与栈顶下标 <code>top</code> 表示状态，空栈约定 <code>top=−1</code>；压栈先递增、再赋值，出栈先取值、再递减。其他实现可能让 top 指向下一个空位置，做题时先看约定。</p><div class="diagram"><pre class="tree-diagram">栈顶 top=2
┌─────┐
│  C  │ ← 最后进入，最先弹出
├─────┤
│  B  │
├─────┤
│  A  │
└─────┘</pre></div>
<pre><code>#include &lt;vector&gt;
#include &lt;stdexcept&gt;
template&lt;class T&gt; class Stack {
    std::vector&lt;T&gt; a;
public:
    bool empty() const {return a.empty();}
    void push(const T&amp; x){a.push_back(x);}
    T pop(){
        if(empty()) throw std::underflow_error("empty stack");
        T x=a.back(); a.pop_back(); return x;
    }
    const T&amp; top() const{
        if(empty()) throw std::underflow_error("empty stack");
        return a.back();
    }
};</code></pre><p>动态数组顺序栈：除扩容外 push/pop/top O(1)，push 均摊 O(1)。链栈在头部插删，同样 O(1)，每个结点附带指针存储成本。</p><div class="question"><div class="qtitle">题：空栈按 top=−1 的约定，执行 push(3),push(5),pop(),push(7) 后 top 及内容？</div><details id="q03-1"><summary>展开答案与推导</summary><div class="answer">top=1；栈底到栈顶为 [3,7]。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>顺序栈需要考虑容量及扩容失败；链栈需要管理动态结点的释放。空栈执行 pop 的结果应由接口明确规定。若 push 是尾递归函数内部的局部栈操作，切勿混淆“数据栈”和“调用栈”。</p>
</details>

## 合法出栈序列与括号匹配 {#ch03-sequence}
列车按 1,2,3,… 依次入栈，目标弹出序列先出现 3，就必须先压进 1、2、3，然后只弹最上面的 3。每一步都让“目标车号”与栈顶比较；想要的车被别的车压住且后面再无机会时，候选序列即不可行。

<div class="lesson-body">
<p>入栈顺序固定时，出栈顺序受到限制。同一个元素一旦出栈不能再回到栈中。</p>
<p>判断候选出栈序列的通用方法：按固定入栈顺序逐个压栈，只有当栈顶等于期望输出时才弹出；直到匹配全部输出或输入耗尽仍无法匹配。</p>
<pre><code>#include &lt;stack&gt;
#include &lt;vector&gt;
bool validPop(const std::vector&lt;int&gt;&amp; input,
              const std::vector&lt;int&gt;&amp; output) {
    if(input.size()!=output.size()) return false;
    std::stack&lt;int&gt; s;
    size_t j=0;
    for(int x:input){
        s.push(x);
        while(!s.empty() &amp;&amp; j&lt;output.size() &amp;&amp; s.top()==output[j]){
            s.pop();++j;
        }
    }
    return j==output.size();
}</code></pre><div class="question"><div class="qtitle">题：入栈 1,2,3,4，出栈顺序 3,1,4,2 是否可能？</div><details id="q03-2"><summary>展开答案与推导</summary><div class="answer">不可能。为弹出 3，先压 1,2,3 并弹出 3，栈顶变 2。此时下一步要求弹出 1，但 2 阻挡它。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>不同元素的所有合法出栈排列数是第 n 个 Catalan 数 <code>Cₙ = (1/(n+1))·binom(2n,n)</code>（n=3 时为 5）。证明可将合法压栈/弹栈序列映射为从不越过水平线的括号序列，但这个计数结论适用于固定互异元素的单栈进出模型。</p>
</details>

## 中缀、后缀表达式与两栈求值 {#ch03-expression}
中缀表达式写的是我们习惯的数学顺序，后缀表达式要求运算符出现在两个操作数之后。先写 A+B*C 的计算：B、C 先相乘，所以后缀为 A B C * +。实现时运算符栈暂存尚未输出的符号，读到低优先级运算符会触发高优先级符号弹出。

<div class="lesson-body">
<p>中缀表达式形如 <code>3+4*2</code>，后缀（逆波兰）为 <code>3 4 2 * +</code>。后缀求值只需要一个操作数栈。</p>
<p>依次扫描：遇数字压栈，遇二元运算符连续弹出两个数 <code>b</code>、<code>a</code>，算 <code>a op b</code> 再压回。例如 <code>8 3 -</code> 是 8−3，而非 3−8。</p><div class="diagram"><pre class="tree-diagram">3 4 2 * +
3：    [3]
4：    [3,4]
2：    [3,4,2]
*：    [3,8]
+：    [11]</pre></div>
<pre><code>#include &lt;stack&gt;
#include &lt;sstream&gt;
#include &lt;string&gt;
#include &lt;stdexcept&gt;
int evalPostfix(const std::string&amp; expr){
    std::istringstream in(expr);
    std::stack&lt;int&gt; s;std::string t;
    while(in&gt;&gt;t){
        if(t=="+"||t=="-"||t=="*"||t=="/"){
            if(s.size()&lt;2)throw std::runtime_error("bad postfix");
            int b=s.top();s.pop();
            int a=s.top();s.pop();
            if(t=="/" &amp;&amp; b==0)throw std::runtime_error("division by zero");
            s.push(t=="+"?a+b:t=="-"?a-b:t=="*"?a*b:a/b);
        }else{s.push(std::stoi(t));}
    }
    if(s.size()!=1)throw std::runtime_error("bad postfix");
    return s.top();
}</code></pre><p>中缀转后缀：数字直接输出；运算符遇到栈顶<strong>优先级更高或相等</strong>的左结合运算符，先弹出它；左括号入栈，右括号弹出直到左括号。运算符结合性需专门处理，比如幂运算常取右结合。</p><div class="question"><div class="qtitle">题：将 (A+B)*C-D 转为后缀式。</div><details id="q03-3"><summary>展开答案与推导</summary><div class="answer"><code>AB+C*D-</code>。括号中 A+B 先计算，其结果与 C 相乘，最后减 D。</div></details></div>
</div>

<h4>把“符号优先级”变成真的栈操作</h4>
<p>以 <code>A+B*C-D</code> 为例。读 A 立即输出；读 + 时符号栈空，压 +；读 B 立即输出；读 * 时比栈顶 + 优先级高，压 *；读 C 输出；读 - 时比 * 和 + 都低，所以依次弹出 *、+，再压 -；最后读 D 输出，输入结束时再弹出 -。</p>
<div class="diagram"><pre>读入       输出后缀               运算符栈（底→顶）
A          A                      空
+          A                      +
B          A B                    +
*          A B                    + *
C          A B C                  + *
-          A B C * +              -
D          A B C * + D            -
结束       A B C * + D -          空</pre></div>
<p>遇到括号时，左括号先压栈作为屏障，右括号触发弹出至左括号；括号本身不会进入后缀输出。要处理 <code>!A</code> 或 <code>-A</code> 时，还得在识别 token 的阶段明确它们是一元运算符。初次练习先掌握二元四则运算的表格，再迁移到复杂逻辑表达式。</p>

<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>表达式求值中的中缀转后缀法可看作“将运算优先级编码进输出顺序”。对包含负数字面量、单目负号、函数和幂运算的输入，必须明确词法与优先级约定；简化教学算法只处理正整数及四则二元运算。</p>
</details>

## 两个栈共享一个数组 {#ch03-shared}
两个独立栈若各自分配固定长度，即使左栈爆满，右栈空出的空间也无法借用。把一根数组分给两个从相反方向增长的栈，只有两端栈顶相邻时才真满；推导满条件前先写清两个初始 top 值。

<div class="lesson-body">
<p>共享栈用同一数组存两个栈，栈 0 从左向右增长，栈 1 从右向左增长。只要中间还有空位，任意一方可以继续进栈。</p>
<p>容量 n 的数组，初始 <code>top0=−1</code>、<code>top1=n</code>；左栈压入后 top0++，右栈压入前 top1--。当 <code>top0+1==top1</code> 时整个数组已满。</p>
<pre><code>#include &lt;vector&gt;
class DualStack{
  std::vector&lt;int&gt; a;int l=-1,r;
public:
  explicit DualStack(int n):a(n),r(n){}
  bool pushLeft(int x){if(l+1==r)return false;a[++l]=x;return true;}
  bool pushRight(int x){if(l+1==r)return false;a[--r]=x;return true;}
  bool popLeft(int&amp; x){if(l&lt;0)return false;x=a[l--];return true;}
  bool popRight(int&amp; x){if(r==(int)a.size())return false;
     x=a[r++];return true;}
};</code></pre><div class="question"><div class="qtitle">题：长度 8 的共享栈，top0=2、top1=5，两个栈合计占用几个位置？</div><details id="q03-4"><summary>展开答案与推导</summary><div class="answer">左栈占 0,1,2 共 3 项；右栈占 5,6,7 共 3 项；合计 6 项，中间 3、4 两个空位。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>共享栈的优点是两侧空间可动态分配，避免预先为两个大小变化不确定的栈各分配固定容量。注意 top 的方向、入栈前判满和各自的判空条件必须成套使用。</p>
</details>

## 作业重点：一元负号、!、比较及 &&/|| 的后缀转换 {#ch03-operators}
复杂表达式首要步骤是标记每个符号是一元还是二元。例如 -A 的负号只接收一个操作数，A-B 的减号接收两个；它们即使写法相同也应在词法阶段区分。逻辑非同样是一元，先把括号内部结果求出来，才能对其取反。

<p><strong>读完这一节要能做：</strong>把二元运算、一元运算、结合性和 C++ 优先级分开处理。</p>
<div class="lesson-body">
<p>四则后缀转换的简单规则需要扩展到<strong>一元负号</strong>、<code>!</code>、<code>&lt;</code>、<code>&gt;</code>、<code>&amp;&amp;</code>、<code>||</code>。按本次作业，常用优先级从高到低：一元 <code>!</code> 与一元负号；乘除；加减；关系运算；逻辑与；逻辑或。括号强制改变组合次序。</p>
<p>为避免歧义，讲义使用 <code>NEG</code> 代表一元负号。输入 <code>-A+B-C+D</code> 解析为 <code>(((-A)+B)-C)+D</code>，后缀 <code>A NEG B + C - D +</code>；输入 <code>A*(-B)+C</code> 的后缀为 <code>A B NEG * C +</code>。按运算符结合性处理同优先级：加减乘除和二元关系运算在此题中按从左往右结合；一元前缀运算符从右往左绑定。</p>
<p>作业中逻辑题的分步结果：</p><div class="diagram"><pre>(A && B) || !(E > F)

## 作业重点：列车出栈合法性及 I/O 操作轨迹 {#ch03-stack-schedules}
不要只判断“这个出栈序列看起来合理”。逐步记 I1、I2… 和 O1、O2…，写下栈顶的变化，就得到一份可复核证据。对于所有合法序列的数量，先从 n=1、2、3 的小规模观察，再理解 Catalan 递推。

<div class="lesson-body">
<p>固定入栈顺序 1,2,3,4,5,6，出栈序列的可能数目为 <code>C₆=132</code>。检验某个候选序列时，按要求不断压入尚未入栈的下一列车，直到栈顶等于目标车号，再弹出；若目标车始终被别的车挡住，序列不合法。</p>
<p>给操作写下轨迹最稳妥：<code>I1</code> 表示车 1 入栈，<code>O1</code> 表示车 1 出栈。中途能否输出指定车完全由<strong>栈顶</strong>决定；不能随意从栈底抽车。</p>

## 作业重点：中缀转后缀中每次入栈 I、出栈 O 的序列 {#ch03-io-events}
作业里的 I、O 有时特指运算符栈事件，并不表示操作数。读入 a 时直接输出，读入 * 时才压栈记 I(*)；读到 - 时，若 * 优先于 -，应先弹出 * 记 O(*) 再压 -。先划分事件对象，统计才不会多算。

<div class="lesson-body">
<p>将 <code>a*x-b/x↑2</code> 转成 <code>a x * b x 2 ↑ / -</code>，要求记录的 I、O 只针对<strong>运算符栈</strong>；读到操作数直接输出，既不记 I 也不记 O。运算符 ↑ 优先级高于乘除，乘除高于加减。</p>
<p>每遇到低优先级运算符，先把栈中应先执行的高优先级符号弹出输出，再压入当前运算符。例如读到 <code>-</code> 时，必须先弹出 <code>*</code>；读到 <code>/</code> 时，先前压着的 <code>-</code> 优先级更低，直接压入 /。</p>

</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>另一个解题法是维护不变量：操作符栈（不计括号）从底到顶按优先级大致递增；读到新操作符时，反复弹出所有应先运算的栈顶操作符。遇到同优先级符号是否弹出，还要根据结合性判断。以上输出轨迹采用“运算符读入时计入栈，表达式结束统一清栈”的约定。</p>
</details>

<p class="checkpoint"><strong>学完核对：</strong>合上公式，自己说出输入与约定、为何选择这一步、执行状态怎样变化、答案如何验证。若说不出，重做上面的具体例子。</p>

## 章节练习：从基础操作到陌生题 {#ch03-extra-exercises}
这些题目的思路和答案默认收起。先独立写出结果，再展开提示核查；一道题若仅能跟着答案做，说明还应回看相应操作示范。

<details class="question"><summary>【基础】push(3),push(8),pop(),push(5)，栈底到栈顶是什么？</summary>
<p><strong>选方法的提示：</strong>先弹出最后进入的 8。</p>
<p><strong>完整推理与结果：</strong>3,5，栈顶为 5。</p>
<p><strong>最容易错的地方：</strong>栈为后进先出。</p>
</details>

<details class="question"><summary>【巩固】(A+B)*C-D 的后缀表达式是什么？</summary>
<p><strong>选方法的提示：</strong>括号内先加，再乘，最后减。</p>
<p><strong>完整推理与结果：</strong><code>A B + C * D -</code>。</p>
<p><strong>最容易错的地方：</strong>二元操作数顺序保持不变。</p>
</details>

<details class="question"><summary>【作业同级】固定入栈 1,2,3,4,5，能否按 3,2,5,4,1 出栈？写 I/O 轨迹。</summary>
<p><strong>选方法的提示：</strong>为输出 3 先入栈 1、2、3。</p>
<p><strong>完整推理与结果：</strong>可行：I1 I2 I3 O3 O2 I4 I5 O5 O4 O1。</p>
<p><strong>最容易错的地方：</strong>应写出能证明可行的具体操作。</p>
</details>

<details class="question"><summary>【作业同级】将 !(A &amp;&amp; B) || C&gt;D 转为后缀。</summary>
<p><strong>选方法的提示：</strong>! 只处理一个括号结果；&gt; 优先于 ||。</p>
<p><strong>完整推理与结果：</strong><code>A B &amp;&amp; ! C D &gt; ||</code>。</p>
<p><strong>最容易错的地方：</strong>! 是一元操作符。</p>
</details>

<details class="question"><summary>【提高】a+b*c-d 的运算符入栈 I、出栈 O 事件序列？</summary>
<p><strong>选方法的提示：</strong>读到 - 时先弹出 * 和 +。</p>
<p><strong>完整推理与结果：</strong>I(+) I(*) O(*) O(+) I(-) O(-)，简写 <code>I I O O I O</code>。</p>
<p><strong>最容易错的地方：</strong>到输入结束，还要把栈内符号清空。</p>
</details>
