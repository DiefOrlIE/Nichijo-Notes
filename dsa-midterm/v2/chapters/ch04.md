# 递归：调用栈与非递归转换
<!-- id: ch04 | source: 3a-Recursion，第 1—24 页；3-Stack&Queue 中栈的应用 -->
递归函数如何知道做完当前任务后应回到哪里？先从具体调用过程观察，再讨论什么时候可以改写成循环以及怎样计算时间与空间。


## 递归三件事：定义、规模缩小、出口 {#ch04-why}
以 factorial(3) 为例：函数需要的只是“3! 等于 3×2!”；求 2! 又回到同样形式，最后在 0! 返回 1。递归定义必须明确更小的任务与出口，并检验规模每次确实下降，否则调用可以无限延伸。

<div class="lesson-body">
<p>递归函数在解决规模较大的问题时，调用自身处理规模更小的同类问题。必须有<strong>终止条件</strong>，并保证每次调用向终止条件推进。</p>
<p>阶乘是最直接的例子：<code>fact(4)=4×fact(3)</code>，一直分解到 <code>fact(0)=1</code>。执行有两个方向：先沿调用链“下潜”，再逐层返回结果“上浮”。</p><div class="diagram"><pre class="tree-diagram">fact(4) → fact(3) → fact(2) → fact(1) → fact(0)
    24   ←   6    ←   2    ←   1    ←   1</pre></div>
<pre><code>long long factorial(int n){
    if(n&lt;0) throw std::invalid_argument("negative");
    if(n==0) return 1;
    return n*factorial(n-1);
}</code></pre><p><strong>函数调用帧</strong>存放当前调用需要保留的参数、局部状态和返回位置等。<code>factorial(4)</code> 的四层待乘运算在子调用返回前都要保留。</p><div class="question"><div class="qtitle">题：为什么先输出再递归与先递归再输出得到相反顺序？</div><details id="q04-1"><summary>展开答案与推导</summary><div class="answer">前者在下潜时输出（从大到小），后者在回溯时输出（从小到大）。例如 P(3)：先输出时 3,2,1，后输出时 1,2,3。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>正确性常用数学归纳法证明：基础情形正确；假设规模较小调用正确；再证明当前步骤利用子问题结果能产生正确答案。终止性另外证明：选取非负整数度量 n，每次严格减小，最终达到出口。</p>
</details>

## 模拟调用栈：返回地址为何要保存 {#ch04-stack}
调用 factorial(3) 时，计算机不能丢失尚未执行的“乘 3”这一动作。它把当前参数和返回地址保存在调用栈，等 factorial(2) 返回后接着做乘法。画三层栈帧比只看源代码更容易解释为什么深递归可能栈溢出。

<div class="lesson-body">
<p>递归过程大体包含：保存当前调用的必要状态、传递实参、执行下一调用，返回后恢复状态并继续下一条语句。</p>
<p>如果一个函数先调用自身再打印 <code>w</code>，调用 <code>P(3)</code> 时必须记住“返回后打印当前这一层的 w”。这种尚未完成的工作就是栈帧存在的原因。</p><div class="diagram"><pre class="tree-diagram">P(3) 等待：打印 3
P(2) 等待：打印 2
P(1) 等待：打印 1
P(0) 到达出口 → 打印 1 → 2 → 3</pre></div>
<pre><code>// 递归版本：先深入，返回后打印
void P(int w){
    if(w&gt;0){P(w-1);std::cout&lt;&lt;w&lt;&lt;"\n";}
}
// 显式栈版本：保留需要在回溯时使用的 w
void P_iterative(int w){
    std::stack&lt;int&gt; s;
    while(w&gt;0){s.push(w);--w;}
    while(!s.empty()){std::cout&lt;&lt;s.top()&lt;&lt;"\n";s.pop();}
}</code></pre><div class="question"><div class="qtitle">题：递归打印 1,2,3,4 的过程，显式栈应该按什么顺序压入？</div><details id="q04-2"><summary>展开答案与推导</summary><div class="answer">按 w=4、3、2、1 压入。LIFO 弹出顺序自然变为 1、2、3、4。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>一个函数如果有多个递归调用点且返回后执行的后续代码不同，显式栈帧除参数外还应记录“程序计数器”或“阶段标记”，用于决定返回后继续哪一段。课件例 6 的 L1/L2 正是这个思想。</p>
</details>

## 尾递归为什么可以压缩成循环 {#ch04-tail}
尾递归里最后一步就是返回子调用结果，不需要保留“递归回来后再执行”的工作。把更新后的参数放回循环变量，通常能写出等价 while；如果还有 return n*f(n−1)，返回后仍需乘 n，便不满足这种直接转换的条件。

<div class="lesson-body">
<p><strong>尾递归</strong>指递归调用完成后，当前函数无需再做额外工作，能够直接把返回值交给调用者。</p>
<p><code>print(w); P(w-1);</code> 是尾部递归调用的典型形式，转成 <code>while(w&gt;0){print(w);--w;}</code> 不需要积压一层层返回后的操作。</p>
<pre><code>void printDescending(int n){
    while(n&gt;0){
        std::cout&lt;&lt;n&lt;&lt;"\n";
        --n;
    }
}
long long factorialTail(int n,long long acc=1){
    if(n&lt;0) throw std::invalid_argument("negative");
    while(n&gt;0){acc*=n;--n;} // 用累积参数去掉待乘工作
    return acc;
}</code></pre><p>很多 C++ 编译器并不保证尾调用优化，因此写成明确的循环才可以从语言层面保证常数级调用栈占用。这里的阶乘仍可能发生整数溢出。</p><div class="question"><div class="qtitle">判断：只要函数最后一行写了自己调用，就一定是尾递归。</div><details id="q04-3"><summary>展开答案与推导</summary><div class="answer">需要检查调用返回后是否还有计算。例如 <code>return n*f(n-1)</code> 仍要乘以 n，因此该调用不属于严格的尾调用；<code>return f(n-1)</code> 可属于尾调用。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>多个分支中的尾调用也可转循环，但有时需要状态机来区分不同分支。递归一旦涉及分叉回溯、树的遍历或复杂返回路径，显式栈的思路通常比强行使用 while 更清晰。</p>
</details>

## 递归正确性证明与复杂度 {#ch04-proof}
递归正确性可沿问题规模写归纳：先验证最小规模答案；假定较小的子问题返回正确；再说明当前把这些结果怎样组合出正确答案。复杂度则从调用树累计所有工作，与栈空间沿最长调用路径计量。

<div class="lesson-body">
<p>用递推式描述运行时间：链式递归常满足 <code>T(n)=T(n−1)+O(1)</code>，二叉分叉可能满足 <code>T(n)=2T(n−1)+O(1)</code>，空间还要另算栈深度。</p>
<p>例：<code>sum(n)=n+sum(n−1)</code>，递归深度 n，时间 Θ(n)、栈空间 Θ(n)；用变量循环累加，则时间 Θ(n)、额外空间 Θ(1)。两种写法结果相同，资源不同。</p>
<div class="question"><div class="qtitle">题：递归求二叉树结点数 <code>1+count(left)+count(right)</code> 的时间与额外空间？</div><details id="q04-4"><summary>展开答案与推导</summary><div class="answer">每个结点恰访问一次，时间 Θ(n)。递归同时活跃的调用层数等于树的高度 h，因此辅助栈 Θ(h)；平衡树 h=Θ(log n)，链状树 h=Θ(n)。</div></details></div><div class="question"><div class="qtitle">题：朴素递归 Fibonacci 的时间为何指数级？</div><details id="q04-5"><summary>展开答案与推导</summary><div class="answer"><code>F(n)=F(n−1)+F(n−2)</code> 重复计算大量相同的子问题。时间满足 <code>T(n)=T(n−1)+T(n−2)+Θ(1)</code>，增长为 Θ(φⁿ)，栈深 Θ(n)；记忆化或迭代可做到 Θ(n) 时间。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>阶乘正确性证明：基础 n=0 时返回 1=0!。假定 <code>factorial(n−1)=(n−1)!</code>，对于 n&gt;0，函数返回 <code>n×(n−1)!=n!</code>。因为参数 n 每次减 1，且为非负整数，故终将终止。<strong>部分正确性 + 终止性</strong>共同给出整体正确性。</p>
</details>

## 汉诺塔与分治递归树 {#ch04-hanoi}
汉诺塔的最后一步必须把最大盘移到目标柱，而在此之前必须挪走上方所有小盘。于是一次任务自然分成“移动 n−1 盘、移最大盘、再移动 n−1 盘”。虽然函数定义短，递归树的工作量却指数增长。

<div class="lesson-body">
<p>汉诺塔把 n 个盘子从 A 柱移到 C 柱，借用 B 柱：先移 n−1 个到 B；移最大盘到 C；再将 n−1 个从 B 移到 C。始终遵守大盘不能压在小盘之上。</p>
<p>递推次数 <code>T(n)=2T(n−1)+1</code>，且 T(1)=1，因此 <code>T(n)=2^n−1</code>。每次调用都严格减少盘子数，但总移动次数仍呈指数增长。</p>
<pre><code>#include &lt;iostream&gt;
void hanoi(int n,char from,char aux,char to){
    if(n&lt;=0)return;
    hanoi(n-1,from,to,aux);
    std::cout&lt;&lt;from&lt;&lt;" -&gt; "&lt;&lt;to&lt;&lt;"\n";
    hanoi(n-1,aux,from,to);
}</code></pre><div class="question"><div class="qtitle">题：n=3 时最少移动次数是多少，前两步如何移？</div><details id="q04-6"><summary>展开答案与推导</summary><div class="answer">7 步。由 A 到 C、借 B：先 A→C（最小盘），再 A→B（次小盘），随后 C→B，A→C，B→A，B→C，A→C。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>时间 Θ(2ⁿ)，递归栈深 Θ(n)。把它与阶乘的单递归链 Θ(n) 时间作比较，就能理解递归复杂度来自“每次产生多少子调用”，而非只看递归深度。</p>
</details>

## 作业重点：Ackermann 函数的嵌套递归与手算 {#ch04-ackermann}
阿克曼函数令人困惑的是第三分支：第二个参数本身还要通过另一次递归算出来。先固定 m=1，推得 A(1,n)=n+2；再算 A(2,0)、A(2,1)，即可计算稍大的值。按参数依赖的顺序画箭头，避免直接代一大串嵌套式。

<p><strong>读完这一节要能做：</strong>知道每层调用的展开顺序，能一步不跳地写出 Ack(2,1) 的结果。</p>
<div class="lesson-body">
<p>作业采用以下 Ackermann 函数（m、n 为非负整数）：<code>A(0,n)=n+1</code>；<code>A(m,0)=A(m−1,1)</code>（m&gt;0）；<code>A(m,n)=A(m−1,A(m,n−1))</code>（m,n&gt;0）。它用来说明多层<strong>嵌套递归</strong>及快速增长。</p>
<p>第三种情形一定要从内向外计算：<code>A(m,n−1)</code> 是外层 <code>A(m−1,·)</code> 的第二个参数。不能把两个调用当作彼此独立的并列调用，也不能写成 <code>A(m−1,n−1)</code>。</p><div class="diagram"><pre>A(0,n) = n+1
A(1,0) = A(0,1) = 2
A(1,n) = A(0,A(1,n-1)) = A(1,n-1)+1
因此 A(1,n)=n+2
A(2,0)=A(1,1)=3
A(2,1)=A(1,A(2,0))=A(1,3)=5</pre></div>
<p>伪代码：<code>if m=0 return n+1; if n=0 return Ack(m−1,1); return Ack(m−1,Ack(m,n−1))</code>。</p><pre><code>#include &lt;stdexcept&gt;
long long Ack(int m,long long n){
    if(m&lt;0||n&lt;0)throw std::invalid_argument("nonnegative");
    if(m==0)return n+1;
    if(n==0)return Ack(m-1,1);
    return Ack(m-1,Ack(m,n-1));
}</code></pre><p>对应作业完整展开：<code>A(2,1) = A(1,A(2,0)) = A(1,A(1,1)) = A(1,A(0,A(1,0))) = A(1,A(0,A(0,1))) = A(1,A(0,2)) = A(1,3) = 5</code>。</p><div class="question"><strong>同类自测：</strong>计算 A(2,2)。<details><summary>展开答案</summary>A(2,2)=A(1,A(2,1))=A(1,5)=7。对固定 m=2，A(2,n)=2n+3。</details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>先对 m=1 用归纳法推出 A(1,n)=n+2；再对 m=2 推出 A(2,n)=2n+3。这样能减少手算分支错误。递归算法非常快地增长并产生大量调用，真实实现很快出现深栈或整数溢出；期中主要要求正确建立递归关系、画出展开过程及求低阶具体值。</p>
</details>

## 章节练习：从基础操作到陌生题 {#ch04-extra-exercises}

<details class="question"><summary>【基础】f(n)=n+f(n−1)、f(0)=0，f(4) 是多少？</summary>
<p><strong>选方法的提示：</strong>逐步展开到出口。</p>
<p><strong>完整推理与结果：</strong>4+3+2+1+0=10。</p>
<p><strong>最容易错的地方：</strong>递归有终止条件才能返回。</p>
</details>

<details class="question"><summary>【巩固】void p(int n){if(n&gt;0){p(n-1);cout&lt;&lt;n;}}，p(3) 输出？</summary>
<p><strong>选方法的提示：</strong>输出放在递归调用之后。</p>
<p><strong>完整推理与结果：</strong>输出 123。</p>
<p><strong>最容易错的地方：</strong>下潜顺序与回溯输出顺序相反。</p>
</details>

<details class="question"><summary>【作业同级】A(0,n)=n+1；A(m,0)=A(m−1,1)；A(m,n)=A(m−1,A(m,n−1))，求 A(2,2)。</summary>
<p><strong>选方法的提示：</strong>先推得 A(1,n)=n+2。</p>
<p><strong>完整推理与结果：</strong>A(2,1)=5，故 A(2,2)=A(1,5)=7。</p>
<p><strong>最容易错的地方：</strong>一定先求内层参数。</p>
</details>

<details class="question"><summary>【作业同级】四个盘子的汉诺塔最少移动多少次？栈空间增长如何？</summary>
<p><strong>选方法的提示：</strong>T(n)=2T(n−1)+1。</p>
<p><strong>完整推理与结果：</strong>T(4)=2⁴−1=15；最大递归深度 Θ(n)，空间 Θ(n)。</p>
<p><strong>最容易错的地方：</strong>指数移动次数与线性栈深并不冲突。</p>
</details>

<details class="question"><summary>【提高】为什么树结点总数的左右递归 Θ(n)，朴素 Fibonacci 递归却指数级？</summary>
<p><strong>选方法的提示：</strong>检查子问题是否发生大量重复。</p>
<p><strong>完整推理与结果：</strong>树左右子树互不相交，每个结点仅访问一次；Fibonacci 重复计算 F(k)，运行时间 Θ(φⁿ)。</p>
<p><strong>最容易错的地方：</strong>只看有几个递归调用，不能决定复杂度。</p>
</details>
