# 数组、矩阵与压缩存储
<!-- id: ch06 | source: 4-String，第 1—49 页（数组、稀疏矩阵）；页码按原 PPT 顺序 -->
二维表格放入一维内存后，我们需要在下标与地址之间来回转换；当大量位置必为零时，还需要只存有效信息的压缩表示。


## 多维数组的行优先与列优先地址映射 {#ch06-mapping}
二维数组 A[3][4] 可以想成每行四格的货架。要定位第 2 行第 1 列，先跨过两整行共八项，再向右跨一项，因此偏移 2×4+1。列优先的公式必须重新想象存储顺序，先看有多少整列。

<p><strong>读完这一节要能做：</strong>不背错 m、n：清楚行数、列数、下标起点、元素字节数。</p>
<div class="lesson-body">
<p>数组是同类型元素按下标组织的集合。二维数组 <code>A[m][n]</code> 表示 m 行、n 列。每个元素占 b 字节，首元素地址为 base。<strong>行优先</strong>：<code>LOC(A[i][j])=base+(i*n+j)*b</code>（0-based）；<strong>列优先</strong>：<code>base+(j*m+i)*b</code>。</p>
<p>想象把二维表格拉成一根长条。行优先先放满第 0 行（n 个）、再放第 1 行；来到第 i 行前已经放了 i*n 个，该行再跳过 j 个，故偏移 i*n+j。列优先则先填满 j 列之前的 j*m 项。</p><div class="diagram"><pre class="tree-diagram">A[3][4]（行优先）
     列0 列1 列2 列3
行0   0   1   2   3
行1   4   5   6   7
行2   8   9  10  11</pre></div>
<p>示例：A[3][4]、base=1000、每项 4 字节，A[2][1] 在行优先下偏移 2*4+1=9 项，地址 1036；列优先下偏移 1*3+2=5 项，地址 1020。</p><div class="question"><div class="qtitle">题：A[5][7] 行优先，A[3][4] 的线性下标（从 0）及地址？首地址 200，每项 8 字节。</div><details id="q06-1"><summary>展开答案与推导</summary><div class="answer">下标 3×7+4=25，地址 200+25×8=400。</div></details></div><div class="question"><div class="qtitle">题：若 i、j 的下界分别为 1、1，行优先的公式怎么改？</div><details id="q06-2"><summary>展开答案与推导</summary><div class="answer">将各自减去下界：<code>base+((i−1)*n+(j−1))*b</code>。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>推广三维 A[d₁][d₂][d₃]，页/行/列优先的偏移为 <code>i*d₂*d₃+j*d₃+k</code>。一般 d₁×...×dₙ 的下标为 <code>Σ iₖ·∏(后续维大小)</code>。这是逐维递推的混合进制表示。C/C++ 原生多维数组采用行优先，动态 <code>int**</code> 逐行分别分配时不一定整体连续，不能无条件当成一个连续二维块。</p>
</details>

## 对称矩阵的上下三角压缩 {#ch06-symmetric}
对称矩阵中的 A[3][1] 与 A[1][3] 相等，保存两次就是浪费。若只存下三角，前 i 行已有 1+2+⋯+i 项，再在当前行走 j 项，就得到 i(i+1)/2+j 的位置；另一半坐标需先交换。

<div class="lesson-body">
<p>对称矩阵满足 <code>A[i][j]=A[j][i]</code>。只存一侧三角及主对角线，共 <code>n(n+1)/2</code> 项。下三角按行存储时，若 i≥j，下标 <code>k=i(i+1)/2+j</code>；若 i&lt;j，交换 i、j。</p>
<p>为什么有 i(i+1)/2？行 0 存 1 项，行 1 存 2 项，…，行 i−1 存 i 项，它们合计 1+2+...+i=i(i+1)/2；第 i 行 A[i][j] 前面还有 j 项。</p><div class="diagram"><pre class="tree-diagram">下三角 n=4：
行0：[a00]                  → B[0]
行1：[a10 a11]              → B[1..2]
行2：[a20 a21 a22]          → B[3..5]
行3：[a30 a31 a32 a33]      → B[6..9]</pre></div>
<p>上三角按行：行 0 存 n 项，行 1 存 n−1 项，前 i 行共 <code>in−i(i−1)/2</code> 项；行 i 内 A[i][j] 再跳 j−i 项。故 <code>k=i(2n−i−1)/2+j</code>（i≤j）。另半边交换 i、j。</p><div class="question"><div class="qtitle">题：4 阶对称矩阵只存下三角，A[1][3] 在 B 的哪个下标？</div><details id="q06-3"><summary>展开答案与推导</summary><div class="answer">转成 A[3][1]，k=3×4/2+1=7。</div></details></div><div class="question"><div class="qtitle">题：4 阶对称矩阵只存上三角，A[2][3] 的 k？</div><details id="q06-4"><summary>展开答案与推导</summary><div class="answer">k=2×(8−2−1)/2+3=8，对照序列 a00,a01,a02,a03,a11,a12,a13,a22,a23,a33。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>给定下三角存储数组的 k，可解唯一行 i 满足 <code>i(i+1)/2 ≤ k &lt; (i+1)(i+2)/2</code>，再求 <code>j=k−i(i+1)/2</code>。手算可逐步找三角数；实现可二分查找行号。注意题目如要求“第 k 个存储单元”可能从 1 开始，必须先减 1。</p>
</details>

## 三对角矩阵的压缩与逆映射 {#ch06-tridiag}
三对角矩阵每行最多三个有效位置，第 0 行和末行各两个，中间各三个，所以总共只有 3n−2 项。压缩公式来自“前面完整行的项数 + 当前行中的位置”；先检查 |i−j|≤1，再应用公式。

<div class="lesson-body">
<p>n 阶三对角矩阵只允许主对角线及相邻两条副对角线含非零元素，即 <code>|i−j|≤1</code>。按行压缩这三条对角线，共 <code>3n−2</code> 个位置（n≥2；n=1 时为 1）。</p>
<p>首行有 2 项，末行有 2 项，中间 n−2 行各 3 项，因此总数 <code>2+3(n−2)+2=3n−2</code>。在第 i 行开始之前，已经放入 2+3(i−1)=3i−1 项（i≥1），该行 A[i][j] 的列从 i−1 开始，行内下标为 j−i+1。相加得到 <code>k=2i+j</code>。</p>
<p>逆映射：<code>i=floor((k+1)/3)</code>，<code>j=k−2i</code>，对合法 k=0,…,3n−3 成立。</p><div class="question"><div class="qtitle">题：n=6 的三对角矩阵，A[3][2] 对应 B[?]，B[8] 对应哪个 A 元素？</div><details id="q06-5"><summary>展开答案与推导</summary><div class="answer">A[3][2] → k=2×3+2=8；反过来 i=floor(9/3)=3，j=8−6=2。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>数组外的元素是隐含的零，不占压缩数组位置；不能把不满足 <code>|i−j|≤1</code> 的任意坐标代入公式当作有效索引。对三对角矩阵的乘法或线性方程求解可以设计专用线性算法，但这些属于课程以外的延伸。</p>
</details>

## 稀疏矩阵三元组、转置和快速转置 {#ch06-sparse}
稀疏矩阵只存非零项，转置时行列互换。逐列反复扫描三元组会产生很多重复工作；快速转置先统计各列项数并求前缀和，直接知道新行的开始位置，然后一遍将每项送到正确位置。

<p><strong>读完这一节要能做：</strong>手工构造 rowSize/rowStart，理解为什么快速转置一次扫描就能定位每个元素。</p>
<div class="lesson-body">
<p>稀疏矩阵大多数元素为零。三元组 <code>(row,col,value)</code> 只记录非零项；还需记录矩阵行数、列数和项数。转置 <code>B[j][i]=A[i][j]</code>。<strong>朴素转置</strong>逐列扫描三元组表；<strong>快速转置</strong>使用计数与起始位置。</p>
<p>若输入三元组按原矩阵“行号升序、同一行列号升序”排列，转置后要按“新行号升序、新列号升序”排列。直接调换 row/col 会打乱新行分组；朴素算法对每个原列扫描全部元素，复杂度 O(cols·t)。</p><div class="diagram"><pre class="tree-diagram">A 的三元组（行、列、值）
(0,1,5) (0,3,8) (1,0,7) (2,1,9)
转置后的有序三元组：
(0,1,7) (1,0,5) (1,2,9) (3,0,8)</pre></div>
<p>快速转置分三步：① 统计原矩阵每列非零个数 count[c]；② 计算每个新行在输出的起点 start[c]（前缀和）；③ 原表逐项扫描，把元素放入 <code>B[start[col]]</code>，随后 start[col]++。</p><pre><code>#include &lt;vector&gt;
#include &lt;stdexcept&gt;
struct Triple{int row,col,value;};
std::vector&lt;Triple&gt; fastTranspose(
    int rows,int cols,const std::vector&lt;Triple&gt;&amp; a){
    if(rows&lt;0||cols&lt;0)throw std::invalid_argument("dimension");
    std::vector&lt;int&gt; count(cols,0),start(cols,0);
    for(auto x:a){
        if(x.row&lt;0||x.row&gt;=rows||x.col&lt;0||x.col&gt;=cols)
            throw std::out_of_range("coordinate");
        ++count[x.col];
    }
    for(int c=1;c&lt;cols;++c)start[c]=start[c-1]+count[c-1];
    std::vector&lt;Triple&gt; b(a.size());
    for(auto x:a){
        int dest=start[x.col]++;
        b[dest]={x.col,x.row,x.value};
    }
    return b; // 前提：a 已按原行、同一行原列升序
}</code></pre><div class="question"><div class="qtitle">题：原列数为 4，列非零项 count=[1,2,0,1]，求初始 start。</div><details id="q06-6"><summary>展开答案与推导</summary><div class="answer">start[0]=0，start[1]=1，start[2]=3，start[3]=3，即 [0,1,3,3]。随后放入元素时，对应的 start 项自增。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>计数 O(t)，前缀和 O(cols)，填写 O(t)，合计时间 <code>O(t+cols)</code>，辅助数组 O(cols)，输出 O(t)。课件还涉及带行指针的二元组表及<strong>正交链表</strong>：前者可将每行开始位置单独存储；后者让每个非零元素同时属于一条行链和一条列链，适于动态插删。</p><div class="question"><div class="qtitle">题：快速转置能否随意打乱输入三元组顺序而保持输出按行列有序？</div><details id="q06-7"><summary>展开答案与推导</summary><div class="answer">不能保证。它稳定保留同一原列内各项的扫描顺序；若输入已按原行有序，转置后的同一新行才会按新列有序。</div></details></div>
</details>

## 带行指针的二元组与正交链表 {#ch06-orthogonal}
三元组数组连续、节省指针，但频繁插入一个非零项时可能搬移许多记录。正交链表给每个非零项两条路径：同一行的右邻和同一列的下邻。若任务大量按行、按列动态操作，这份额外链接就值得维护。

<div class="lesson-body">
<p>除了 (row,col,value) 三元组，稀疏矩阵还可以用<strong>带行指针数组的二元组</strong>：存每行起始偏移，元素只保留 (col,value)。<strong>正交链表</strong>让每个非零元同时连入所在行、所在列的链表。</p>
<p>行指针数组通常按行开始位置记录，行 r 的项占区间 <code>[start[r],start[r+1])</code>。常见工程实现用 rows+1 项保存最后的终止位置，课程原 PPT 的行指针可采用 rows 项，必须根据定义确定末行结束位置。</p>
<pre><code>struct OrthogonalNode {
    int row,col,value;
    OrthogonalNode* right; // 所在行的下一个非零项
    OrthogonalNode* down;  // 所在列的下一个非零项
};
// 构造时要同时维护行头数组与列头数组；
// 每个非零项只创建一份结点，两方向共享。</code></pre><div class="question"><div class="qtitle">题：稀疏矩阵执行大量非零元素的动态插删，三元组数组与正交链表哪一种通常更合适？</div><details id="q06-8"><summary>展开答案与推导</summary><div class="answer">正交链表可在已有链接位置局部接入、删除结点，避免三元组数组大规模搬移，但要维护行、列两套链接关系。</div></details></div>
</div>
<details class="optional"><summary>选读：原理推广与额外边界</summary>
<p>正交链表在行、列遍历与稀疏结构更新频繁时具有优势，但代码与指针开销更大。若只用于稀疏矩阵乘向量，压缩行存储往往有更好的连续访问局部性。</p>
</details>

## 章节练习：从基础操作到陌生题 {#ch06-extra-exercises}
这些题目的思路和答案默认收起。先独立写出结果，再展开提示核查；一道题若仅能跟着答案做，说明还应回看相应操作示范。

<details class="question"><summary>【基础】0-based A[4][6] 行优先，A[2][3] 的一维下标？</summary>
<p><strong>选方法的提示：</strong>前两行各 6 项。</p>
<p><strong>完整推理与结果：</strong>2×6+3=15。</p>
<p><strong>最容易错的地方：</strong>乘列数，而非行数。</p>
</details>

<details class="question"><summary>【巩固】8 行×10 列、每项 8 字节的数组至少占多少字节？</summary>
<p><strong>选方法的提示：</strong>元素总数×单项字节。</p>
<p><strong>完整推理与结果：</strong>8×10×8=640 字节。</p>
<p><strong>最容易错的地方：</strong>不能忽略每元素的字节大小。</p>
</details>

<details class="question"><summary>【作业同级】5 阶对称矩阵只存下三角，A[1][4] 映射到 0-based B 的下标？</summary>
<p><strong>选方法的提示：</strong>先交换 i、j 到下三角。</p>
<p><strong>完整推理与结果：</strong>A[4][1] → 4×5/2+1=11。</p>
<p><strong>最容易错的地方：</strong>应先检查存储的是上三角还是下三角。</p>
</details>

<details class="question"><summary>【作业同级】某稀疏矩阵按列非零项个数 count=[2,0,1,3]，快速转置 start 数组？</summary>
<p><strong>选方法的提示：</strong>对 count 求排他前缀和。</p>
<p><strong>完整推理与结果：</strong>start=[0,2,2,3]。</p>
<p><strong>最容易错的地方：</strong>start[c] 指向新第 c 行的首项位置。</p>
</details>

<details class="question"><summary>【提高】7 阶三对角矩阵按行压缩，B[12] 对应哪个 A[i][j]？</summary>
<p><strong>选方法的提示：</strong>i=floor((k+1)/3)，j=k−2i。</p>
<p><strong>完整推理与结果：</strong>i=floor(13/3)=4，j=12−8=4，所以 A[4][4]。</p>
<p><strong>最容易错的地方：</strong>下标公式只对矩阵带内元素有意义。</p>
</details>
