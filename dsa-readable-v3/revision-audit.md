# 第十五章独立教学审查：旧版缺口、修改与验收
日期：2026-10-26
范围：旧版 `dsa-midterm/v2/chapters/ch15.md` 与新增 `dsa-readable-v3/manuscripts/ch15.md`。
旧版仍保留在 https://dieforlie.github.io/Nichijo-Notes/dsa-midterm/；新版单独发布，不覆盖旧版源稿或读者进度。

## 读者模型
只假定读者会基本 C++ 变量、数组、简单循环和链表指针。无须看过《集合与散列》PPT，也无需先懂位掩码、等价关系、并查集、哈希、复杂度摊还分析或 ASL。正文须在首次使用处解释这些概念的用途及操作。

## 逐段审查与具体修改

| 旧版位置与证据 | 为什么无法顺读 | 新版修改及可观察能力 |
|---|---|---|
| ch15-set 第 2 段直接抛出 ADT、全集大小和成员映射 | 学生还未亲手完成集合运算，就需要比较实现策略 | 先对两张选课名单执行交并差，再引入集合名称、子集和 ADT；能独立判断具体成员关系 |
| ch15-bit-vector 起首写 q=⌊x/w⌋、r=x mod w、`1ULL << r`，随后直接大段代码 | 打包公式、位移符号、C++ 类一次到齐，前置操作未形成 | 先八格纸面位图、逐位真值表、原始 C++ 四行；随后解释机器字划分与完整 BitSet；能手动定位编号 19 所在位 |
| ch15-linked-set 已给出两个数组的合并结果但略掉两个游标的每一步 | 学生只能抄最后结果，不清楚相等时指针怎样移动 | 增加五行完整轨迹，并分类讨论 <、=、>；能自己写交并差双指针 |
| ch15-equivalence 用社团是否等价作为开头，随后一句话切到树 | 反例抢在正面能力之前，等价类与动态合并的动机脱节 | 先从三条同组消息逐次归并，再归纳自反/对称/传递；最后解释为何普通更新组号低效 |
| ch15-dsu 只给一次 parent 最终数组，混入负数/根的定义 | 根、指向与大小在一段中同时切换，读者看不懂数组变化 | 先画父指针树，再明确 parent 两种状态、表格推 Union(1,4) 和逐次数组 |
| ch15-union-find 刚出现路径压缩马上给全 C++ 和反阿克曼结论 | 复杂度与代码被放在 Find/Union 执行示例之前 | 先构造长链的问题，分别讨论按大小与路径压缩；再完整代码、逐操作状态表；复杂度为补充结论 |
| ch15-dictionary 一段话将字典、BST、散列并列 | 两个新知识点之间缺少任务识别和工具比较 | 从书号找书名的键值对任务，检查数组/有序数组/BST 的不足，再引入地址计算 |
| ch15-hash-function 五种函数名称紧挨碰撞定义 | 新手看不到散列真正怎么定位一个记录 | 从 104→4 和 49 与 89 冲突入手，明确 m 与 p 的不同用途，再比较函数选择 |
| ch15-linear-probe 成功 ASL 后紧接失败 ASL=2.5 | 欠缺一次失败查找如何停止的操作证据 | 增加插入表、成功探查路径表、失败初始地址逐格表；分清“空槽算探查”与“只数实存键比较” |
| ch15-other-probes、ch15-chaining 连续公式 | 改进方案为何产生、算法保持什么条件不清楚 | 线性聚集→平方/双重散列的动机，再用同一组键比较；链地址从真实桶链表与查找路径引入 |
| ch15-asl-exam 只给三道综合题 | 独立题型和方法选择不足 | 基础位向量、并查集状态、线性插表、失败 ASL、工具选择五类迁移题，分提示与答案 |
| 旧版 BitSet 代码存在未限定的 `size_t` 使用和密集实现 | 代码无法保证明确依赖且不方便边学边试 | 新版独立给最小可执行片段及使用 `std::size_t` 的完整 C++17；后续自动编译测试 |

## 教材范围与勘误
保留 85 页 PPT 所覆盖的集合表示、等价类、UFSets 的 Find/Union、大小/高度合并、路径压缩、字典、散列函数、线性/平方/双重探查、拉链法、ASL。对课件第 14 页逻辑非错误、第 54 页键值笔误、第 83 页表长与模数关系进行限定说明。现代 C++17 和健壮性细节明确标记为讲义补充。

## 交付与证据
1. 原始教学稿 `manuscripts/ch15.md` 必须先独立完成，并经过全文顺读与演算核对。
2. 用单一 Markdown 源构建 `chapter-data.js` 及独立 `index.html`，旧页面与进度不受影响。
3. 用自动化脚本检查全部 15 个主题、表格与代码围栏、练习、字体、夜间模式、持久化状态及手机宽度；将 C++17 的 BitSet、DSU、LinearHashSet 代码编译并运行小测试。
4. 自动化测试支持网站行为与已测算例，不足以证明真实初学者阅读无障碍；未做真实读者试读或 iOS Safari 真机测试时明确记载。
